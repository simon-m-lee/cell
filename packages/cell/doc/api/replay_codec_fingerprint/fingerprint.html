String fingerprint(

Computes the SHA-256 fingerprint of value's canonical JSON form, hex-encoded.

When to use

Fingerprints are the unit of identity in the replay ledger:

  • CellSnapshot.configFingerprint — identifies a cell's receptor + rule
    • context configuration. A cell whose fingerprint changed between recording and replay is a hard divergence.
  • PulseDigest — identifies a pulse's fully expanded lineage. Two pulses with the same digest are byte-identical, which the ledger uses to reconstruct without storing the whole chain per entry.

How it works

The value is serialised with canonicalJsonEncode and hashed with SHA-256.

Parameters:

  • value: Any JSON-encodable value.

Returns:

The hex digest string, not the Digest object — every consumer eventually serialises it, so returning hex here removes a second encoding step everywhere.

Implementation

String fingerprint(Object? value) {
  final canonical = canonicalJsonEncode(value);
  final digest = sha256.convert(utf8.encode(canonical));
  return digest.toString();
}
