API Chooser — cell

Layer: Cell — graph nodes, ingress/observe, TestCell, transactions, deputies. Does not own: the decision (cell_flow), the books (cell_tissue).

Read this file when: a BRD sentence says "capture X", "retain X", "show X derived from Y", "commit two facts together", or "redact PII".

The full decision procedure lives in the layer HowTo; this matrix is generated from the ### AI Agent Guide blocks and cannot drift.
