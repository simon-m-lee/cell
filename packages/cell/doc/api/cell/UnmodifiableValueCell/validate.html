TestCell<Cell> validate

Layers TestCell.readOnly atop the principal's integrity gate.

Because this projection shares the principal's nucleus (and therefore its Box, lock, and receptor), the only safe place to install the read-only enforcement is on the validate seam. CellBase.apply consults validate.action(...), which now sees chain([principal.testRule, readOnly]) and rejects any call to a whitelisted function (i.e. apply itself).

Cached (late final) because TestCell.chain allocates a fresh record.
