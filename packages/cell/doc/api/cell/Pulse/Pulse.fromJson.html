Constructs a pulse from the canonical JSON produced by Pulse.toJson, with optional overrides for every constructor parameter.

The result is a decoded pulse — its source is resolved via resolver (or overridden by source), its policy and callbacks are null unless overridden, and its branches and cycle checker are fresh. The decoded pulse is semantically the same pulse the original had on the wire, plus the caller's overrides.

Version discriminator

The JSON must carry "__pulse__": "<version>" where <version> is supported by the current codec (1.x). A missing or unsupported version throws PulseDecodeError.

Source resolution

If the encoded pulse carries a source, resolver is called with the encoded Cell.id. The resolver returns the live cell with that id, or null if the cell is not in the current graph. A null resolution is not an error — the decoded pulse has source == null.

If source is passed, it overrides the resolver's result. To strip a source from the JSON, pass source: pulseNullSource.

Overrides

Every override is optional. An absent override means "use the JSON's value." A sentinel (pulseNullX) means "explicitly override to null." Anything else is an override.

Field Absent override Override Sentinel
policy null (a decoded pulse never has a policy) the given policy pulseNullPolicy (equivalent to absent)
context the JSON's context the given context — (null means "use JSON")
payload the JSON's payload the given payload pulseNullPayload
type the JSON's type (inheriting from parent) the given type pulseNullType
source the resolved source, or null the given source pulseNullSource
step the JSON's step the given step pulseNullStep
priority the JSON's priority (inheriting from parent) the given priority — (null means "use JSON")
onComplete null the given callback — (null means "use JSON", i.e., none)
onError null the given callback — (null means "use JSON", i.e., none)
onProgress null the given callback — (null means "use JSON", i.e., none)

Collective pulses

A JSON with isComposite: true cannot have a payload override; the factory throws PulseDecodeError. The children cannot be overridden; a caller who wants different children constructs a new collective via Pulse.batch.

Lenient mode

Pass lenient: true to accept the lenient decode contract: where the document structure is sound but a reference or codec resolution fails (a context codec mismatch), a safe default is substituted (PulseContext.system) and the field is recorded. onSkipped is invoked once after decoding with the aggregated skip list — qualified paths for parent/child levels ('parent.onComplete'). Structural corruption still throws, and an override always wins over the lenient fallback and is never counted as skipped.

Re-encodability

A pulse with an overridden onComplete, onError, onProgress, or policy cannot be re-encoded strictly. Pulse.toJson on the result throws the corresponding PulseNotSerializable; pass lenient: true to substitute and record instead. This is the honest answer: the caller chose to attach a non-serializable field.

Errors

  • PulseDecodeError if the JSON is malformed, the version is unsupported, or an override is invalid for the JSON's shape.
  • PulseNotSerializable is not thrown by this factory; it is thrown by Pulse.toJson.

factory Pulse.fromJson(
  Map<String, dynamic> json, {
  PulseResolver? resolver,
  bool lenient = false,
  void Function(List<String> skipped)? onSkipped,

  // Overrides. Absent or null means "use the JSON's value."
  // Sentinels mean "explicitly override to null."
  Object? policy,
  PulseContext? context,
  Object? payload,
  Object? type,
  Object? source,
  Object? step,
  int? priority,
  void Function(Pulse pulse)? onComplete,
  void Function(Pulse pulse, Object error, {StackTrace? stackTrace})? onError,
  void Function(Pulse pulse, Cell cell, {String? message})? onProgress,
}) {
  // 1. Reject an invalid override before any decoding work.
  if (json['isComposite'] == true && payload != null) {
    throw PulseDecodeError(
      'cannot override payload on a collective pulse; '
      'construct via Pulse.batch',
    );
  }

  // 2. Decode the JSON's envelope. [lenient] and [onSkipped] are
  //    passed through to the codec: lenient substitutes a safe
  //    default for reference/codec resolution failures (never for
  //    structural corruption) and records every substitution in the
  //    onSkipped callback with qualified paths.
  final decoded = decodePulse(
    json,
    resolver: resolver,
    lenient: lenient,
    onSkipped: onSkipped,
  );

  // 3. Apply overrides. The helper implements the sentinel convention:
  //    absent → JSON's value; sentinel → explicit null; present → the
  //    override. Sentinels compare by identity — pass the sentinel
  //    itself, never a value that merely equals it.
  T? resolveOverride<T>(Object? override, Object sentinel, T? current) {
    if (identical(override, sentinel)) return null;
    if (override == null) return current;
    return override as T;
  }

  final effectivePayload =
      resolveOverride<P>(payload, pulseNullPayload, decoded.payload as P?);
  final effectiveType =
      resolveOverride<Object?>(type, pulseNullType, decoded.type);
  final effectiveSource =
      resolveOverride<Cell>(source, pulseNullSource, decoded.source);
  final effectiveStep =
      resolveOverride<String>(step, pulseNullStep, _localStepOf(decoded));
  final effectivePolicy = identical(policy, pulseNullPolicy)
      ? null
      : (policy as PulseEphemeralPolicy?);
  final effectiveContext = context ?? decoded.context;
  final effectivePriority = priority ?? decoded.priority;
  final effectiveParent = decoded._parent;

  // 4. Construct. The type parameter P is the caller's; the cast is
  //    safe because the override or the decoded payload is already
  //    the correct type.
  return _Pulse<P>(
    payload: effectivePayload,
    type: effectiveType,
    context: effectiveContext,
    timestamp: decoded.timestamp,
    source: effectiveSource,
    step: effectiveStep,
    priority: effectivePriority,
    policy: effectivePolicy,
    parent: effectiveParent,
    onComplete: onComplete,
    onError: onError,
    onProgress: onProgress,
  );
}
