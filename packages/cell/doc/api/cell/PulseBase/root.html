root

root property

  1. @override
PulseBase<P> get root
override

The primordial ancestor that initiated this pulse's causal lineage.

The root represents the "ground truth" of a signal before any transformations, metadata evolutions, or diagnostic steps were applied.

When to use

  • Root Cause Analysis: Use this to trace a signal back to its point of origin during debugging or forensic auditing.
  • Intent Preservation: Access the root when you need to verify the original, unmodified payload or context that started a propagation event.
  • Lineage Correlation: Identifying if two different pulses in the graph share the same starting point.

How it works

The root is established when the first pulse in a chain is constructed. Every subsequent evolution (via evolve, withStep, or map) inherits this reference. It is immutable and persists throughout the entire lifecycle of the signal.

Non‑obvious: Roots are not aware of descendants

Causal tracking in the cell graph is backwards-looking. A pulse knows its parent, but a parent does not know its children.

Consequently, calling root.trace (or any lineage inspection) will only show the history of the root itself—which is typically empty. It will not show the steps or transformations added by descendants. To see the "complete story" of a signal's evolution, you must inspect the latest pulse in the chain.

Non‑obvious: Self-referential roots

For an original pulse (the start of a chain), pulse.root returns the pulse itself. For any evolved pulse, pulse.root points back to that first instance.

Example

final original = Pulse<int>(1);
final evolved = original
  .withStep('sanitized')
  .withStep('validated');

print(evolved.trace);  // ['sanitized', 'validated']
print(original.trace); // [] (The root doesn't know about future steps)

print(identical(evolved.root, original)); // true

Implementation

@override
PulseBase<P> get root {
  if (_parent == null) {
    return this;
  }

  PulseBase p = this;
  PulseBase? parent = _parent;
  while (parent != null) {
    p = parent;
    parent = p._parent;
  }
  return p as PulseBase<P>;
}
