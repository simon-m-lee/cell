Traverses the causal chain from the root ancestor to this pulse to reconstruct a historical timeline of values.

When to use

  • Value Evolution Auditing: Use this to see how a specific property (like payload or step) has changed across every hop in the graph.
  • Forensic Debugging: Identify exactly which transformation step introduced an unexpected value.
  • Explainable AI (XAI): Reconstruct the decision path of a signal through a complex reactive network.
  • State Drift Analysis: Compare the primordial root value with the current state to calculate total delta.

How it works

  1. The method starts at the current pulse and walks up the parent chain until it reaches the root.
  2. For each pulse in the chain, it extracts the requested value using the provided arg.
  3. The resulting collection is reversed to provide a chronological sequence (FIFO: First-In, First-Out).

Non‑obvious: chronological order

Unlike the manual parent traversal which is LIFO (Last-In, First-Out), lineage returns a FIFO list. The element at index 0 is always the root pulse's value.

Non‑obvious: type safety

If a pulse in the chain returns a value that does not match the requested type T, that specific hop is omitted from the results to prevent runtime type exceptions during iteration.

Example

// Trace how the payload evolved from the original input
final history = pulse.lineage<double>(Pulse.payload);
print(history); // [100.0, 115.0, 103.5]

// Trace the causal "steps" taken through the graph
final steps = pulse.lineage<String>(Pulse.step);
print(steps); // ['origin', 'tax_calc', 'discount_apply']

Parameters:

  • arg: A LineageArgument defining which property to extract from the causal chain.

Returns:

A fixed-length List<T> containing the historical values in chronological order (Primordial -> Present).
