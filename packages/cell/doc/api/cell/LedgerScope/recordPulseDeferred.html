Records a pulse whose observable settlement happens asynchronously (ingress emits whose downstream operators perform effects in detached continuations). The entry is appended one event-loop turn later — after the microtask queue settles, and with it the operator's cooperative captureEffect calls — so the entry carries the effects and deltas the pulse actually produced.

Bursts of emits that do not wait for their asynchronous work to settle share one settlement turn; their effect attribution is a A later revision's concern (pulse-tagged effect windows).

static void recordPulseDeferred({
  required Pulse pulse,
  ApplyReceipt? receipt,
  Cell? emitCell,
  Function? emitFunction,
  Object? emittedValue,
}) {
  final scope = current;
  if (scope == null) return;
  final effectiveReceipt = receipt ??
      _syntheticReceipt(
        cell: emitCell ?? (pulse.source ?? (throw ArgumentError(
              'LedgerScope.recordPulse: a synthetic receipt needs '
              'emitCell or a pulse source.',
            ))),
        function: emitFunction ?? ((Object? _) => null),
        emittedValue: emittedValue,
      );
  final cellId = effectiveReceipt.cell.id;
  scope.openWindow(
    pulse: pulse,
    receipt: effectiveReceipt,
    cellId: cellId,
  );
}
