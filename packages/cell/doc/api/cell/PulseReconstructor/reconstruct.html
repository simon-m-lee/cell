Reconstructs the input pulse for entry, or returns null if the entry cannot be reconstructed.

cell is the resolved target cell; it is used to populate the pulse's source field on the heuristic fallback path, which matters for TestPulseRule validation.

The pulse body is the primary path

Entries appended by Ledger.appendInternal now store the materialised pulse JSON (entry.pulseJson), and Ledger.verify checks it against pulseDigest. Reconstruction decodes that body with PulseCodec.fromJson — payload, type, context, priority, parent chain, and trace all round-trip. Parent pulses resolve by digest through parentsByDigest, which the engine populates as it replays earlier entries (the ledger API the codec's docs always anticipated).

Pre-8.3 entries (no body) fall back to the heuristic below: the first positional receipt argument as the payload (exact for the emit/ingress path; the apply path stores the command's argument, not the pulse the receptor saw), then the entry's own delta after. Context, priority, parent, trace, named arguments, and positional arguments beyond the first are dropped on that path.

Implementation

static Pulse<dynamic>? reconstruct({
  required LedgerEntry entry,
  required Cell cell,
  Map<String, Pulse<dynamic>>? parentsByDigest,
}) {
  final storedBody = entry.pulseJson;
  if (storedBody != null) {
    final parentDigest = storedBody['parentDigest'] as String?;
    Pulse<dynamic>? parent;
    if (parentDigest != null) {
      parent = parentsByDigest?[parentDigest];
      if (parent == null) {
        // The chain prefix this pulse evolved from was not replayed
        // (partial replay); the body cannot be decoded alone.
        return null;
      }
    }
    try {
      final decoded = PulseCodec.fromJson(storedBody, parent: parent);
      parentsByDigest?[fingerprint(storedBody)] = decoded;
      return decoded;
    } catch (_) {
      // Malformed body: verify() already validated the digest; a
      // decode failure is a format error and reads as unreconstructable.
      return null;
    }
  }

  final args = entry.receipt.arguments.positionalArguments;
  if (args != null && args.isNotEmpty) {
    return Pulse<dynamic>(
      args.first,
      source: cell,
    );
  }

  StateDelta? delta;
  final cellId = entry.receiptCellId;
  for (final d in entry.deltas) {
    if (d.cellId == cellId) {
      delta = d;
      break;
    }
  }
  delta ??= entry.deltas.isEmpty ? null : entry.deltas.last;
  if (delta == null) return null;

  return Pulse<dynamic>(
    delta.after,
    source: cell,
  );
}
