VerdictEffect

VerdictEffect class

The decision reached by an effectful TestCell.

Recorded once per rule call. On replay, the rule is not called again; the recorded decision is served. This is what makes an effectful test rule replayable without re-executing its external checks.

The inputDigest is a fingerprint of the object being tested (for a pulse, its canonical JSON; for a value, its canonical JSON). It lets ReplayJournal assert that the rule is being asked about the same input it was asked about during recording.
