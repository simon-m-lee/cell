JournalScope

JournalScope class abstract final

The task-local stack of active journals.

The stack, not a single slot, because nested operations are real: a transaction inside a recording may run a what-if branch, which pushes a ReplayJournal on top. The inner branch sees its replay journal; when it pops, the outer recording resumes.

The stack lives in a Zone — this is the only place in the design where a Zone is used, and it is used because Dart has no task-local storage primitive. Unlike a general "put the journal in the zone" pattern, the stack is drained on scope exit, so a spawned task that outlives the scope sees an empty stack and EffectJournal.current returns NullJournal. That is the correct behaviour: a leaked task has no journal, so its effects fail loudly.

The journal an effectful operator should actually use: the ambient journal when an outer scope has pushed one (the ReplayEngine pushes a per-entry ReplayJournal around the dispatch), otherwise the journal the operator captured at construction.
