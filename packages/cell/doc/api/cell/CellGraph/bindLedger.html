Future<Ledger> bindLedger({
  1. required LedgerStore store,
})

Binds this graph to a new ledger backed by store. Runs Ledger.openVerified so a corrupt store fails at bind time, not on first append.

How it works

Every subsequent Cell.apply / ValueCell.update on a cell in this graph — inside run — is recorded in the ledger. Binding is idempotent: if the graph is already bound, throws StateError — a graph cannot have two ledgers, and silently swapping would leave the old ledger permanently incomplete.

Parameters:

  • store: The persistence backend for the new ledger.

Returns:

The opened and verified ledger.

Implementation

Future<Ledger> bindLedger({required LedgerStore store}) async {
  if (_ledger != null) {
    throw StateError(
      'CellGraph.bindLedger: graph "$graphId" is already bound to a '
      'ledger. Call unbindLedger first if you intend to swap.',
    );
  }
  final ledger = await Ledger.openVerified(graph: this, store: store);
  _ledger = ledger;
  return ledger;
}
