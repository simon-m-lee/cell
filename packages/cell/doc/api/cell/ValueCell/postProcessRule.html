postProcessRule property

Instruction<Cell, Pulse, Pulse> postProcessRule
getter/setter pair

A static, reusable Instruction that commits a validated pulse to the cell's Box.

This is the "commitment stage" of the pipeline. It's used internally by ValueCell and ValueNucleus. You don't need to call it directly.
