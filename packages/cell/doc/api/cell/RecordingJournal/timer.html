Record (or replay) a timer firing. duration is the scheduled window; the journal records both the schedule and the fire time so that replay reproduces the same interleaving.

How it works

The onFire callback is invoked by the journal at the appropriate moment. On the recording side, the actual Timer is scheduled and the callback is called when it fires. On the replay side, the callback is called in journal order, not against a real timer. This is what makes debounce/throttle replayable.

Parameters:

  • duration: The scheduled window.
  • input: The timer's input; its fingerprint is recorded.
  • onFire: The callback to invoke when the timer fires.
  • fireAtEnd: Hints the ENGINE replay semantics: true for timers whose fire is an OUTPUT (a debounce trailing edge — it must run after the entry loop so the downstream write lands where the recording's did), false for timers whose fire is INTERNAL state (a throttle gate release — it must run promptly so the next entry sees the released gate). Recording ignores the hint.

Implementation

@override
Future<void> timer({
  required Duration duration,
  required Object? input,
  required FutureOr<void> Function() onFire,
  bool fireAtEnd = false,
}) async {
  final at = _clockSource();
  // Review fix: append the record BEFORE awaiting the fire callback.
  // Any effects the callback performs are nested inside the timer;
  // appending after the callback placed them BEFORE the timer record
  // in the journal, and the replay side consumes the timer record
  // first — an inversion that diverged for nested effects. The
  // recorded `firedAtMillis` therefore approximates the schedule/fire
  // moment rather than a post-fire timestamp (forensic only; replay
  // never validates it).
  _records.add(TimerEffect(
    ordinal: _nextOrdinal++,
    inputDigest: fingerprint(input),
    outputDigest: fingerprint(at.millisecondsSinceEpoch),
    at: at,
    scheduled: duration,
    scheduledAtMillis: at.millisecondsSinceEpoch,
    firedAtMillis: at.millisecondsSinceEpoch,
  ));
  await _timerScheduler(duration, onFire);
}
