LineageArgument

LineageArgument enum

Defines the specific data field to be extracted when traversing a Pulse's Causal History via the lineage method.

Lineage arguments allow the framework to reconstruct the Provenance Path of a signal, identifying how properties like security context, execution priority, or the payload itself have evolved as the pulse moved through the reactive graph.

When to use

  • Auditing: Use source or context to trace the authority behind a state change.
  • Debugging: Use payload to see how data was transformed at each node.
  • Policy Inspection: Use policy to understand why a pulse was retained or discarded.
