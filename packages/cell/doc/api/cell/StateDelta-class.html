StateDelta

StateDelta class

A single cell's state change within a ledger entry.

Captured by ValueCell.postProcessRule immediately before and after the commit, so before and after reflect the exact values the receptor produced — not the values the caller intended. That distinction matters: a receptor can transform its input, and the ledger must record the transformed value, or replay will diverge.

Non-obvious: before == after is legal

A receptor can commit the same value (e.g., an idempotent set). The delta is still recorded, because the fact that the pulse visited the cell is part of the causal chain; the absence of a value change is not the absence of an event.
