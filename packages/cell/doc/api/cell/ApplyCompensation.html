ApplyCompensation

ApplyCompensation typedef

ApplyCompensation = ({ApplyArguments arguments, Cell? cell, Function function})

A set of instructions used to undo or "roll back" a change if it fails.

ApplyCompensation is a record that holds the logic needed to reverse a specific action. It serves as a Forensic Safety Net, ensuring that every state change that happens can be safely undone if an error occurs or if a transaction is canceled.

In this framework, we treat state changes as "atomic" operations—meaning the instruction to "do" something and the instruction to "undo" it should always stay together.

Why it is used

  • Transactional Integrity: When multiple changes are grouped in a transaction, the framework uses these instructions to clean up and revert state if the transaction cannot be completed.
  • Error Recovery: If a command passes the safety gates but fails during execution, the framework can automatically trigger the compensation logic.
  • Forensic History: It provides a clear audit trail of not just what changed, but how that change was intended to be corrected.

How it works

A compensation includes three parts:

  1. function: The specific action to run to perform the reversal.
  2. arguments: The data payload (positional or named) needed for the reversal function.
  3. cell: The specific cell where the reversal should happen. If this is null, the framework targets the same cell that performed the original action.

Technical Details

  • Grouped Logic: By bundling the function, data, and target together, it prevents "orphaned" undos where the framework knows it needs to revert but doesn't have the data to do so.
  • Delayed Execution: Compensations are usually created at the same time as the command but are only executed by the framework's internal governance layer when a rollback is triggered.

See also:

  • ApplyCommand — The main request that carries this compensation.
  • ApplyArguments — The structure used to store the reversal data.
  • ApplyOutcome — The result of a command, which may trigger a rollback.
