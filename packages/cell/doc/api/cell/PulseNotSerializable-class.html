PulseNotSerializable

PulseNotSerializable class

A pulse cannot be serialised because it carries a field that has no honest wire representation.

When to use

Catch it around Pulse.toJson / encodePulse and either strip the offending field or log the rejection — never silently drop it.

How it works

field names the offending field: 'policy', 'onComplete', 'onError', 'onProgress', 'scrutinize', 'source' (empty Cell.id), 'payload', 'context', or 'user' (non-JSON-encodable value). pulse is the pulse whose field failed — for a parent chain failure it is the node that carried the field.

Non-obvious

  • Fail loudly, don't fake it. A dropped callback would silently change replay semantics; the error is the honest answer.
  • Callbacks and policies are not serialisable by construction.
