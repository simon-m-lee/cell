replayFork static method

Future<ReplayResult> replayFork({
  1. required ForkHandle fork,
  2. required Mutation mutation,
  3. ReplayOptions options = ReplayOptions.strict,
})

Replays fork.parent's entries from fork.record.divergedAt + 1 into fork.graph, applying mutation to each entry.

mutation receives the reconstructed input pulse. Returning null drops the entry (the fork's ledger will not contain it). Returning a pulse — same or different — replays that pulse into the fork's graph.

The fork's ledger is written via fork.ledger.appendInternal. This is the only path that writes a fork ledger; a fork does not accept external append calls.

Non-obvious: the fork replays from divergedAt + 1, not from

divergedAt

The fork's seq 0 is the ForkRecord. The parent's seq divergedAt is the last entry included in the fork's baseline. The first entry the fork replays is parent seq divergedAt + 1. This is what makes "fork at 100" mean "the fork's baseline is the parent's state at 100; the fork replays 101 onward".

Non-obvious: the fork serves the parent's effects

The parent's effects are in the parent ledger; the fork's entries carry them forward into the fork ledger. Each replayed entry is dispatched under a ReplayJournal built from the PARENT entry's records — the fork never re-runs effectful io against the real world, and the fork's ledger stores the same effect list the parent recorded. Consequence: a mutation that replaces a pulse whose I/O differs from the parent's will diverge instead of becoming the fork's history. What-if is defined over pulses, not effects; re-recording mutated effects (a fresh RecordingJournal + live I/O) is a later forking revision. When a mutation drops an entry, nothing is appended.

Implementation

static Future<ReplayResult> replayFork({
  required ForkHandle fork,
  required Mutation mutation,
  ReplayOptions options = ReplayOptions.strict,
}) async {
  if (!identical(fork.ledger.graph, fork.graph)) {
    throw StateError(
      'ReplayEngine.replayFork: fork.ledger.graph is not fork.graph. '
      'This is a bug in CellGraph.fork; file an issue.',
    );
  }

  final parent = fork.parent;
  final startSeq = fork.record.divergedAt + 1;

  // Hardening (review fix): never replay a corrupt history,
  // and never append onto a corrupt fork chain.
  await parent.verify();
  await fork.ledger.verify();

  final divergences = <DivergenceReport>[];
  int replayed = 0;
  int? firstDivergedAt;
  final parentsByDigest = <String, Pulse<dynamic>>{};
  final deferredFires = <FutureOr<void> Function()>[];

  await for (final entry in parent.entriesSince(startSeq)) {
    if (options.maxEntries != null && replayed >= options.maxEntries!) {
      break;
    }

    // The parent ledger's entries are the source of truth for
    // *what was recorded*; the mutation decides *what the fork
    // replays*.
    final cellId = entry.receiptCellId;
    final registered = fork.graph[cellId];
    if (registered == null) {
      final d = DivergenceReport(
        seq: entry.seq,
        expected: cellId,
        actual: '<not registered in fork>',
        reason: 'parent entry refers to cell "$cellId", which is not '
            'registered in the fork graph',
      );
      divergences.add(d);
      firstDivergedAt ??= entry.seq;
      if (options.failOnDivergence) {
        throw ReplayDivergenceException(d.reason, seq: entry.seq, report: d);
      }
      replayed++;
      continue;
    }

    final originalPulse = PulseReconstructor.reconstruct(
      entry: entry,
      cell: registered.cell,
      parentsByDigest: parentsByDigest,
    );
    if (originalPulse == null) {
      final d = DivergenceReport(
        seq: entry.seq,
        expected: '<reconstructable pulse>',
        actual: null,
        reason: 'pulse could not be reconstructed from parent entry',
      );
      divergences.add(d);
      firstDivergedAt ??= entry.seq;
      if (options.failOnDivergence) {
        throw ReplayDivergenceException(d.reason, seq: entry.seq, report: d);
      }
      replayed++;
      continue;
    }

    // Apply the mutation.
    final mutatedPulse = mutation(entry, originalPulse);
    if (mutatedPulse == null) {
      // Dropped. The fork's ledger will not contain a record of this
      // entry. That's the mutation's explicit choice.
      replayed++;
      continue;
    }

    // Replay the mutated pulse into the fork's graph, writing to the
    // fork's ledger.
    final divergence = await _replayForkOne(
      entry: entry,
      mutatedPulse: mutatedPulse,
      fork: fork,
      options: options,
      deferredFires: deferredFires,
    );

    replayed++;
    if (divergence != null) {
      divergences.add(divergence);
      firstDivergedAt ??= entry.seq;
      if (options.failOnDivergence) {
        throw ReplayDivergenceException(
          divergence.reason,
          seq: entry.seq,
          report: divergence,
        );
      }
    }
  }

  // Run the deferred timer fires after the fork's entry loop, exactly
  // like the main engine.
  for (final fire in deferredFires) {
    await fire();
  }

  return ReplayResult(
    success: divergences.isEmpty,
    entriesReplayed: replayed,
    divergedAt: firstDivergedAt,
    divergences: List.unmodifiable(divergences),
    newSnapshot: fork.graph.snapshot(
      // Tie the snapshot to the parent sequence the fork reached
      // (review fix: the default -1 made the snapshot unbound).
      lastLedgerSeq: startSeq + replayed - 1,
    ),
  );
}
