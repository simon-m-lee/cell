Creates a PersistedCell backed by adapter.

The inner cell is a RestorableCell (register it with a CellRestorationScope). A Cell.persistedState extension spelling is not reachable from another package — Dart extension statics belong to the extension, not the extended type — so the factory ships as this top-level function.
