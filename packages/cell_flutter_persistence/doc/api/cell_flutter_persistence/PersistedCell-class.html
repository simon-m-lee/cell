PersistedCell

PersistedCell<T> class

A durable, restorable state cell.

PersistedCell composes the two mechanisms Flutter offers:

  • Restoration (process kill) — the inner cell is a RestorableCell; register it with a CellRestorationScope and the value survives the OS killing the app.
  • Persistence (explicit quit) — load reads the durable value from adapter on mount, and writeMode controls when changes write back.

Usage

final counter = persistedState<int>(
  restorationId: 'counter',
  initial: 0,
  adapter: SharedPreferencesAdapter.integer(prefs),
);

// In initState:
CellRestorationScope.maybeOf(context)?.register(counter.cell);
counter.load(); // async; the cell updates when the read completes.

// Everywhere else:
counter.cell.value = 5; // restored + persisted (per writeMode)

Write cadence

WriteMode.immediate writes every change; WriteMode.debounced (default, 1s) writes after a quiet period and coalesces bursts; WriteMode.onAppPause writes when handleAppPaused is called — call it from a WidgetsBindingObserver.didChangeAppLifecycleState override for AppLifecycleState.paused.

Failure behavior

load never throws — a failing adapter read returns false and leaves the cell at its current value. persistNow surfaces adapter errors to the caller.
