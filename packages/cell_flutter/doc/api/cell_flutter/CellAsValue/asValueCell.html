asValueCell

asValueCell<V> method

MirroredCell<V> asValueCell<V>({
  1. V? initial,
})

Mirrors this cell into a fresh ValueCell and returns the paired handle.

The returned MirroredCell contains both the mirror (a ValueCell seeded from this cell's currently visible value, or from initial) and a dispose callback that must be called when the mirror is no longer needed — otherwise the backing egress leaks.

When to use

Prefer CellValueBuilder inside widgets — it manages the mirror's lifecycle automatically. Use asValueCell when the mirror must outlive a widget (for example, shared across a service layer), or when you need a synchronous, ValueCell-typed value that CellBuilder / CellSelector can consume.

How it works

  1. A fresh ValueCell is created and seeded via the same priority rules documented under Seed semantics on the extension: the retained pulse if it is a data pulse assignable to V, otherwise initial.
  2. A Cell.observe link is opened on this cell; each data pulse assigns pulse.payload to the mirror.
  3. The mirror and the egress-stop callback are packaged as a MirroredCell record.

Disposal contract

Calling the returned dispose callback is mandatory. Failure to call it leaves the egress attached to this cell, receiving (and holding) every pulse for the mirror's remaining lifetime. dispose is safe to call more than once.

Error pulses

Error pulses are silently skipped; the mirror's value stays at its last data value. To observe errors, use CellValueBuilder(emitErrors: true), CellListener, or asStream(emitErrors: true) on the source.

Technical Details

  • One egress per mirror: each call to asValueCell opens a new observation link. Two mirrors from the same source are two egresses.
  • Type erasure at observation: the link is typed Pulse<Object?> so error and type-mismatch pulses can be received; the payload is narrowed with is V / null is V inside the effect.
  • Payload type-mismatch: reported via Zone.current.handleUncaughtError with a StateError (see the extension docs for why this differs from the other bindings).

Concurrent asyncMap caveat

If the source is Cell.asyncMap with concurrency > 0, the mirror inherits the framework's caveat. The mirror's observation is correct; the caveat is about the source's replay fidelity.

Parameters:

  • initial: The Seed Fallback. Used when no retained data pulse is assignable to V on the source (the source has never emitted, the retained pulse is an error, or its payload is not a V). Defaults to null.

Returns:

A MirroredCell record: cell is the fresh ValueCell; dispose is the egress-stop callback.

Example

final source = Cell.derive<Pulse<int>, Pulse<int>>(
  source: counter.cell,
  project: (p) => Pulse((p.payload ?? 0) * 2),
);
final mirrored = source.asValueCell<int>(initial: 0);
try {
  // ... use mirrored.cell with CellBuilder ...
} finally {
  mirrored.dispose(); // required — releases the egress
}

See Also:

  • MirroredCell — the return type.
  • CellValueBuilder — the widget-layer alternative (no manual disposal).
  • CellBuilder / CellSelector — the widgets that need a ValueCell.

Implementation

MirroredCell<V> asValueCell<V>({V? initial}) {
  final mirror = ValueCell<V>(initial: seedFromRetained(this, initial));
  final egress = Cell.observe<Pulse<Object?>>(
    source: this,
    effect: (pulse) {
      if (pulse.type == 'error') return;
      final payload = pulse.payload;
      if (payload == null && null is V) {
        mirror.value = null;
      } else if (payload is V) {
        mirror.value = payload;
      } else {
        Zone.current.handleUncaughtError(
          StateError(
            'asValueCell<$V>: pulse payload is ${payload.runtimeType}, '
            'not $V.',
          ),
          StackTrace.current,
        );
      }
    },
    initiallyStarted: true,
  );
  return (cell: mirror, dispose: egress.stop);
}
