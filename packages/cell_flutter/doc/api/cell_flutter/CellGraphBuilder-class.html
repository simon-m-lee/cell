CellGraphBuilder

CellGraphBuilder class

The entry point for constructing a CellGraph.

final graph = CellGraph.builder()
  ..register('user.name', nameCell)
  ..register('user.cart', cartCell)
  ..register('user', synthesisCell)
  ..build();

When to use

As the only supported way to assemble a registered graph. The builder is stateful but single-use: after build() is called, further register calls throw. This prevents the common bug where a caller constructs a graph, then continues registering cells that will never appear in the graph, silently de-synchronising the in-memory graph from its snapshot.

How it works

Each register call claims a graph-scoped name and records the (name, cell) pair; build freezes the builder, creates the CellGraph, and validates reachability immediately.

Non-obvious: strictness modes

By default, the builder is strict: after the graph is built, every cell that receives a pulse from any registered root must itself be registered, either directly or via the bind chain. CellGraph.unrestricted() disables this for tests, and is documented as unsafe for production.

See also:

  • CellGraph — what the builder produces.
  • RegisteredCell — the wrapper each register call returns.
