CellGraphFork

CellGraphFork extension

Forking extensions for CellGraph.

When to use

Provided as an extension so cell_graph.dart does not gain a fork method — the fork diff surface keeps cell_graph.dart unchanged and puts all fork code in fork/. The trade-off is that graph.fork(...) is only available when replay.dart is imported, which is correct: fork is a replay concern, not a graph concern.

See also:

  • ForkHandle — what fork returns.
  • ForkPolicy — the policy parameter.
  • ReplayEngineFork — replays into the fork this creates.
