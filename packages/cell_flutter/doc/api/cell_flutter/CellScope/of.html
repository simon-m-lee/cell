of<V> static method

Cell of<V>(
  1. BuildContext context,
  2. Symbol id
)

Returns the cell registered at id in the nearest enclosing CellScope.

Parameters:

  • context: The Lookup Context. Must be beneath a CellScope.
  • id: The Registration Key. The Symbol used at registration.

Returns:

The registered Cell. If the registration is a ValueCell<V>, the result is narrowed to that type; plain Cell registrations are returned as-is.

Throws:

  • AssertionError in debug (or StateError in release) when there is no CellScope above context, or when no cell is registered under id. Both are programmer bugs.
  • StateError on a type mismatch: a ValueCell registered under id whose value type does not satisfy V.

See Also:

  • maybeOf — nullable variant for optional registrations.
  • valueOf — narrows the result to ValueCell<V>.

Implementation

static Cell of<V>(BuildContext context, Symbol id) {
  final cell = _lookup(context, id);
  if (cell is ValueCell && cell is! ValueCell<V>) {
    throw StateError(
      'CellScope.of<$V>($id): registered cell is ${cell.runtimeType}, '
      'which is not a ValueCell<$V>.',
    );
  }
  return cell;
}
