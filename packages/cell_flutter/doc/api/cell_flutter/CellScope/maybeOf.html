maybeOf<V> static method

Cell? maybeOf<V>(
  1. BuildContext context,
  2. Symbol id
)

Like of, but returns null when id is not registered (or no CellScope encloses context).

maybeOf does not swallow type mismatches. A missing scope or unknown id is treated as an absence, not a bug; a type mismatch on a ValueCell registration still throws StateError — that is a caller bug, not an absence. Use this only when absence is a valid test outcome.

Parameters:

  • context: The Lookup Context.
  • id: The Registration Key.

Returns:

The registered Cell, or null if there is no CellScope above context or no cell is registered under id.

Throws:

StateError on a type mismatch.

See Also:

  • of — non-nullable variant that treats absence as a bug.
  • valueOf — narrows the result to ValueCell<V>.

Implementation

static Cell? maybeOf<V>(BuildContext context, Symbol id) {
  final scope = context.dependOnInheritedWidgetOfExactType<CellScope>();
  if (scope == null) return null;
  final cell = scope.cells[id];
  if (cell == null) return null;
  if (cell is ValueCell && cell is! ValueCell<V>) {
    throw StateError(
      'CellScope.maybeOf<$V>($id): registered cell is '
      '${cell.runtimeType}, which is not a ValueCell<$V>.',
    );
  }
  return cell;
}
