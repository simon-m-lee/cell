Object? canonicalJsonDecode(
  1. String source

Decodes a canonical JSON string into a JSON-encodable object tree.

When to use

As the matched pair of canonicalJsonEncode. Using this instead of jsonDecode directly keeps the (encode, decode) helpers uniform and prevents accidentally mixing jsonEncode with canonicalJsonEncode.

Returns:

The decoded object tree (Map, List, String, num, bool, or null).

Implementation

Object? canonicalJsonDecode(String source) => jsonDecode(source);
