ReplayEngineFork

ReplayEngineFork extension

Fork-aware replay: replays a parent ledger into a fork handle, applying a Mutation to each entry.

When to use

As the fork engine's core addition to ReplayEngine. It shares the engine's reconstruction machinery but:

  • Applies the mutation before dispatch: mutation(entry, pulse) can drop the entry (null) or replace the pulse (Pulse).
  • Writes to the fork ledger, not the parent: each replayed entry (whether original or replaced) is appended to fork.ledger, so the fork has its own history.
  • Does not verify against the parent's deltas — the fork is expected to diverge; its own ledger records what it actually did.

See also:

  • CellGraphFork.fork — creates the fork handle this replays into.
  • Mutation — the hook this extension applies per entry.
