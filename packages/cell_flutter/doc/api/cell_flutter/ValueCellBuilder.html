ValueCellBuilder

ValueCellBuilder<V> extension

Fluent constructor for a CellBuilder over a ValueCell.

ValueCellBuilder is the binding's Widget-Layer Sugar: a one-line shortcut that turns any ValueCell into a self-rebuilding widget without importing CellBuilder at the call site. It produces a standard CellBuilder — same semantics, same rebuild granularity, same debug-mode anti-pattern warning — with key forwarded.

Why it is used

  • Readability: counter.cell.builder((ctx, v) => Text('$v')) reads as a fluent sentence in composition-heavy trees, and avoids a fully-qualified CellBuilder<int>(...) in every leaf.
  • Zero cost: this is an extension; it adds no memory to ValueCell instances and produces a normal CellBuilder at runtime.

Technical Details

  • Extension, not a wrapper: the returned widget is a plain CellBuilder; there is no subclass and no indirection.
  • Key forwarding: key is passed through to the CellBuilder constructor, so the usual Flutter key semantics apply.

See Also:

  • CellBuilder — the widget this extension constructs.
  • CellValueBuilder — the equivalent for non-ValueCell sources (which does not have a .builder() extension).
