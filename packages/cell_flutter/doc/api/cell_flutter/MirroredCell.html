MirroredCell

MirroredCell<V> typedef

MirroredCell<V> = ({ValueCell<V> cell, void Function() dispose})

The paired result of CellAsValue.asValueCell: a mirror cell and the callback that releases it.

MirroredCell is the binding's Mirror Handle. It packages a fresh ValueCell (the "mirror") with the dispose callback that stops the egress backing it. The pairing is deliberate: mirroring a cell opens a Cell.observe link, and that link is not closed automatically. The handle makes the lifecycle obligation impossible to miss — you cannot obtain a mirror without also receiving the way to tear it down.

Why it is used

  • Explicit lifetime: a plain ValueCell<V> return would hide the EgressHandle. The caller would have no handle to stop mirroring, and the egress would leak when the mirror outlives the source or is created in a build.
  • Record shape, zero boilerplate: Dart record destructuring gives you final (:cell, :dispose) = source.asValueCell<int>(); for free — no class, no allocation overhead beyond the mirror itself.
  • Non-optional contract: because dispose is a required member of the record, callers cannot accidentally discard it the way they could ignore a returned EgressHandle.

Contract

  • dispose must be called when the mirror is no longer needed. Failing to do so leaves the underlying Cell.observe link open: the mirror continues to receive pulses (and hold them in its box) for as long as the source lives, and the observation is never reclaimed.
  • dispose is idempotent with respect to the egress it stops: EgressHandle.stop is safe to call more than once.
  • The mirror outlives nothing else — it does not need to be invalidated separately. Once dispose has been called the mirror simply stops updating; it does not become invalidated and its current value remains readable.

Parameters (record fields)

  • cell: The Mirror. A fresh ValueCell that is seeded from the source's current value (see CellAsValue.asValueCell) and updated on every subsequent pulse from the source.
  • dispose: The Release Callback. Stops the egress that keeps the mirror in sync with the source. Call exactly once when the mirror is no longer needed; safe to call more than once.

See Also:

  • CellAsValue.asValueCell — the method that produces this handle.
  • CellValueBuilder — the widget-layer alternative that Flutter's own state lifecycle manages.
  • EgressHandle — the underlying primitive dispose wraps.
