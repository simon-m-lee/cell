RestorableCell

RestorableCell<V> class

A ValueCell whose value participates in Flutter's state restoration.

RestorableCell is the Restorable State Atom: it behaves exactly like any other ValueCell — observers subscribe through the reactive graph, writes flow through the cell's integrity gates — while its value is additionally serialized into a RestorationBucket when the cell is registered with a CellRestorationScope. On a later restore (process kill, hot restart, backgrounding) the persisted value is written back into the cell before the first frame that depends on it is built, so the app renders the restored state instead of initial.

How it works

  1. Construction stores initial and the optional codecs; the cell is otherwise a plain ValueCell (super(initial: initial)).
  2. CellRestorationScopeState.register wraps the cell in an internal RestorableProperty delegate and registers that with Flutter's RestorationMixin. The delegate restores the cell from the bucket (via fromPrimitives) when persisted data exists, or initializes it to initial otherwise.
  3. Every write through value notifies the delegate, which pushes the serialized value (via toPrimitives) into the bucket.

Serialization contract

By default only bool, int, double, String, and null values can be persisted — the types Flutter's StandardMessageCodec supports without ambiguity. Any other V throws UnsupportedError when the delegate first serializes it; pass a toPrimitives / fromPrimitives pair to persist custom types (see the example).

Lifecycle

The cell itself has no dispose — like every ValueCell, its invalidation is the caller's responsibility. The restoration delegate (and its internal observation) is released when the cell is unregistered from its scope or the scope is disposed.

Example

// In a StatefulWidget beneath a CellRestorationScope:
late final RestorableCell<int> counter;

@override
void initState() {
  super.initState();
  counter = restorableState<int>(
    restorationId: 'counter',
    initial: 0,
  );
  CellRestorationScope.maybeOf(context)?.register(counter);
}
