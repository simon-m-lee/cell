Record (or replay) a single EphemeralPolicy tick.

How it works

On the recording side, a PolicyTickEffect is written. On the replay side, the recorded tick is consumed and validated; the caller then re-applies it to the CycleChecker (the cycle-checker reseed).

Parameters:

  • policyLabel: A stable label for the policy.
  • cellId: The cell on which the policy ticked.
  • input: The tick's input; its fingerprint is recorded.

Implementation

@override
void policyTick({
  required String policyLabel,
  required String cellId,
  required Object? input,
}) {
  final before = _journal.records.length;
  _journal.policyTick(
    policyLabel: policyLabel,
    cellId: cellId,
    input: input,
  );
  _captureSince(before);
}
