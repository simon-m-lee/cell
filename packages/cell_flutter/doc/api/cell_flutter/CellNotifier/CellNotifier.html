Subscribes to cell and seeds the notifier with its current value.

Parameters:

  • cell: The Observed Cell. The ValueCell whose value this notifier mirrors. Held by reference for the lifetime of the notifier; callers may read notifier.cell to reach the source.

Throws:

ArgumentError if cell is invalidated. Subscribing to a dead cell would produce a notifier that never fires — a latent bug, not a recoverable state.

See Also:

  • dispose — releases the egress and the underlying ValueNotifier.

Implementation

CellNotifier(this.cell) : super(_initialValue(cell)) {
  _egress = Cell.observe<Pulse<V>>(
    source: cell,
    effect: _onPulse,
    initiallyStarted: true,
  );
}
