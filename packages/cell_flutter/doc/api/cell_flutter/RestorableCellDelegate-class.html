RestorableCellDelegate

RestorableCellDelegate<V> class

The internal RestorableProperty that bridges a RestorableCell to Flutter's restoration protocol.

The delegate exists because RestorableProperty extends ChangeNotifier and owns the registration/unregistration protocol (_owner?._unregister on dispose) — implementing that interface directly on the cell would force the cell to duplicate Flutter's bookkeeping. The delegate instead:

  1. Observes the cell through a CellNotifier and re-notifies Flutter's RestorationMixin whenever the cell's value changes.
  2. Implements createDefaultValue / fromPrimitives / toPrimitives / initWithValue by delegating to the cell's codecs and value.
  3. Releases its observation on dispose before handing off to RestorableProperty.dispose, which unregisters from the owner.
