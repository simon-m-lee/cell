CellTextField

CellTextField class

A TextFormField whose value is bound two-way to a ValueCell<String>.

CellTextField is the Cell-Bound Text Field — the one-line answer to "bind a text field to a cell": typing updates the cell, cell updates re-render the field, and the enclosing Form's validation works unchanged because the widget is a TextFormField underneath.

How it works

  1. A CellEditingController binds the field's text to cell with the equality-guarded two-way sync (typing → cell; cell → field with cursor preservation).
  2. validator and autovalidateMode are forwarded to the inner TextFormField, so Form.validate() reports this field's errors through the standard FormFieldState mechanism.
  3. A cell swap in didUpdateWidget rebinds the controller; the field keeps focus because the controller is replaced, not the element.

Focus and cursor

Focus is preserved across cell updates (the controller is never disposed on update). The cursor's offset from the end is preserved on cell-driven updates; see CellEditingController for the exact rule.

Example

CellTextField(
  cell: email.cell,
  decoration: const InputDecoration(labelText: 'Email'),
  validator: (v) => v?.contains('@') == true ? null : 'Invalid email',
);
