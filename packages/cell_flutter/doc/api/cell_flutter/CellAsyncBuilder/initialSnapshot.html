initialSnapshot property

AsyncSnapshot<V>? initialSnapshot
final

Optional initial snapshot. Defaults to AsyncSnapshot<V>.nothing().

Two use cases:

  1. Cache hydration — pass AsyncSnapshot.withData(ConnectionState.active, cached) to render the cached value before the first pulse arrives.
  2. Seed override — the default seed path already replays the retained pulse of any state-like operator (fromFuture, fromStream, asyncMap, derive) and ValueCell. Pass a snapshot here only to replace that seed with a value the caller holds.

When initialSnapshot is null, the widget seeds from snapshotForCell, which serves the cell's retained pulse when one exists and returns null otherwise.
