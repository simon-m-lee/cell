FutureOr<DeputyContext> translate(

Translates source from fromVersion to toVersion. Returns a context whose version equals toVersion.

How it works

The translator is responsible for preserving the meaning of the source context — a Clearance.administrative source must not silently become Clearance.observational (that would weaken the mandate's authority); a new field added in the target version must be given a sensible default documented in the translator's toString.

Parameters:

  • source: The context to translate.

Returns:

The translated context (or a Future of it).
