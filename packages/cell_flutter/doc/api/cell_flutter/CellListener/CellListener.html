Creates a listener over cell that invokes onPulse for every pulse.

child is passed through unchanged and is not rebuilt when cell emits. If the child needs to react visually, compose a CellBuilder inside it rather than expecting CellListener to rebuild.

Parameters:

  • cell: The Observed Cell. Any Cell. Held by reference.
  • onPulse: The Side-Effect Handler. Invoked once per pulse, on this widget's BuildContext.
  • child: The Stable Subtree. Displayed unchanged across pulses.

Throws:

ArgumentError at first build if cell is invalidated. See _CellListenerState._bind.
