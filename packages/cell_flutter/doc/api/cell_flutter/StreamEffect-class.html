StreamEffect

StreamEffect class

A stream event. Records the event's stream label, the digest of the value, and optionally the raw value.

Non-obvious: codec-only today

No journal operation produces or consumes StreamEffect yet — the journalled operators record stream events as IoEffects. The type exists so the schema is stable for a later dedicated stream journaling (per-event sequence tags).
