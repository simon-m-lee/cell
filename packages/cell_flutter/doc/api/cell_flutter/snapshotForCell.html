snapshotForCell<V> function

AsyncSnapshot<V>? snapshotForCell<V>(
  1. Cell cell
)

Returns the AsyncSnapshot the widget should show for cell's currently retained pulse, or null when nothing usable is retained.

snapshotForCell is the Late-Subscriber Seed used by CellAsyncBuilder. When a widget subscribes to a cell that already emitted — a completed Cell.fromFuture, a Cell.derive that produced a value — the widget should render that value on its first frame instead of flickering through nothing() first. This function provides the seed.

How it works

  1. It calls retainedPulseOf on cell.
  2. If the result is null, it returns null — the widget falls back to AsyncSnapshot<V>.nothing().
  3. Otherwise it delegates to snapshotForPulse and returns the snapshot.

Seed semantics (please read)

retainedPulseOf reads the core package's retained pulse via Cell.latestPulse, so the common use cases this widget was built for — Cell.fromFuture, Cell.fromStream, Cell.asyncMap, Cell.derive — do seed through this function once they have emitted: a completed fromFuture renders its data on the first frame instead of nothing(). A cell that has never emitted returns null and the widget falls back to AsyncSnapshot<V>.nothing(). If the caller wants to override the seed, pass CellAsyncBuilder.initialSnapshot as an AsyncSnapshot. The behavior is defined by retainedPulseOf; see test/seed_paths_test.dart for the coverage.

Technical Details

  • No subscription: this function does not open an egress. It reads only what the binding can already see synchronously.
  • Pulse-shape fidelity: any error in the retained slot is surfaced as an error snapshot (via snapshotForPulse) rather than as data.

See also:

  • snapshotForPulse — the decoder this function delegates to.
  • retainedPulseOf — the retained-value probe.
  • test/seed_paths_test.dart — the seed-behavior coverage.
  • CellAsyncBuilder.initialSnapshot — the explicit override.

Implementation

AsyncSnapshot<V>? snapshotForCell<V>(Cell cell) {
  final latest = retainedPulseOf(cell);
  if (latest == null) return null;
  return snapshotForPulse<V>(latest);
}
