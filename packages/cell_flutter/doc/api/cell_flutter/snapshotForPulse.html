Projects a single Pulse into an AsyncSnapshot for a CellAsyncBuilder.

snapshotForPulse is the binding's Pulse-to-Snapshot Decoder — the one place where cell-level pulse types are translated into Flutter's AsyncSnapshot contract. Every rendering decision in CellAsyncBuilder flows through this function, which keeps the widget state class small and makes the mapping testable in isolation.

Why it is used

  • Single source of truth: error pulses, null data, and type-mismatched payloads are all decoded here, not scattered through the widget's state machine.
  • Testability: it is a pure function; unit tests can assert every pulse shape without pumping a widget.

How it works

pulse.type Payload Snapshot produced
'error' any non-null withError(active, payload, now)
'error' null withError(active, StateError('…'), now)
data null, null is V withData(active, null)
data is V withData(active, payload)
data not V withError(active, StateError('…'), now)

The result is always ConnectionState.active: no core operator ever emits a completion pulse, so ConnectionState.done is never produced here (see CellAsyncBuilder class docs).

Technical Details

  • StackTrace.current used for error snapshots: AsyncSnapshot requires a stack trace on error; a fresh one is synthesized at decode time because the pulse does not carry one.
  • Null-aware V: distinguishes "V admits null" (null is V) from "V does not admit null" so CellAsyncBuilder<int?> and CellAsyncBuilder<int> behave correctly.
  • No state, no allocation beyond the returned snapshot.

See also:

  • snapshotForCell — the retained-value seed used by CellAsyncBuilder.
  • CellAsyncBuilder — the widget that calls this function per pulse.

Implementation

AsyncSnapshot<V> snapshotForPulse<V>(Pulse<Object?> pulse) {
  final type = pulse.type;
  final payload = pulse.payload;
  if (type == 'error') {
    return AsyncSnapshot<V>.withError(
      ConnectionState.active,
      payload ?? StateError('Pulse of type "error" with null payload'),
      StackTrace.current,
    );
  }
  if (payload == null && null is V) {
    return AsyncSnapshot<V>.withData(ConnectionState.active, null as V);
  }
  if (payload is V) {
    return AsyncSnapshot<V>.withData(ConnectionState.active, payload);
  }
  return AsyncSnapshot<V>.withError(
    ConnectionState.active,
    StateError(
      'CellAsyncBuilder<$V>: pulse payload is ${payload.runtimeType}, not $V.',
    ),
    StackTrace.current,
  );
}
