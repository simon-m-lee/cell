PulseRecorder<T> recordPulses()

Records every pulse emitted by this cell.

Returns a PulseRecorder whose PulseRecorder.pulses and PulseRecorder.payloads getters expose the recorded sequence. Call PulseRecorder.stop (or addTearDown(recorder.stop)) to release the egress; the recorder pins the source cell until stopped.

Returns:

A PulseRecorder over this cell, already subscribed and recording.

See Also:

  • PulseRecorder — the returned type.
  • CellRecordPulses — the extension-level docs, including the error-pulse behavior and cleanup contract.
