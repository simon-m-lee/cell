Pumps a bare CellBuilder over cell inside a default MaterialApp + Scaffold frame.

No CellScope is installed; widgets under test that require one should be pumped via CellPumpWithCells.pumpWithCells instead.

Parameters:

  • cell: The Rendered Cell. Must be a ValueCell because CellBuilder requires a synchronous current value. Use asValueCell or CellValueBuilder for plain-Cell sources.
  • builder: The Render Callback. Called on initial build and whenever cell emits a new value. Same contract as CellBuilder.builder — receives V?.

Returns:

The Future from WidgetTester.pumpWidget — resolves once the first frame has been built.

See Also:

  • CellPumpCell — the extension-level docs, including the rationale for omitting a CellScope.
  • CellPumpWithCells.pumpWithCells — the scoped-lookup variant.
