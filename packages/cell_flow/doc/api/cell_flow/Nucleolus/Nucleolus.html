Nucleolus constructor

const Nucleolus()

The default constant constructor for Nucleolus.

This constructor creates a canonical, immutable instance of the framework's "zero-state" nucleus. Because Nucleolus is defined as a const class, this constructor is primarily used by the Nucleus.empty factory to provide a singleton-like, memory-efficient root for all cell property hierarchies.

Efficiency:

Using const Nucleolus() ensures that no unique heap allocation occurs for the nucleus of a standard cell. All cells using the default configuration point to the same transitively immutable instance in the data segment.
