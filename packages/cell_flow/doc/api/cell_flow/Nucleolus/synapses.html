synapses property

  1. @override
Synapses<Pulse, Cell> get synapses
override

The connectivity manager responsible for tracking and notifying downstream observers of this Cell.

When to use

You can inspect this to see what observers are linked, but you normally use Synapses.link/Synapses.unlink to modify it.

How it works

Returns the Synapses instance that manages the observer registry. If synapses are disabled, returns Synapses.disabled.

Implementation

@override
