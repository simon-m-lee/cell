GovernanceMixin

GovernanceMixin<G extends Governance<V>, V> mixin

A convenient mixin that provides default implementations for the Governance interface methods.

GovernanceMixin simplifies the creation of custom governance enums by providing ready-to-use implementations of isType and entry. This reduces boilerplate and ensures consistent behavior across all governance dimensions.

Type Parameters

  • G: The specific Governance type (must be an enum).
  • V: The value type for this governance dimension.

See also:

  • Governance: The interface that defines governance dimensions.
  • Ontology: The structural governance enum.
  • Provenance: The causal governance enum.
  • Mandate: The delegation governance enum.
