ForkVerify

ForkVerify extension

Fork-aware verification. A fork's verify requires the parent ledger's verify() to pass.

How it works

The verification steps are:

  1. Parent ledger verification: the parent must be intact. A fork from a corrupt ledger is a fork from a lie.
  2. Fork chain verification: the fork's own chain (from ForkRecord.genesisHash onward) must be intact.
  3. Genesis binding verification: the ForkRecord.parentHeadHash must match the parent's hash at divergedAt. This is what makes the fork a fork — a fork record whose parentHeadHash does not match the parent's actual hash is either stale or forged.

See also:

  • ForkHandle — the handle this extension verifies.
  • ForkIntegrityException — what a failed verification throws.
