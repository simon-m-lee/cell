StateDelta

StateDelta class

A single cell's state change within a ledger entry.

StateDelta is the Atomic Record of Change: the smallest unit of forensic history the ledger stores. It captures one cell's value before and after a commit, together with the wall-clock time of the commit, so an auditor can trace every state transition.

Captured by ValueCell.postProcessRule immediately before and after the commit, so before and after reflect the exact values the receptor produced — not the values the caller intended. That distinction matters: a receptor can transform its input, and the ledger must record the transformed value, or replay will diverge.

Why it is used

  • Replay Fidelity: Replay must reproduce the exact value the receptor committed, not the caller's intent, or the reconstructed graph diverges from the original.
  • Causal Traceability: The delta ties a value change to a cell id and a timestamp, so the ledger's causal chain is queryable.
  • Tamper Evidence: Each delta's digest is folded into the entry hash, so altering a stored value breaks the chain.

How it works

  1. ValueCell.postProcessRule observes (before, after) around the commit.
  2. It constructs a StateDelta and hands it to the active LedgerScope.captureDelta.
  3. The scope bundles the deltas with the pulse's receipt and effects into a LedgerEntry, whose hash chain binds them permanently.

Technical Details

  • Non-obvious: before == after is legal. A receptor can commit the same value (e.g., an idempotent set). The delta is still recorded, because the fact that the pulse visited the cell is part of the causal chain; the absence of a value change is not the absence of an event.
  • Forensic only timestamp. Replay does not compare at — a wall-clock time cannot be reproduced — it is recorded for auditors, not for replay equality.
  • Null vs missing key. toJson drops null before/after keys, so a digest cannot distinguish "the value was null" from "the key was dropped". This is deliberate: an explicit null marker would change every stored delta digest and invalidate existing ledgers; the hash chain is what makes tampering loud.

See also:

  • LedgerEntry — the row that carries this delta.
  • LedgerScope — the ambient that captures deltas during a commit.
