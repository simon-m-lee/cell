ReplayResult

ReplayResult class

The result of a ReplayEngine.replay call.

How it works

A successful replay has success == true and divergences == []. A lenient replay (with failOnDivergence: false) can have success == false and a non-empty divergences list, while entriesReplayed == entries.length — the replay ran to completion but every entry did not match. A strict replay throws ReplayDivergenceException on the first divergence; the ReplayResult is only returned for successful replays.

Non-obvious: newSnapshot is the state at the end of replay

Not at the divergence point. A caller that wants a snapshot at a specific sequence should use ReplayEngine.replay with options.maxEntries: seq + 1. This is deliberate: reconstructing a snapshot at every step is expensive; the caller knows which step they care about, and the maxEntries option gives them a cheap way to get there.

See also:

  • ReplayEngine.replay — produces this result.
  • DivergenceReport — the per-divergence entries of divergences.
