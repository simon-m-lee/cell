CellGraphSnapshot

CellGraphSnapshot class

A serialisable snapshot of an entire cell graph.

When to use

As one of the two persistence units of the replay module: a snapshot is the state at a point in time, a Ledger is the history that produced it. Both are needed for replay — ReplayEngine replays the ledger from a snapshot's lastLedgerSeq.

How it works

The snapshot carries the graph's graphId, a schemaVersion that gates forward compatibility, the ledger position the snapshot was taken at, the optional parentLedgerHash of the ledger up to that position, and one CellSnapshot per cell (sorted by id). toJson/fromJson round-trip the record; currentSchemaVersion is the version this codec writes.

See also:

  • CellSnapshot — the per-cell atom of this snapshot.
  • Ledger — the history this snapshot anchors.
