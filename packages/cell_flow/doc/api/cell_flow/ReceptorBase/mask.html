Creates a mask record for the receptor configuration.

Always stores a stable named-record shape so optional pipeline fields can be read as null without throwing NoSuchMethodError on missing getters (which happens with sparse/() flyweight records under a debugger that breaks on caught exceptions).

Parameters:

  • instruction: The core transformation instruction.
  • preProcess: Sanitization stage.
  • postProcess: Commitment stage.
  • reaction: Simplified reaction function.
  • user: User metadata factory.
  • init: Initialization function.

Returns:

A record with a fixed set of named fields (instruction, init, user, userBox). Nested instruction always exposes instruction, preProcess, postProcess, and reaction.

Implementation

static Record mask({
  Instruction? instruction,
  Instruction? preProcess,
  Instruction? postProcess,
  Function? reaction,
  Function? user,
  Function? init
}) {

  final userBox = user != null ? (FinalBox()..value = user()) : null;

  // Always return a named-record shape, even when no stages are configured.
  // An empty record () would make getters like _record.instruction throw
  // NoSuchMethodError; that error is swallowed by get(..., orElse: null)
  // but remains noisy under debuggers that break on all exceptions.
  // Commonly triggered by Cell.ingress combined with operators that
  // construct an empty _Receptor() (e.g. Flow.bufferTime).
  return (
    instruction: (
      instruction: instruction,
      preProcess: preProcess,
      postProcess: postProcess,
      reaction: reaction,
    ),
    init: init,
    user: user,
    userBox: userBox,
  );
}
