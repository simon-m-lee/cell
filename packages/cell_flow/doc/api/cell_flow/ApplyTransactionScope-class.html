ApplyTransactionScope

ApplyTransactionScope class abstract

Handle for a staged command transaction — the mechanism behind Cell.txApply.

When to use

Use txApply when you need to execute multiple Cell.apply commands atomically, with the ability to compensate already-executed commands if a later command fails. This is the Saga-style counterpart to Cell.transaction (which buffers value updates and provides isolation levels).

How it works

  1. begin registers participant cells.
  2. Commands are staged via enqueueCommand (indirectly, through Cell.apply(command, tx: scope)).
  3. commit validates each command's whitelist status, then executes them sequentially. On any failure, executed commands are compensated in reverse order.
  4. rollback discards the staging buffer, optionally compensating already-executed commands. With a savepoint, only commands after the savepoint are affected and the scope remains active.
