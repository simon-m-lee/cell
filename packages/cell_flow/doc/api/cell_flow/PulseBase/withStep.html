Appends a diagnostic stage to the pulse's causal trace without branching the causal chain.

Use this method to document the logical path a signal takes as it flows through the cell graph. Unlike evolve, this method does not create a parent-child relationship; it simply records milestones within the current signal's lineage.

When to use

  • Diagnostic Auditing: Use this to mark significant milestones in a pulse's journey (e.g., 'sanitized', 'validated', 'serialized').
  • Breadcrumb Generation: Building a historical trail that describes how a value reached its current state without creating a new evolved signal.
  • Performance Tracing: Marking timestamps or stages to analyze propagation latency across different cells.

How it works

This method updates the internal trace log. Unlike evolve, which creates a new EvolvedPulse instance to represent a transition to a new stage or context, withStep simply lengthens the lineage of the current pulse. It preserves the same identity, context, and payload.

Non‑obvious: It is not an Evolution

Calling withStep does not trigger a causal branch. Because it does not create an EvolvedPulse, the pulse's structure remains flat. This means:

  • isComposite remains false.
  • length remains 1.
  • Iterating over the pulse yields only the pulse itself.

Non‑obvious: Traces are forward‑looking

Causal tracking is inherently backwards-looking. Because withStep lengthens the lineage of the specific pulse instance without creating a new causal node, the root pulse remains oblivious to these steps. Calling root.trace will not show steps added via withStep on its descendants. To see the full story, you must inspect the trace of the final pulse in the chain.

Parameters:

  • step: A descriptive string identifying the processing stage completed.

Returns:

The Pulse instance with the updated causal trace.

Example

final root = Pulse<int>(10);
final processed = root.withStep('sanitized').withStep('validated');

print(processed.trace);  // ['sanitized', 'validated']
print(root.trace);       // [] (root doesn't know about future steps)
print(processed.length); // 1 (lineage lengthened, not evolved)
