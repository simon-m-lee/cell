TimerEffect

TimerEffect class

A timer firing. Records the scheduled duration and the actual fire time; the pair is what makes debounce/throttle replayable.

at → DateTime
Wall-clock time of the observation. Recorded because replay needs to reconstruct ordering; not part of the semantics of the effect.

cancelled ↔ bool
Whether the recorded timer was cancelled before it fired (review fix). The recording side marks this when a debounce/throttle timer is superseded; replay consumes the record but must NOT invoke the fire callback — otherwise a cancelled timer fires during replay and the graph diverges from its own recording.
