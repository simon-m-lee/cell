CellSnapshot

CellSnapshot class

A serialisable projection of one cell's identity and current value.

When to use

As the atom of CellGraphSnapshot: one CellSnapshot per registered cell. Its configFingerprint is the SHA-256 of the cell's receptor name + version, its test rule, and its context — the three things that determine whether a replay of the same pulse sequence will produce the same result.

How it works

The snapshot stores the graph-scoped id, the configFingerprint, the receptor's version string, the current value (JSON-encoded), and any extras carried from the nucleus. toJson/fromJson round-trip the record unchanged.

See also:

  • CellGraphSnapshot — the container that holds one snapshot per cell.
