hopLimit

hopLimit property

int? get hopLimit

The maximum number of node transitions (hops) permitted.

When to use

Use this to limit propagation depth – e.g., prevent a broadcast from traversing more than a certain number of nodes.

How it works

Each call to onEvent can increment the hop counter (or not). When the counter reaches or exceeds this limit, the pulse is invalidated.

Non‑obvious

  • The hop counter starts at 0 and is updated by onEvent.
  • You can reset the counter by returning (hops: 0) from onEvent.

Returns:

The maximum allowed hop count, or null if no hop limit.

Implementation

int? get hopLimit {
  return get<int?>(() => _record.hopLimit, orElse: null);
}
