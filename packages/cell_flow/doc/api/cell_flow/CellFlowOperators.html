CellFlowOperators

CellFlowOperators extension

Fluent wrappers around the authoritative Flow static factories.

Instead of nesting:

Flow.map<int, String>(
  Flow.filter<int>(source, test: (n) => n > 0).cell,
  project: (n) => '$n',
);

chain:

source
    .filter<int>(test: (n) => n > 0)
    .map<int, String>(project: (n) => '$n');

CellFlowOperators starts a pipeline from a Cell. FlowOperators continues from a FlowHandle using its .cell. Each method delegates to the matching Flow factory — behaviour stays in one place.
