Opens a deferred pulse window: the append runs one event-loop turn later, once the microtask queue (and with it the pulse's asynchronous effect continuations) has settled.

Review fix: the DELTAS are snapshotted-and-cleared now — they were captured synchronously while this pulse's receptor ran, and a second window opened before either microtask used to steal them (both windows shared one _pending bag). Effects stay shared for one turn by design (burst attribution is the documented deferred limitation), but the ambient-journal watermark advances at close so a later immediate recordPulse cannot re-sweep the same records onto its entry.

Implementation

void openWindow({
  required Pulse pulse,
  required ApplyReceipt receipt,
  required String cellId,
}) {
  final deltas = List<StateDelta>.from(_pending);
  _pending.clear();
  final done = Future<void>.delayed(Duration.zero).then((_) {
    // Still current scope? The zone captured at scheduling keeps
    // `LedgerScope.current` resolving here even after the enclosing
    // run's body returned (drain waits for this window).
    final effects = List<EffectRecord>.of(_pendingEffects);
    _pendingEffects.clear();
    // The captured effects are attributed to THIS window's entry;
    // advance the watermark past them so the next immediate append's
    // recordsSince sweep does not attach them again.
    _journalWatermark = _journal.consumed;
    unawaited(recordAndAppend(
      pulse: pulse,
      receipt: receipt,
      cellId: cellId,
      effects: effects,
      deltas: deltas,
    ));
  });
  _windows.add(done);
  done.whenComplete(() => _windows.remove(done));
}
