postProcessRule property

Instruction<Cell, Pulse, Pulse> postProcessRule
getter/setter pair

A static, reusable Instruction that commits a validated pulse to the cell's Box.

This is the "commitment stage" of the pipeline. It's used internally by ValueCell and ValueNucleus. You don't need to call it directly.

Implementation

static Instruction postProcessRule =
    Instruction<ValueCell, Pulse, Pulse>((pulse, {cell, user}) {
  final scope = LedgerScope.current;
  if (scope == null) {
    cell!._nucleus.state.value = pulse.payload;
    return pulse;
  }

  // Capture the delta if a ledger is bound. The encoding
  // happens BEFORE the commit: a non-JSON-encodable payload must
  // never reach the state box. The entry points (_emit/apply) already
  // validate the common path loudly at the caller's call site; this
  // pre-commit check closes the residual path where a transform
  // produces a non-encodable payload (the pipeline's error contract
  // swallows a throw here, so the write is simply dropped instead of
  // committed-and-silently-unrecorded).
  final before = cell!._nucleus.state.value;
  final Object? encodedBefore;
  final Object? encodedAfter;
  try {
    encodedBefore = _encodeForLedger(before);
    encodedAfter = _encodeForLedger(pulse.payload);
  } catch (e, st) {
    // Hardening (review fix): the pipeline's error contract
    // swallows a throw here, which used to mean "write silently
    // dropped and unrecorded" with no observable signal at all. Fail
    // the pulse instead — the drop is now visible on the pulse's
    // onError channel, and the ledger's deferred window still records
    // the pulse (with its empty deltas) so the failure is part of the
    // history rather than a hole in it.
    (pulse as PulseBase)._fail(e, stackTrace: st);
    return pulse;
  }
  cell._nucleus.state.value = pulse.payload;
  scope.captureDelta(StateDelta(
    cellId: cell.id,
    before: encodedBefore,
    after: encodedAfter,
    at: DateTime.now(),
  ));
  return pulse;
});
