API Chooser — cell_flow operators

Layer: Flow. Owns: riskOf / operators / latch / product filter / chain assembly / toHandle. Does not own: ingress, observe, Transaction, or any Tissue write. See HowTo-Mitose-Flow.md §1.

Read this file when: a BRD sentence asks "wait", "rate-limit", "cancel", "parallel", "batch", or "combine multiple sources."

The full decision procedure lives in HowTo-Mitose-Flow.md; this matrix is generated from the ### AI Agent Guide blocks and cannot drift.
