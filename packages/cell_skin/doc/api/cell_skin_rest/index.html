cell_skin_rest library Features

The REST binding entry point.

RestAdapter imports dart:io, so it is exported from this library rather than from the main cell_skin.dart barrel — web and Flutter-web consumers of the wire, the membrane, or the in-process client must be able to compile without an io dependency.

import 'package:cell_skin/cell_skin.dart';
import 'package:cell_skin/cell_skin_rest.dart';

final adapter = await RestAdapter.bind(
  membrane: membrane,
  auth: const AllowAllSkinAuth(), // anonymous access is opt-in
);
