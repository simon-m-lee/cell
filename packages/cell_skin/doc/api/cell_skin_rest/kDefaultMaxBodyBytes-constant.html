kDefaultMaxBodyBytes top-level constant

int const kDefaultMaxBodyBytes

The default somatic saturation limit for an incoming impulse at a membrane pore.

In the framework's biological metaphor, this constant defines the maximum volume of Somatic Nutrients (payload bytes) that a Skin Membrane pore can ingest before the Integrity Gate triggers a Membrane Rejection.

When to use

  • Pore Configuration: Used as the default cap in RestAdapter.bind to protect the somatic graph from being overwhelmed by oversized Nervous Signals.

How it works

  1. Signal Ingress: A request hits the RestAdapter.
  2. Saturation Check: As the Skin Payload is read, the adapter tracks the total bytes.
  3. Gate Trigger: If the volume exceeds this threshold, the impulse is discarded, and a body_too_large WireError is returned.

Non‑obvious behavior

  • Forensic Omission: Rejections caused by this limit occur before a Command Journey begins, meaning no Forensic Receipt is generated in the ledger.
  • Default Value: Set to 1 MiB (1,048,576 bytes), balancing standard command payloads against system resource preservation.

See also

  • RestAdapter.bind: Where this limit is applied.
  • WireError: The rejection signal sent when this limit is breached.

Implementation

const int kDefaultMaxBodyBytes = 1024 * 1024;
