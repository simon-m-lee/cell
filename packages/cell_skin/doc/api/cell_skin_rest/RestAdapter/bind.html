Binds the REST adapter to a physical network address and port./// In the framework's biological metaphor, this method sensitizes the pore. It opens a specific communication channel at the Skin Membrane, allowing the system to receive discovery impulses, command signals, and forensic audit streams via HTTP and SSE.

When to use

  • Production Egress: The standard way to expose a somatic graph to the web, mobile apps, or curl-based administrative tools.
  • Testing: Used to spin up ephemeral pores for integration testing of the membrane's Integrity Gates.

How it works

  1. Socket Anchoring: Binds an HttpServer to the provided address and port.
  2. Gate Configuration: Initializes the Identity Gatekeeper (auth) and the Membrane Translator (contextBridge).
  3. Saturation Limits: Applies the _maxBodyBytes cap to all incoming Skin Payloads to prevent resource exhaustion.
  4. CORS & Host Validation: Configures the Membrane Filter using allowedHosts and allowedOrigins to prevent unauthorized stimulation.

Non‑obvious behavior

  • Closed by Default: auth is mandatory. To explicitly allow anonymous signals, you must pass const AllowAllSkinAuth().
  • Forensic Timing: The requestTimeout defines the window for a Command Journey. If exceeded, the pore returns a 504 error, but the state change may still complete internally (an "Observation Lag").
  • SSE Liveness: Disconnects are detected via the keepAliveInterval. A failed ping cleans up the subscription to prevent "Forensic Leaks" of memory in the adapter.

Parameters

  • membrane — The reactive organ to be exposed.

  • auth — required. Pass const AllowAllSkinAuth() to make anonymous access an explicit opt-in.

  • contextBridge — translates the authenticated principal into the framework Context stamped on every inbound pulse (DescribeContextBridge by default; SystemContextBridge is the loud opt-in to system authority).

  • address — The physical IP to bind (defaults to loopback).

  • port — The network port (use 0 for an ephemeral port).

  • maxBodyBytes — The saturation cap for impulses (default 1 MiB).

  • allowedHosts — accepted Host header values; defaults to the loopback names.

  • allowedOrigins — accepted browser Origin header values. Empty by default: a browser request carrying an Origin header is rejected unless its origin is listed here.

  • maxBodyBytes — request body cap (default 1 MiB).

  • requestTimeout — the membrane request timeout surfaced as 504 outcome_unknown (default 30s).

  • keepAliveInterval — SSE ping cadence (default 15s). A silent client disconnect is detected by the next failed ping, which releases the subscription.

SkinAuth, ContextBridge, ARCHITECTURE-Skin.md §7.

static Future<RestAdapter> bind({
  required SkinMembrane membrane,
  required SkinAuth auth,
  ContextBridge contextBridge = const DescribeContextBridge(),
  Object? address,
  int port = 0,
  Set<String>? allowedHosts,
  Set<String>? allowedOrigins,
  int maxBodyBytes = kDefaultMaxBodyBytes,
  Duration requestTimeout = const Duration(seconds: 30),
  Duration keepAliveInterval = const Duration(seconds: 15),
}) async {
  final server =
      await HttpServer.bind(address ?? InternetAddress.loopbackIPv4, port);
  return RestAdapter._(
    membrane,
    server,
    auth,
    contextBridge: contextBridge,
    allowedHosts: allowedHosts ??
        {
          'localhost',
          '127.0.0.1',
          '::1',
          'localhost:${server.port}',
          '127.0.0.1:${server.port}',
          '[::1]:${server.port}',
        },
    allowedOrigins: allowedOrigins ?? const {},
    maxBodyBytes: maxBodyBytes,
    requestTimeout: requestTimeout,
    keepAliveInterval: keepAliveInterval,
  );
}
