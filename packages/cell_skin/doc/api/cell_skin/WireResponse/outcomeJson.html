outcomeJson property

WireOutcome? outcomeJson
final

The wire-safe JSON version of the cell's result.

In the framework’s biological metaphor, this is the Skin Form of the Forensic Receipt. While the outcome property holds a live object inside the system, this property holds a simplified version that is safe to send over the network (the "Wire").

When to use

  • Network Responses: Use this when you are writing a client (like a web app or an AI tool) that receives a response over a network.
  • Data Inspection: Use this to read the results of a Command Journey without needing access to the original live cell objects.

How it works

  1. Serialization: When a response leaves the system, the framework converts the live result into a plain JSON map.
  2. Decoding: When WireResponse.fromJson is called, it places the result data here.
  3. Result Access: You can then check this object to see if the original Nervous Signal was accepted or rejected.

Non‑obvious behavior

  • Mutually Exclusive: If this field is filled, the live outcome field will be null. You only use outcomeJson for responses that have traveled across the Skin Membrane.
  • Information Loss: Because this is a simplified copy, it does not contain the actual Dart functions or live references that were part of the original Somatic State Transition.
  • Pending States: If pendingReceipt is true, this field is usually null because the final result hasn't been written to the Forensic Ledger yet.

See also

  • WireOutcome: The data structure used for JSON results.
  • WireResponse.outcome: The live version of this result.
  • WireResponse.fromJson: The factory that populates this field.
