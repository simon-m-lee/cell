Decodes a raw JSON map into a WireResponse envelope.

In the framework's biological metaphor, this factory acts as the Signal Decoder at the Skin Membrane. It takes the raw Forensic Stamp received from the wire and translates it into a format the local system can read.

When to use

  • Egress Processing: Use this when a client (AI agent, web app, or Dart client) receives a result from a remote cell.
  • Testing: Use this to verify that a serialized response matches the expected forensic output.

How it works

  1. Causal Mapping: It extracts the correlationId to ensure the receipt can be matched to the original impulse.
  2. Outcome Translation: It converts the JSON payload into a WireOutcome.
  3. Live Guard: Because a live ApplyOutcome cannot survive the trip across the wire, the outcome property is left null.

Non‑obvious behavior

  • Forensic Holes: If the incoming JSON lacks a result and is not marked as pendingReceipt, this factory will produce an object that fails the internal Integrity Guard assertion.
  • Somatic Snapshots: If the response was sent while a ledger write was in flight, receiptJson is captured to provide the last known state of the cell's "DNA".
  • Type Safety: It strictly casts positional and named argument maps to ensure the Command Journey data remains stable.

See also

  • WireResponse.toJson: The reverse process for sending receipts.
  • WireOutcome.fromJson: How the result data itself is decoded.

Implementation

factory WireResponse.fromJson(Map<String, Object?> json) => WireResponse(
      correlationId: json['correlationId'] as String,
      clientCorrelationId: json['clientCorrelationId'] as String?,
      outcomeJson: json['outcome'] == null
          ? null
          : WireOutcome.fromJson(
              (json['outcome'] as Map).cast<String, Object?>()),
      pendingReceipt: json['pendingReceipt'] as bool? ?? false,
      receiptJson: (json['receipt'] as Map?)?.cast<String, Object?>(),
    );
