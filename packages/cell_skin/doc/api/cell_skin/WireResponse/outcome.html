outcome property

ApplyOutcome<Object?>? outcome
final

The live internal result produced by the target cell.

In the framework's biological metaphor, this is the Live Forensic Receipt. It represents the finalized state of the Nervous Signal immediately after it completes its Command Journey.

When to use

  • Internal Processing: Use this when you are working with a response locally within the Dart process to check if an action succeeded.
  • Direct Access: Use this to access the typed result and metadata of an ApplyOutcome before it is converted to JSON.

How it works

This field captures the exact ApplyOutcome returned by the cell's apply method. It identifies whether the transition was Accepted, Rejected (by an Integrity Gate), or Staged (in a transaction).

Non‑obvious behavior

  • Serialization Boundary: This property is only available in "live" responses. Because an ApplyOutcome can contain functions and complex logic, it cannot survive a trip across the wire.
  • Decoded Nullability: If this WireResponse was created from JSON (using WireResponse.fromJson), this field will be null. In that case, you must use outcomeJson to see the data.
  • Pending States: If pendingReceipt is true, this outcome represents the current status before the Forensic Ledger has permanently finished writing the record.

See also

  • ApplyOutcome: The internal framework result being carried.
  • WireResponse.outcomeJson: The wire-safe version of this result.
