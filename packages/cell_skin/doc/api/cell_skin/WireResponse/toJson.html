Converts the response into a JSON-safe map for transport.

In the framework's biological metaphor, this method creates the Skin Form of the response. It applies the final Forensic Stamp to the envelope, proving that a Command Journey has successfully returned to the Skin Membrane.

When to use

  • Egress: Use this when a server, MCP host, or bridge needs to serialize a result to send it over the wire to a client.
  • Persistence: Used to store a snapshot of a response in a transport-level log.

How it works

  1. Signal Labeling: It includes the kind ('response') so the receiver knows how to decode the envelope.
  2. Causal Mapping: It embeds the correlationId to ensure the Forensic Receipt can be matched to the original request.
  3. Outcome Encoding: It converts the internal ApplyOutcome into a simplified JSON structure via wireOutcomeJson.
  4. Status Flagging: It marks whether the result is a finalized ledger entry or a pendingReceipt.

Non‑obvious behavior

  • Serialization Guard: If a live outcome object exists, it is transformed into a wire-safe format. If the object was already decoded from JSON, outcomeJson is used instead to avoid double-encoding.
  • Echo Preservation: The clientCorrelationId (the External Echo) is included exactly as it was received in the request, ensuring the caller can recognize their own signal.
  • Authoritative Identity: The resulting map is the only version of the response that is legal to transmit across the system membrane.

See also

  • WireResponse.fromJson: The reverse process for decoding signals.
  • wireOutcomeJson: The utility that prepares the forensic result for the wire.

Implementation

@override
Map<String, Object?> toJson() => withWire({
      'kind': kind,
      'correlationId': correlationId,
      if (clientCorrelationId != null)
        'clientCorrelationId': clientCorrelationId,
      if (outcome != null) 'outcome': wireOutcomeJson(outcome!),
      if (outcomeJson != null) 'outcome': outcomeJson!.toJson(),
      'pendingReceipt': pendingReceipt,
      if (receiptJson != null) 'receipt': receiptJson,
      if (ledgerSeqs != null && ledgerSeqs!.isNotEmpty)
        'ledgerSeqs': ledgerSeqs,
    });
