WireRequest

WireRequest class final HowTo · Wire Messages HowTo · Idempotency

An envelope for an incoming command sent from the outside world into the system./// In the framework's biological metaphor, WireRequest is a Nervous Signal that has just touched the Skin Membrane. It carries the instructions needed to start a Command Journey inside the reactive graph.

When to use

  • External Commands: Use this when a tool (like MCP), a web client (REST), or a remote server wants to trigger an action in a cell.
  • Skin Adapters: Use this as the standard data format for any transport layer you build.

How it works

  1. Ingress: The request arrives at the system membrane with a cellId and a function name.
  2. Correlation: The system assigns a correlationId to track the signal's journey through the Forensic Ledger.
  3. Conversion: The system turns this envelope into an internal command record and sends it to the target cell's Integrity Gate.

Non‑obvious behavior

  • JSON Argument Stability: Positional arguments are stored as a map of index strings (e.g., {"0": value}) rather than a list. This ensures that JSON parsers do not accidentally reorder your data.
  • Strict Correlation: The correlationId is the "Source of Truth" for the ledger. Even if a client provides their own ID, the server-assigned ID is what determines the official Forensic Receipt.
  • Stateless Cursors: The lastSeenSeq allows a client to say "I only want to run this if my view of the data is up to date."

Example

final request = WireRequest(
  cellId: 'home.thermostat',
  function: 'setTemperature',
  positional: {'0': 22},
  correlationId: 'srv-tx-777',
  clientCorrelationId: 'my-local-req-1',
);

AI Agent Guide

Layer: Skin — this is a command envelope, not a graph node. When to use: sending a command at a bound (cellId, function) over any transport. When NOT to use: fire-and-forget signals — use WireNotification; state observations — use WireStateChange. Live signature: const WireRequest({required String cellId, required String function, Map<String, Object?>? positional, Map<String, Object?>? named, required String correlationId, String? clientCorrelationId, int? lastSeenSeq}) — pinned at cell_skin: 0.1.0 Do NOT confuse with: ApplyCommand (the framework's own command record, built from this by the binding). Guide: ARCHITECTURE-Skin.md §3 (wire taxonomy) and §6 (correlation). Example: example/lib/mock/mock_agent.dart (every scripted beat is one request). Cross-layer: the target cell's own TestCell gate may reject the command after exposure accepts it. Minimal compilable example

  cellId: 'home.living.thermostat',
