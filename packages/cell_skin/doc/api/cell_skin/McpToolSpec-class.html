McpToolSpec

McpToolSpec class final

A transport-neutral definition of an interactable somatic function, formatted for AI consumption.

In the framework's biological metaphor, McpToolSpec is a Synaptic Tool Descriptor. It represents a specific segment of the system's "DNA" (SkinFunctionDescriptor) that has been physically exposed at the Skin Membrane for external AI stimulation.

This class acts as the bridge between the framework's internal JsonSchema and the tool definitions required by Model Context Protocol (MCP) clients.

When to use

  • Discovery: Generated during a Discovery Impulse to populate the tools/list response for an AI agent.
  • Schema Mapping: Used by the McpAdapter to ensure that external tool calls are validated against the correct Somatic Blueprint.

How it works

  1. Extraction: The system reads a SkinFunctionDescriptor from the Somatic Index (manifest).
  2. Translation: The descriptor is converted into this neutral spec, mapping the cell and function names into a stable Synaptic Label.
  3. Broadcasting: The McpAdapter serializes this spec into the specific format required by the AI agent's transport (e.g., JSON-RPC).

Non‑obvious behavior

  • Atomicity: A tool spec represents exactly one apply target. It cannot bridge multiple cells; each cell/function pair is a distinct synaptic point.
  • Two names, one tool: name is the escaped MCP wire name — characters outside [A-Za-z0-9_-] become _ — and is the only name registered; dottedName is the raw <cellId>.<functionName>. An adapter that maps toJson() onto an SDK tool must not also register dottedName, or the model sees two tools for one binding.

See also

  • McpAdapter: The bridge that broadcasts these specs.
  • SkinFunctionDescriptor: The internal metadata this spec represents.
  • JsonSchema: The blueprint defining valid inputs for this tool.
