Builds the terminal egress point of the membrane, connecting the internal graph to the physical transport.

In the framework's biological metaphor, buildOutboundCell creates the Terminal Egress Pore. It represents the absolute boundary of the Skin Membrane, where a Nervous Signal (a WireMessage) is physically expelled from the somatic body to become an External Echo.

When to use

  • Transport Binding: The final step in orchestrating a SkinMembrane. It bridges the unified mux stream to a specific transport effect (e.g., writing to a WebSocket, SSE stream, or MCP transport).
  • Pore Realization: Used by adapters to turn an internal somatic event into a physical network packet.

How it works

  1. Signal Observation: It creates a Cell.observe on the mux cell.
  2. Effect Trigger: For every pulse that passes through the Egress Funnel, the send function is executed.
  3. Physical Egress: The send function translates the Skin Form of the message into the transport-specific protocol (e.g., JSON-RPC over stdio).

Non‑obvious behavior

  • Forensic Pass-through: This cell does not alter the signal or generate new forensic data. It is the final observer of the Command Journey's result.
  • Lifecycle Governance: The returned EgressHandle is the authoritative control for this pore. If the handle is not cancelled when the external connection is severed, it creates a "Forensic Leak" (a memory leak) as the observation remains active.
  • Ordered Delivery: It ensures that state changes and ledger entries are pushed to the environment in the exact sequence they were anchored in the Forensic Ledger.
