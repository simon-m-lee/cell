SkinFunctionDescriptor

SkinFunctionDescriptor class final

A technical description of a single interactable point on the membrane.

In the framework's biological metaphor, SkinFunctionDescriptor is a Synaptic Descriptor. It defines the metadata for a specific Signal Label, detailing how the environment can stimulate a cell to undergo a Somatic State Transition.

These descriptors are the building blocks of the SkinManifest (the Somatic Index), allowing external agents to understand the system's "DNA" before initiating a Command Journey.

When to use

  • Discovery: Provided to AI agents or dashboards so they know which functions are physically exposed at the Skin Membrane.
  • Validation: Used by clients to pre-screen payloads against the advertised Somatic Blueprint.

How it works

  1. Binding Extraction: The descriptor is generated from a SkinBinding.
  2. Schema Resolution: The argumentSchema is determined by prioritizing explicit binding hints, then observed cell values, and finally falling back to a permissive state.
  3. Manifest Integration: Multiple descriptors are grouped into a SkinCellDescriptor to represent the full surface of a cell.

Non‑obvious behavior

  • Statelessness: The descriptor is a static snapshot of a capability. It does not represent a specific pulse or a historical ledger entry.
  • Immutability: Once the membrane is open and the binding table is sealed, these descriptors remain constant for the life of the connection.

See also

  • SkinCellDescriptor: The container for these descriptors.
  • JsonSchema: The structure used to define the argumentSchema.
  • SkinBinding: The source of truth for this descriptor.
