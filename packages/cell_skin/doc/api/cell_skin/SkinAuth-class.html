SkinAuth

SkinAuth class abstract interface HowTo · Auth

The gatekeeper responsible for identifying external actors at the membrane.

In the framework's biological metaphor, SkinAuth is the Identity Gatekeeper. It sits at the entry point of the Skin Membrane and analyzes the Environmental Markers (SkinCredentials) attached to an incoming Nervous Signal.

Its sole responsibility is to resolve the caller's "Who"—transforming raw transport markers into the Resolved Identity DNA (SkinPrincipal) required to begin a Command Journey.

When to use

  • Identity Resolution: Implement this to define how your system verifies tokens, API keys, or peer identities.
  • Adapter Configuration: Required when binding a RestAdapter or McpAdapter, as the membrane requires an explicit gatekeeper to establish provenance.

How it works

  1. Signal Arrival: A request hits the physical transport layer.
  2. Verification: The authenticate method inspects the credentials.
  3. Identity Resolution: If valid, it returns a SkinPrincipal. If invalid, it returns null, triggering an immediate Membrane Rejection.
  4. Provenance Flow: The resulting principal is passed to the ContextBridge to be translated into internal somatic authority.

Non‑obvious behavior

  • Authentication != Authorization: This interface only identifies the actor. The decision to allow or reject a specific Somatic State Transition is handled deeper in the graph by a cell's Integrity Gate.
  • Forensic Impact: The identity resolved here is what eventually appears in the Forensic Ledger. A failure here prevents a Forensic Receipt from ever being generated.
  • Async Nature: Verification often requires external lookups (e.g., a database or OIDC provider), so the process is asynchronous.

See also

  • SkinCredentials: The raw markers provided to this gatekeeper.
  • SkinPrincipal: The identity DNA produced by this gatekeeper.
  • ContextBridge: The next step in the journey, translating identity to authority.

final class TokenAuth implements SkinAuth {
  @override
  Future<SkinPrincipal?> authenticate(SkinCredentials credentials) async =>
      credentials.token == 'secret'
          ? const SkinPrincipal(id: 'tester')
          : null;
}
