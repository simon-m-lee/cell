Sets up observers to send signals out of the system for cells that do not use a forensic ledger.

In the framework's biological metaphor, this function builds the Exiting Signal Path. It watches specific cells and packages their changes into "Wire Signals" so they can be sent to other parts of the network.

When to use

  • Outbound Communication: Use this when you need to notify external systems about state changes.
  • Simple Membranes: Use this for "Unledgered Membranes"—systems that need to send data out but don't need a permanent history log.

How it works

  1. Target Lookup: It loops through a list of IDs and finds the matching cell in the system.
  2. Observation: It starts a Cell.observe to listen for any new Pulse (Nervous Signal) from that cell.
  3. Wrapping: When a change happens, it wraps the data into a WireStateChange message.
  4. Forwarding: It triggers the onEgressPulse callback to actually send the data out.

Parameters

  • cellIds: A list of unique names for the cells you want to watch.
  • resolveTarget: A function that finds the actual Cell object based on its name.
  • onEgressPulse: The final gateway function that handles the message once it is ready to exit the system.

Non‑obvious behavior

  • Pending Receipts: Because these cells do not have a forensic ledger, every message is marked as pendingReceipt: true. This tells the receiver that there is no official "Forensic ID" for this specific change yet.
  • Causal Preservation: The exiting signal keeps the original context of the change, so you can still tell what triggered the action even after it leaves the cell.

Example

final handles = buildEgressCells(
  cellIds: ['user_profile', 'settings'],
  resolveTarget: (id) => myRegistry.find(id),
  onEgressPulse: (id, pulse) {
    networkAdapter.send(pulse.payload.toJson());
  },
);

Implementation

Map<String, EgressHandle<Pulse>> buildEgressCells({
  required Iterable<String> cellIds,
  required Cell? Function(String cellId) resolveTarget,
  required void Function(String cellId, Pulse<WireStateChange> pulse)
      onEgressPulse,
}) {
  final handles = <String, EgressHandle<Pulse>>{};
  for (final cellId in cellIds) {
    final target = resolveTarget(cellId);
    if (target == null) continue;
    handles[cellId] = Cell.observe<Pulse>(
      source: target,
      effect: (pulse) {
        onEgressPulse(
          cellId,
          Pulse<WireStateChange>.governed(
            payload: WireStateChange(
              cellId: cellId,
              payload: pulse.payload,
              pendingReceipt: true,
            ),
            type: '${SkinPulseTypes.egressPrefix}$cellId',
            source: target,
            context: pulse.context,
          ),
        );
      },
    );
  }
  return handles;
}
