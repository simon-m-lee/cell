SkinCellDescriptor

SkinCellDescriptor class final

A description of a single cell's physical surface at the membrane.

In the framework's biological metaphor, SkinCellDescriptor is a Somatic Address Record. It groups all Synaptic Points (functions) belonging to a specific cell, representing that cell's total "DNA" exposure to the external environment.

When to use

  • Discovery: Part of the SkinManifest used by AI agents to understand the structure of a cell before stimulating it.
  • Routing: Used by the membrane to identify which cell a specific Nervous Signal is intended to reach.

How it works

  1. Index Assembly: The system identifies an exposed cell in the graph.
  2. Capability Mapping: It gathers all SkinFunctionDescriptors associated with that cell.
  3. Descriptor Bundling: These descriptors are packaged into this structure for transport across the Skin Membrane.

Non‑obvious behavior

  • Authoritative Address: The cellId is the permanent Somatic Address. If a cell is renamed or moved within the graph without updating the binding, the descriptor will fail to route signals.
  • Filtering: Only functions that are whitelisted and correctly bound appear in the functions list.

See also

  • SkinManifest: The full index containing these records.
  • SkinFunctionDescriptor: The descriptors for individual functions.
  • Cell.id: The core framework's internal address for this cell.
