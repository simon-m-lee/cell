DescribeContextBridge

DescribeContextBridge class final

The default translator that stamps signals with a descriptive identity.

In the framework's biological metaphor, DescribeContextBridge is the Basic Identity Stamper. It provides a simple External Echo by taking the external SkinPrincipal's traits—its ID and roles—and encoding them directly into the framework's provenance description.

When to use

  • Default Integration: The standard choice when you want the Forensic Ledger to record the remote actor's ID without mapping to a complex internal permission system.
  • Debugging & Auditing: Useful when you need a human-readable string in the ledger that clearly indicates the signal originated from the Skin Membrane.

How it works

  1. Signal Tagging: It reads the SkinPrincipal.id and SkinPrincipal.roles.
  2. Provenance Formatting: It constructs a string prefixed with skin:.
  3. Context Creation: It returns a Context.describe object, which becomes the "Who" for the resulting Command Journey.

Non‑obvious behavior

  • Least Privilege: While it provides identity, it does not grant special framework powers. The resulting Context is treated as a standard external actor by most Integrity Gates.
  • String-Based Identity: Because this bridge relies on Context.describe, it is optimized for logging and auditing. If your cells require structural identity checks (like Context.system), use a specialized bridge instead.
  • Transparency: Every Forensic Receipt generated by a signal processed by this bridge will explicitly show the principal's roles in its provenance record.

See also

  • Context.describe: The internal provenance type created by this bridge.
  • SystemContextBridge: A bridge that grants full authority.
