Invokes (cellId, function) through the membrane and returns the target's real ApplyOutcome.

Returns null when the response was pendingReceipt (the state change was observed but its ledger entry had not landed — the authoritative receipt arrives on the ledger stream).

Throws SkinError for exposure-gate misses, cursor conflicts, and bad arguments; those rejections produced no receipt.

context stamps this request's provenance on the emitted pulse.

Future<ApplyOutcome<Object?>?> apply(
  String cellId,
  String function, {
  List<Object?>? positional,
  Map<String, Object?>? named,
  int? lastSeenSeq,
  String type = SkinPulseTypes.restApplyRequest,
  PulseContext? context,
}) async {
  final request = WireRequest(
    cellId: cellId,
    function: function,
    positional: positional == null
        ? null
        : {for (var i = 0; i < positional.length; i++) '$i': positional[i]},
    named: named,
    correlationId: _nextCorrelationId(),
    lastSeenSeq: lastSeenSeq,
  );
  final message =
      await membrane.request(request, type: type, context: context);
  return switch (message) {
    WireResponse response => response.outcome,
    WireError error => throw SkinError(error.code, error.message),
    _ => throw SkinError('unexpected_response', '$message'),
  };
}
