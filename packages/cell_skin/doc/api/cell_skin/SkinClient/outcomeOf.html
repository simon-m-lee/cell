The live outcome a WireResponse carries, with honest null and error handling.

null is returned only for pendingReceipt — the state change was observed but its ledger entry had not landed. A replay from a durable idempotency store may carry only WireResponse.outcomeJson (the live object cannot survive a restart); returning null for that would masquerade as pendingReceipt, so it throws instead. Fabricating a live outcome from JSON would invent a receipt, which the skin never does — use SkinMembrane.request to read outcomeJson when only the wire form exists.

Implementation

static ApplyOutcome<Object?>? outcomeOf(WireResponse response) {
  if (response.outcome != null) return response.outcome;
  if (response.pendingReceipt || response.outcomeJson == null) return null;
  throw SkinError(
    'outcome_json_only',
    'the stored outcome survived only as wire JSON (a durable '
    'idempotency store replay); use SkinMembrane.request to read '
    'outcomeJson',
  );
}
