Builds the somatic convergence point for all outbound wire signals.

In the framework's biological metaphor, the mux cell is the Egress Funnel. It acts as a final fan-in primitive that collects Nervous Signals from various internal somatic sources—such as the router, the egress fan-in, and the Forensic Ledger tail—and prepares them to cross the Skin Membrane.

When to use

  • Membrane Orchestration: Automatically used by the SkinMembrane to unify multiple internal signal streams into a single outbound channel.
  • Outbound Filtering: Essential for ensuring that only sanitized WireMessage envelopes reach the terminal buildOutboundCell.

How it works

  1. Signal Collection: It performs a Cell.synthesis over all provided sources.
  2. Integrity Scrubbing: The aggregator inspects every incoming pulse. If the payload is not a WireMessage (or a pulse wrapping one), it is suppressed.
  3. Unwrapping: If a signal arrives double-wrapped (e.g., from an async mapping in a cell), the mux strips the outer layer to ensure the outbound stream is a consistent Pulse<WireMessage>.

Non‑obvious behavior

  • Forensic Transparency: The mux does not create new state; it merely facilitates the exit of existing Nervous Signals. It ensures that the Command Journey results and state updates remain chronologically coherent during egress.
  • Wrap Handling: By design, it handles both WireMessage payloads (from the ledger tail) and Pulse<WireMessage> payloads (from the router's asyncMap), preventing internal somatic structure from leaking through the Skin Membrane.

See also

  • buildOutboundCell: The terminal observation cell that follows this mux.
  • WireMessage: The envelope required for all surviving pulses.

Implementation

Cell buildMuxCell({required Iterable<Cell> sources}) =>
    Cell.synthesis<Pulse<WireMessage>>(
      sources,
      aggregator: (cells, emit) {
        final payload = emit.payload;
        if (payload is WireMessage) return emit as Pulse<WireMessage>;
        if (payload is Pulse && payload.payload is WireMessage) {
          return payload as Pulse<WireMessage>;
        }
        return null;
      },
    );
