SkinCredentials

SkinCredentials class final

The raw data extracted from the transport layer before identity is resolved.

In the framework's biological metaphor, SkinCredentials represent the Environmental Markers attached to an incoming signal. They are the raw chemical signatures arriving at the Skin Membrane that must be analyzed by SkinAuth before a Command Journey can be authorized.

When to use

  • Transport Adapters: Used by components like RestAdapter or McpAdapter to package headers, tokens, and peer metadata for authentication.
  • Custom Auth: Provided as the input to SkinAuth.authenticate to determine which SkinPrincipal is attempting to influence the graph.

How it works

  1. Signal Ingress: A request hits the physical transport (e.g., HTTP).
  2. Marker Extraction: The adapter pulls the bearer token and headers into this structure.
  3. Identity Analysis: The credentials are passed to the Identity Gatekeeper (SkinAuth) to resolve the caller's "DNA."

Non‑obvious behavior

  • Pre-Somatic: This data exists entirely outside the reactive graph. It is not recorded in the Forensic Ledger unless the ContextBridge explicitly maps these markers into the resulting Context.
  • Volatility: These credentials are transient and should be discarded as soon as the SkinPrincipal is resolved to prevent credential leakage within the somatic cells.

See also

  • SkinAuth: The processor that turns these credentials into an identity.
  • SkinPrincipal: The resolved identity resulting from these credentials.
