Converts the request into a JSON-safe map for transport.

In the framework's biological metaphor, this method creates the Skin Form of the discovery signal. It prepares the Discovery Impulse to cross the Skin Membrane so it can initiate a scan of the system's exposed capabilities.

When to use

  • Egress: Use this when a client-side bridge needs to serialize a discovery probe to send it to a remote cell system.
  • Testing: Used to verify that the discovery signal is correctly labeled for the transport layer.

How it works

This method produces a minimal map containing only the kind ('manifestRequest'). Because discovery is a global, stateless operation, no somatic addresses or correlation IDs are required in the payload.

Non‑obvious behavior

  • Forensic Omission: The resulting JSON is never stored in the Forensic Ledger. It represents a transient query about the system's current "DNA" that does not alter state.
  • Zero Nutrients: Unlike a notification or a request, this signal carries no parameters. It is a pure impulse that triggers a full manifest generation on the receiver side.

See also

  • WireManifestRequest.kind: The label used to identify this impulse.
  • WireManifestResponse.toJson: The method that serializes the resulting catalog.

Implementation

@override
Map<String, Object?> toJson() => withWire({
      'kind': kind,
      if (correlationId != null) 'correlationId': correlationId,
    });
