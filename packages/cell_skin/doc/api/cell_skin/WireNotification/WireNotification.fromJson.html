Decodes a raw JSON map into a WireNotification impulse.

In the framework's biological metaphor, this factory acts as the Signal Decoder at the Skin Membrane. It translates the Skin Form of a volatile event back into a structured Transient Impulse that the local system can process.

When to use

  • Egress Processing: Use this when a client (AI agent, web app, or remote listener) receives a fire-and-forget notification from the system over a network bridge (SSE, MCP, etc.).
  • Lightweight Monitoring: The primary entry point for ingesting non-somatic updates like heartbeats or progress alerts.

How it works

  1. Intent Resolution: It extracts the method string to identify the type of impulse (e.g., 'ping').
  2. Nutrient Mapping: It pulls the params map representing the temporary data associated with the notification.
  3. Safety Casting: It ensures that the parameters are safely cast to a string-keyed map, defaulting to an empty map if the field is missing.

Non‑obvious behavior

  • Forensic Omission: Unlike WireRequest.fromJson, this factory does not look for a correlationId or a lastSeenSeq. Notifications are environmental noise and are not tracked by the Forensic Ledger.
  • Zero Persistence: The resulting object is transient. Once it passes through the decoder and is handled by a listener, it leaves no audit trail in the somatic graph.

See also

  • WireNotification.toJson: The reverse process for broadcasting signals.
  • WireMessage.fromJson: The top-level membrane decoder.

Implementation

factory WireNotification.fromJson(Map<String, Object?> json) =>
    WireNotification(
      method: json['method'] as String,
      params: (json['params'] as Map?)?.cast<String, Object?>() ?? const {},
    );
