params

params property

Map<String, Object?> params
final

The data payload associated with the notification.

In the framework's biological metaphor, these are the Transient Nutrients carried by the impulse. Since notifications are not recorded in the Forensic Ledger, this data is volatile and exists only for the duration of the signal's presence at the Skin Membrane.

When to use

  • Lightweight Payloads: Use this to send supplemental information for heartbeats, progress alerts, or metadata (e.g., {'progress': 0.5}).
  • Non-Critical Data: Use this only for information that does not require causal traceability or permanent auditing.

How it works

  1. Signal Carrying: The client or server bundles arbitrary JSON-safe data into this map.
  2. Immediate Consumption: The receiver reads these parameters immediately upon arrival.

Non‑obvious behavior

  • Forensic Omission: Data stored in params is never written to the Forensic Ledger. It will not appear in audit trails or somatic history.
  • No Integrity Gates: Unlike WireRequest arguments, these parameters are not vetted by a cell's DNA/rules. They are strictly for transport-layer communication.
  • Memory Longevity: Once the notification is handled by the membrane listeners, these nutrients are "consumed" (garbage collected) and cannot be recovered.

See also

  • WireNotification.method: The identifier for this transient impulse.
  • WireRequest.positional: For arguments that require forensic integrity.
