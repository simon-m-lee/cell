SkinClient

SkinClient class final

The in-process client over a SkinMembrane.

When to use

  • Dart code inside the same process — the demo's scripted agent uses exactly this client, not a mock transport.

How it works

SkinClient.apply emits a WireRequest through SkinMembrane.request and returns the outcome (null means the response was pendingReceipt); SkinClient.observe filters the membrane's stream down to WireStateChange.

Non-obvious

The client never fabricates receipts: a null outcome means the authoritative receipt arrives with the ledger entry.

See also

RemoteCellClient (the cell-shaped facade), RestAdapter (the socket transport).

AI Agent Guide

Layer: Skin — the trusted in-process caller, not a transport. When to use: a script, test, or agent drives the membrane from Dart; the demo pattern is this client, never a fake. When NOT to use: cross-process calls — use RestAdapter; cell-shaped remote views — use RemoteCellClient.
