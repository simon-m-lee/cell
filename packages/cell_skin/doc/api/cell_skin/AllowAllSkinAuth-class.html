AllowAllSkinAuth

AllowAllSkinAuth class final

A permissive gatekeeper that accepts all incoming signals without verification.

In the framework's biological metaphor, AllowAllSkinAuth is the Universal Receptor. It allows any Nervous Signal (request) to cross the Skin Membrane by assigning it the Neutral Signature (SkinPrincipal.anonymous).

When to use

  • Testing & Demos: The standard choice for loopback tests or local demonstrations where identity verification is not required.
  • Public Exposure: Use this for systems intended to be entirely open to the environment, where authorization is handled solely by the downstream Integrity Gates based on the target cell.

How it works

  1. Signal Ingress: A request arrives at the membrane.
  2. Blind Acceptance: This gatekeeper ignores all Environmental Markers (tokens, metadata) within the SkinCredentials.
  3. Anonymous Resolution: It returns SkinPrincipal.anonymous, ensuring the journey can proceed to the ContextBridge.

Non‑obvious behavior

  • Deliberate Opt-in: This is never the default. Adapters like RestAdapter require an explicit auth parameter; passing this class is a conscious decision to disable identity-based rejection at the membrane.
  • Forensic Impact: Every Somatic State Transition triggered through this gate will be recorded in the Forensic Ledger under the ID 'anonymous'. This makes individual actor attribution impossible.
  • Integrity Gates Still Apply: Authenticating a signal as anonymous does not grant it power. If a target cell requires a SystemContext or a specific role, the pulse will still be rejected by the cell's internal Integrity Gate.

See also

  • SkinPrincipal.anonymous: The identity DNA produced by this class.
  • SkinAuth: The base interface for identity gatekeepers.
