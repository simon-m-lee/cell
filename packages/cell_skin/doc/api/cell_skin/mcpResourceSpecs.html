Translates a SkinManifest into neutral resource specs for AI observation.

In the framework's biological metaphor, this function performs Somatic Map Assembly. It converts the Somatic Index (the manifest) into a catalog of Somatic Map Segments (McpResourceSpec) that an external AI agent can use to locate and inspect the state of the graph.

When to use

  • Discovery: The primary logic used by an McpAdapter to fulfill a Discovery Impulse (e.g., an MCP resources/list request), telling the agent where it can find observational data.

How it works

  1. Index Resolution: It iterates through every cell recorded in the manifest's "DNA."
  2. Address Generation: It constructs a stable Somatic Address (URI) for each cell, typically using the cell://graph/<cellId> scheme.
  3. Segment Creation: It bundles the cell ID and URI into a McpResourceSpec for transport across the Skin Membrane.

Non‑obvious behavior

  • Passive Observation: Unlike tool specs, which trigger Command Journeys, the resources generated here are strictly for observation. Reading these URIs does not trigger a Somatic State Transition and leaves no entry in the Forensic Ledger.
  • Granularity: This function currently generates one resource per cell. It does not yet map internal cell sub-paths or specific historical ledger ranges unless they are explicitly defined as exposed cells in the manifest.

See also

  • McpResourceSpec: The descriptor being generated.
  • SkinManifest: The somatic index being translated.
  • mcpToolSpecs: The counterpart for mapping interactable functions.

Implementation

List<McpResourceSpec> mcpResourceSpecs(SkinManifest manifest) => [
  for (final cell in manifest.cells)
    McpResourceSpec(name: cell.cellId, uri: 'cell://graph/${cell.cellId}'),
];
