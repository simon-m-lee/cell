SkinMembrane

SkinMembrane class final HowTo · Membrane

The four-Cell membrane between a CellGraph and the wire.

When to use

  • Every transport: REST, MCP, and Dart clients share this one assembled pipeline — never build a second dispatch path.

How it works

SkinMembrane.open composes Cell.ingress → Cell.asyncMap (concurrency: 1) → target.apply → egress → mux → outbound over the graph, an optional ledger, and a transport writer. request awaits the correlated WireResponse/WireError; responses broadcasts everything that survives the mux.

Non-obvious

The binding table seals at SkinMembrane.open: the egress set and the manifest can never diverge afterwards. Egress is WireStateChange, never a reply; a pending request() is only ever completed by its own correlated response/error.

See also

SkinRouter (the dispatch brain), SkinBindingTable, SkinClient, and ARCHITECTURE-Skin.md §2.
