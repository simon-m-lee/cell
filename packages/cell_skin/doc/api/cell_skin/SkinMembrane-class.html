SkinMembrane

SkinMembrane class final

The master orchestrator of the boundary layer, managing the flow between the somatic graph and the environment.

In the framework's biological metaphor, SkinMembrane is the Somatic Membrane organ. It acts as the singular, authoritative pipeline that governs how Nervous Signals (WireMessage) enter the system and how Forensic Receipts and state observations are expelled to the outside world.

The Four-Cell Pipeline

The membrane is composed of four specialized functional units:

  1. Inbound (inbound): The entry pore where raw Skin Payloads arrive.
  2. Router (router): The Synaptic Junction that performs binding lookups, cursor validation, and triggers the target.apply logic.
  3. Mux (mux): The Egress Funnel that aggregates responses, ledger entries, and volatile state changes.
  4. Outbound (outbound): The terminal pore that writes the finalized Nervous Signals to the transport layer.

Forensic Integrity

The membrane ensures that every successfully processed command results in an authoritative Somatic State Transition recorded in the Forensic Ledger. By centralizing all transport (REST, MCP, SSE) through this single pipeline, it prevents "Forensic Ambiguity" and ensures that provenance is always preserved.

Lifecycle and Sealing

When a membrane is initialized via open, it seals the SkinBindingTable. This ensures the system's "DNA" (its exposed surface) remains immutable throughout the connection, providing a stable Somatic Index for discovery.
