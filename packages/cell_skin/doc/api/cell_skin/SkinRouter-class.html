SkinRouter

SkinRouter class final

The dispatch brain responsible for governing the journey of signals from the membrane to the somatic graph.

In the framework's biological metaphor, SkinRouter acts as the Synaptic Junction. It intercepts every Nervous Signal (WireMessage) arriving at the Skin Membrane and orchestrates its Command Journey toward a specific target cell.

Receipt Provenance

A core responsibility of the router is maintaining Forensic Integrity. It invokes target.apply rather than its own, ensuring that the resulting Forensic Receipt correctly attributes the Somatic State Transition to the domain cell and its specific "DNA" (receptor logic), rather than the transport adapter.

Integrity Gates

Before a signal is allowed to mutate the graph, the router enforces several sequential gates:

  1. Exposure Gate: Checks the SkinBindingTable to ensure the pore is open.
  2. Idempotency Gate: Uses Impulse Memory to prevent duplicate transitions from the same Causal Link.
  3. Schema Gate: Validates the Skin Payload against the Somatic Blueprint.
  4. Cursor Gate: Enforces Causal Linkage by verifying the signal's lastSeenSeq against the Forensic Ledger.

Materialization

The router is typically materialized as a Cell.asyncMap. It enforces a Concurrency Limit of 1 to ensure that all transitions are anchored in the ledger in a deterministic, serial order, preserving the system's chronological "Source of Truth."

Ledger scope

With a bound ledger, every target apply runs inside the graph's LedgerScope: the router opens graph.run around the apply only when no scope is already active, and reuses an existing scope on the same ledger (see the four-row rule on the private _runTarget). A membrane opened without a ledger still does not record.
