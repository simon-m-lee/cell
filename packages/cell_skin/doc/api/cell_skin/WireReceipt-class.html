WireReceipt

WireReceipt class final

The read model of a cell's physical state transition, stripped of live references for transport.

In the framework's biological metaphor, WireReceipt is the Skin Form of the Forensic Receipt. While the internal ApplyReceipt carries live cell objects and Dart functions, this class represents the sanitized, JSON-safe proof that a Somatic State Transition has been recorded.

When to use

  • Audit Inspection: Use this on the client side to verify the exact sequence, timing, and authority of a past change.
  • State Reconstruction: Essential for "Time Travel" or replaying the Forensic Ledger in a remote environment.

How it works

  1. Signal Sanitization: During encoding, live Function objects are replaced with functionLabel to prevent closure internal leakage.
  2. Integrity Guarding: Arguments are checked for JSON safety. If an argument cannot be encoded, it is replaced with a <unencodable: type> marker to prevent a "Forensic Hole" (a transport failure).
  3. Causal Mapping: It bundles the pulseDigest and ledgerSeq to provide a verifiable link back to the Command Journey.

Non‑obvious behavior

  • Honest Labeling: The functionLabel prefers the name provided by the wire binding. If missing, it falls back to a string representation of the closure, which is useful for debugging but not for execution.
  • Historical Snapshot: This receipt is a static record. It does not change if the cell's "DNA" (receptor or rule version) is updated later.

See also

  • ApplyReceipt: The live, internal record being modeled here.
  • WireOutcome: The structure that carries this receipt as proof of result.
  • wireReceiptJson: The encoder that produces this structure.
