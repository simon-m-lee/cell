McpResourceSpec

McpResourceSpec class final

A transport-neutral definition of an observational somatic resource.

In the framework's biological metaphor, McpResourceSpec is a Somatic Map Segment. It describes a read-only observational point physically exposed at the Skin Membrane, such as the topology of a specific cell or a live stream of the Forensic Ledger.

Unlike McpToolSpec, which represents an entry point for a Command Journey, a resource spec represents a passive probe into the system's current state or history.

When to use

  • Discovery: Generated during a Discovery Impulse to populate the resources/list response for an AI agent.
  • State Inspection: Used by agents to locate the Somatic Address of a cell's data without triggering a mutation.

How it works

  1. Index Resolution: The system identifies a cell or ledger stream marked for public observation.
  2. Address Mapping: It constructs a URI (typically cell://graph/<id>) representing the physical location of the data.
  3. Broadcasting: The McpAdapter serializes this spec to inform the AI agent where it can "listen" to the somatic pulse.

Non‑obvious behavior

  • ReadOnly: Resources are strictly observational. They never trigger a Somatic State Transition.
  • URI Stability: The uri is the authoritative Somatic Address. Agents should treat this URI as a stable pointer to the cell's phenotype or history.

See also

  • McpAdapter: The bridge that broadcasts these resources.
  • McpToolSpec: For interactable functions that change state.

AI Agent Guide

Layer: Skin — this provides your observational context. Traceability: Reading a resource is not ledgered as a state change. Protocol: Use the provided uri to fetch the current state of a cell.
