SkinBindingTable

SkinBindingTable class final HowTo · Bindings

The (cellId, functionName) → closure lookup table.

The table can be sealed: a sealed table rejects further registrations, so a membrane that froze its egress cells at open() can never diverge from the manifest.

When to use

  • Registering every exposed tool before SkinMembrane.open — the table is the whole exposure registry.

How it works

register rejects duplicates and, once sealed, any further registration; SkinBindingTable.lookup is the router's exposure gate.

Non-obvious

The membrane seals the table at open(): everything registered later throws — design registration order deliberately.

See also

SkinBinding, SkinWhitelist, SkinMembrane.open.
