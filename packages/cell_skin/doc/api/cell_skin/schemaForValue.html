Derives a best-effort JsonSchema by observing a single somatic value. /// In the framework's biological metaphor, this is Trait Induction. It takes a specific Somatic Nutrient (a value) that has successfully crossed an Integrity Gate and derives the Somatic Blueprint (DNA) required to represent it.

When to use

  • Automatic Discovery: Used by the system to learn the shape of valid signals by watching the Forensic Ledger.
  • Manifest Generation: Helps populate the Somatic Index with schemas when no explicit developer hints are provided.

How it works

  1. Trait Analysis: The function inspects the runtime type of the provided value.
  2. Blueprint Mapping: It maps Dart types to their wire-safe equivalents (e.g., int becomes integer, List becomes array).
  3. Recursive Induction: For complex Skin Payloads (Maps and Lists), it recursively derives blueprints for all internal elements.

Non‑obvious behavior

  • Widen by Type Only: To avoid "Forensic Holes" where a valid future signal is rejected, this function only induces the type. It does not automatically set enum, minimum, or maximum constraints based on a single observation.
  • Required Traits: When inducing an object (Map), any key with a non-null value is marked as required in the resulting blueprint.
  • Permissive Nutrients: If the value is null or an unknown type, it returns a JsonSchema.permissive blueprint, allowing the internal Integrity Gate to remain the sole arbiter of validity.

See also

  • JsonSchema: The blueprint being produced.
  • mergeSchemas: How multiple induced blueprints are combined into a wider system DNA.

Implementation

JsonSchema schemaForValue(Object? value) {
  if (value == null) return const JsonSchema();
  if (value is num) {
    return JsonSchema(type: value is int ? 'integer' : 'number');
  }
  if (value is bool) return const JsonSchema(type: 'boolean');
  if (value is String) return const JsonSchema(type: 'string');
  if (value is List) {
    if (value.isEmpty) return const JsonSchema(type: 'array');
    // Union of every element's schema, not just the first element's.
    var items = schemaForValue(value.first);
    for (final element in value.skip(1)) {
      items = mergeSchemas(items, schemaForValue(element));
    }
    return JsonSchema(type: 'array', items: items);
  }
  if (value is Map) {
    final properties = <String, JsonSchema>{};
    final required = <String>[];
    value.forEach((key, v) {
      if (key is String) {
        properties[key] = schemaForValue(v);
        if (v != null) required.add(key);
      }
    });
    return JsonSchema(
      type: 'object',
      properties: properties,
      required: required,
      additionalProperties: true,
    );
  }
  return const JsonSchema();
}
