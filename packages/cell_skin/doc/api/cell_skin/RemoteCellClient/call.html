Stimulates the remote cell to perform a Somatic State Transition.

This method initiates a Command Journey. It packages the positional and named nutrients into a WireRequest and awaits the remote Forensic Receipt.

Outcomes

  • Accepted: Returns an ApplyOutcome if the remote Integrity Gate anchored the change.
  • Membrane Rejection: Throws a SkinError if the remote membrane discarded the signal (e.g., bad arguments, cursor conflict).
  • Pending: Returns null if the remote system generated a pendingReceipt, indicating the journey is not yet anchored.

Parameters

  • function: The Signal Label of the remote pore to stimulate.
  • lastSeenSeq: The last known sequence from the remote Forensic Ledger to ensure Causal Linkage.

Future<ApplyOutcome<Object?>?> call(
  String function, {
  List<Object?>? positional,
  Map<String, Object?>? named,
  int? lastSeenSeq,
}) {
  final request = WireRequest(
    cellId: cellId,
    function: function,
    positional: positional == null
        ? null
        : {for (var i = 0; i < positional.length; i++) '$i': positional[i]},
    named: named,
    // A counter, not a timestamp: concurrent identical calls must
    // never share a correlation id.
    correlationId:
        'remote-${DateTime.now().microsecondsSinceEpoch}-${_correlationCounter++}',
    lastSeenSeq: lastSeenSeq,
  );
  return transport(request, SkinPulseTypes.restApplyRequest).then((message) {
    return switch (message) {
      WireResponse response => response.outcome,
      WireError error => throw SkinError(error.code, error.message),
      _ => throw SkinError('unexpected_response', '$message'),
    };
  });
}
