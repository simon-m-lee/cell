close method

Future<void> close()

Closes the terminal cell, every egress observer, the receipt join, the ledger-tail subscription and the response stream, and fails every pending request() with a closed SkinError. The graph and ledger stay open — they belong to the caller.

Implementation

Future<void> close() async {
  if (_closed) return;
  _closed = true;
  outbound.stop();
  for (final handle in egress.values) {
    handle.stop();
  }
  egress.clear();
  await _ledgerSubscription?.cancel();
  _ledgerSubscription = null;
  final pending = _pendingRequests.toList();
  _pendingRequests.clear();
  for (final completer in pending) {
    if (!completer.isCompleted) {
      completer.completeError(
          const SkinError('closed', 'the membrane was closed'));
    }
  }
  if (!_events.isClosed) await _events.close();
}
