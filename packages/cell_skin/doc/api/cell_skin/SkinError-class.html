SkinError

SkinError class final

A failure encountered at the boundary when a nervous signal is rejected.

In the framework's biological metaphor, SkinError represents a Membrane Rejection. It is the "pain signal" returned to the environment when an impulse fails to pass through an Integrity Gate or when a Command Journey is terminated before it can result in a Somatic State Transition.

Unlike internal framework exceptions, a SkinError is designed to cross the Skin Membrane. It translates technical somatic failures into a stable vocabulary for external AI agents and remote axons.

When to use

  • Transport Failures: Thrown by a SkinClient or RemoteCellClient when the underlying connection is severed (code: closed).
  • Gate Rejections: Thrown when the SkinRouter blocks a signal due to structural issues (code: bad_arguments) or security violations (code: unauthorized).
  • Causal Conflicts: Thrown when a pulse violates Causal Linkage rules (code: conflict or cursor_required).

Forensic Integrity

Because a SkinError typically represents a rejection before the pulse is anchored, it often corresponds to a Forensic Hole in the target cell's ledger. The environment receives this error, but the cell's internal state remains unchanged.

See also

  • WireError: The wire-format envelope that carries this failure.
  • SkinRouter: The junction that typically generates these rejections.
  • BadArgumentsException: A common internal cause for this error.
