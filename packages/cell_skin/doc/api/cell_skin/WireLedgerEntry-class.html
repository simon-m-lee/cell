WireLedgerEntry

WireLedgerEntry class final

A wrapper for an authoritative audit record from the system's permanent history.

In the framework's biological metaphor, WireLedgerEntry is a Forensic Ledger Row. It represents a finalized Somatic State Transition that has been physically written into the system's "DNA." Unlike a WireStateChange, which can be volatile or pending, this signal is the legal proof of a committed event.

When to use

  • Audit Streaming: Use this to push a real-time feed of the Forensic Ledger to an external auditor or a long-term storage service.
  • Causal Synchronization: Essential for clients that need to reconstruct the exact, sequence-perfect history of the somatic graph.
  • Legal Traceability: The primary message type for identifying who triggered a change and exactly when it was physically anchored.

How it works

  1. Persistence: A change occurs and is accepted by an Integrity Gate.
  2. Anchoring: The Forensic Ledger assigns a global sequence number and timestamp.
  3. Egress: The system emits this envelope through the Skin Membrane as an authoritative confirmation of the transition.

Non‑obvious behavior

  • Authoritative Only: This signal is never "pending." If it exists on the wire, it means the Command Journey has been successfully anchored in the ledger.
  • Global Ordering: The sequence numbers within these entries are the only valid way to determine the absolute order of events across all cells in the body.

See also

  • LedgerEntry: The internal forensic record being carried.
  • WireStateChange: For live observations that may still be pending.
  • WireResponse: For the immediate result of a specific command.
