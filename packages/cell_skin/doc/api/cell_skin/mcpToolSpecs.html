Translates a SkinManifest into neutral tool specs for AI discovery.

In the framework's biological metaphor, this function performs Synaptic Mapping. It converts the Somatic Index (the manifest) into a catalog of Synaptic Tool Descriptors (McpToolSpec) that an external AI agent can stimuate via a Discovery Impulse (e.g., an MCP tools/list request).

When to use

  • Discovery: The primary logic used by an McpAdapter to tell an AI agent which cells and functions are physically exposed at the Skin Membrane.

How it works

  1. Index Iteration: It walks through every cell and function recorded in the manifest's "DNA."
  2. Label Construction: It generates the escaped wire McpToolSpec.name for each pair, keeping the raw pair on McpToolSpec.dottedName.
  3. Integrity Check: Every accepted alias (name and dottedName) must map to exactly one binding, and a name must fit 64 characters. A collision throws StateError before a list is returned.

Non‑obvious behavior

  • Forensic Integrity: A collision is a StateError that names both bindings; the lookup is a map, never a split of the dotted string (that split is ambiguous by construction).
  • Description Inheritance: If a specific function lacks a description, it inherits the description of its parent cell to provide the AI agent with maximum Somatic Context.

See also

  • McpToolSpec: The descriptor being generated.
  • SkinManifest: The somatic index being translated.

Implementation

List<McpToolSpec> mcpToolSpecs(SkinManifest manifest) {
  final specs = <McpToolSpec>[];
  final owners = <String, (String, String)>{};

  void claim(String alias, String cellId, String functionName) {
    final previous = owners[alias];
    if (previous != null &&
        (previous.$1 != cellId || previous.$2 != functionName)) {
      throw StateError(
        'mcpToolSpecs: "$alias" is both '
        '${previous.$1}.${previous.$2} and $cellId.$functionName',
      );
    }
    owners[alias] = (cellId, functionName);
  }

  for (final cell in manifest.cells) {
    for (final function in cell.functions) {
      if (cell.cellId.isEmpty || function.name.isEmpty) {
        throw StateError(
          'mcpToolSpecs: empty cellId or functionName produces no valid '
          'tool name',
        );
      }
      final dottedName = '${cell.cellId}.${function.name}';
      final name = mcpEscapedToolName(cell.cellId, function.name);
      if (name.length > 64) {
        throw StateError(
          'mcpToolSpecs: tool name "$name" for $dottedName is '
          '${name.length} characters; MCP hosts allow at most 64',
        );
      }
      claim(name, cell.cellId, function.name);
      claim(dottedName, cell.cellId, function.name);
      specs.add(McpToolSpec(
        name: name,
        dottedName: dottedName,
        cellId: cell.cellId,
        functionName: function.name,
        description: function.description ?? cell.description,
        inputSchema: function.argumentSchema,
      ));
    }
  }
  return specs;
}
