cell_skin

cell_skin library Getting Started HowTo · Testing Features Architecture Demo: Echo Home Test Verification

cell_skin — the membrane between a Cell graph and the outside world. MCP-native, audit-ready, replay-verifiable.

The wire is a Pulse<WireMessage> stream; the membrane is four Cells composed from framework primitives:

Cell.ingress → Cell.asyncMap → target.apply → Cell.observe → Cell.observe
(inbound)      (router)          (the plug)     (egress)        (outbound)

Quick start:

final graph = (CellGraph.builder(graphId: 'demo')
      ..register('thermostat', thermostatCell))
    .build();
final ledger = await graph.bindLedger(
  store: InMemoryLedgerStore(genesisHash: Ledger.genesisHashOf(graph.id)),
);
final bindings = SkinBindingTable()
  ..register(SkinBinding(
    cellId: 'thermostat',
    functionName: 'setTarget',
    target: thermostatCell,
    function: (int target) => thermostatHandle.update(target),
  ));
final membrane = await SkinMembrane.open(
  graph: graph,
  bindings: bindings,
  ledger: ledger,
  journal: RecordingJournal(),
  send: (_) {}, // the transport's writer
);
final client = SkinClient(membrane: membrane);
final outcome = await client.apply('thermostat', 'setTarget',
    positional: [19]);

Exceptions / Errors

BadArgumentsException
Thrown for a malformed wire argument envelope (positional keys that are not a contiguous 0..n-1 range, or invalid named argument identifiers). The router maps it to a bad_arguments WireError before the target's apply ever runs.
SkinError
A wire-level failure surfaced to a skin client.
