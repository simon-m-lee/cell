Converts the manifest response into a JSON-safe map for transport.

In the framework's biological metaphor, this method creates the Skin Form of the Somatic Index. It prepares the catalog of available tools and cells to cross the Skin Membrane so a discovery client can understand the system's "DNA."

When to use

  • Egress: Use this when the system needs to serialize the result of a Discovery Impulse (WireManifestRequest) to send it to a remote client or AI agent.
  • Handshake Finalization: Used during the initial connection phase to provide the caller with a technical map of the surface.

How it works

  1. Signal Labeling: It includes the kind ('manifestResponse') so the receiver knows this is a capability index.
  2. Somatic Serialization: It calls toJson() on the manifest, transforming the internal cell/tool definitions into a wire-safe format.

Non‑obvious behavior

  • Forensic Omission: The resulting JSON is strictly observational. Because discovery does not trigger a Somatic State Transition, this payload is never recorded in the Forensic Ledger.
  • Statelessness: Unlike a standard WireResponse.toJson, this map does not contain a correlationId. It is a global snapshot of the membrane's surface at a specific point in time.

See also

  • WireManifestResponse.kind: The label used to identify this index.
  • SkinManifest.toJson: The method that serializes the actual cell and tool metadata.

Implementation

@override
Map<String, Object?> toJson() => withWire({
      'kind': kind,
      'manifest': manifest.toJson(),
      if (correlationId != null) 'correlationId': correlationId,
    });
