manifest property

SkinManifest manifest
final

The catalog of exposed tools and cells available for interaction.

In the framework's biological metaphor, this is the Somatic Index. It serves as the physical map of the system's "DNA," detailing the structure and location of every cell and tool physically exposed at the Skin Membrane.

When to use

  • Tool Discovery: Used by AI agents to understand which Nervous Signals (requests) the system is capable of processing.
  • Schema Validation: Provides the JSON schemas required to correctly format arguments for a Command Journey.

How it works

  1. Signal Response: When a Discovery Impulse (WireManifestRequest) is received, the system generates this index.
  2. Structure Mapping: It enumerates all cells and tools that have passed through an Integrity Gate for public exposure.
  3. Payload Delivery: The manifest is serialized into the Skin Form and delivered to the client.

Non‑obvious behavior

  • Forensic Omission: The data within this manifest is observational. It does not represent a Somatic State Transition and is therefore never recorded in the Forensic Ledger.
  • Strict Exposure: If a cell or tool is missing from this index, it is effectively invisible to the outside world, regardless of its existence in the core somatic graph.
  • Snapshot Nature: This manifest represents a point-in-time view of the system's capabilities. If the system's "DNA" changes (e.g., dynamic tool registration), a new Discovery Impulse must be sent.

See also

  • SkinManifest: The internal data structure being carried.
  • WireManifestRequest: The impulse that requested this index.
