Creates a new WireManifestResponse envelope.

In the framework's biological metaphor, this constructor assembles the Somatic Index. It packages the system's "DNA" (available tools and cells) into a Skin Form so it can be transmitted back through the Skin Membrane in response to a Discovery Impulse.

When to use

  • Discovery Completion: Use this when the system has finished scanning its internal graph and is ready to tell a client (like an AI agent) what functionality is exposed.
  • Handshake Finalization: The final step in a connection sequence where the client needs the somatic map to begin sending commands.

How it works

This constructor wraps a SkinManifest, which contains the technical schemas and addresses of the system's surface. Unlike a standard WireResponse, this does not conclude a specific Command Journey and therefore does not require a correlation ID.

Non‑obvious behavior

  • Forensic Omission: The envelope created here is purely observational. It is not recorded in the Forensic Ledger because providing the index does not trigger a Somatic State Transition.
  • Global Snapshot: The manifest provided should represent the entirety of the physically exposed surface at the moment the Discovery Impulse was processed.

See also

  • WireManifestRequest: The discovery signal that triggers this response.
  • SkinManifest: The actual catalog of cells and tools being carried.
