Decodes a raw JSON map into a WireRequest envelope.

In the framework's biological metaphor, this factory acts as the Signal Decoder at the Skin Membrane. It takes raw data from the outside world and translates it into a structured Nervous Signal that the system can understand.

When to use

  • Transport Adapters: Use this when your web server (REST), AI tool (MCP), or network listener receives a JSON message intended to trigger a cell action.
  • Data Ingress: The primary entry point for turning external strings and numbers into a formal request.

How it works

  1. Field Extraction: It looks for keys like cellId and function.
  2. Type Casting: It converts raw JSON types into the specific types required by the WireRequest (e.g., ensuring IDs are strings).
  3. Argument Mapping: It safely casts the positional and named argument maps to ensure they are ready for the Integrity Gate.

Non‑obvious behavior

  • JSON Stability: If positional arguments arrive as a list, they must be converted to a map (e.g., {"0": value}) before calling this factory. This ensures the order of the Command Journey is never lost by accident.
  • Null Safety: Optional fields like clientCorrelationId and lastSeenSeq are handled safely. If they are missing in the JSON, they will be null in the resulting object.

Forensic Integrity

This factory is the first line of defense. By strictly validating the JSON structure here, the system prevents "malformed signals" from ever reaching the Forensic Ledger.

See also

  • WireRequest.toJson: The reverse process of turning a request into JSON.
  • WireMessage.fromJson: The top-level factory that decides which kind of message to decode.

Implementation

factory WireRequest.fromJson(Map<String, Object?> json) => WireRequest(
      cellId: json['cellId'] as String,
      function: json['function'] as String,
      positional: (json['positional'] as Map?)?.cast<String, Object?>(),
      named: (json['named'] as Map?)?.cast<String, Object?>(),
      correlationId: json['correlationId'] as String,
      clientCorrelationId: json['clientCorrelationId'] as String?,
      lastSeenSeq: json['lastSeenSeq'] as int?,
    );
