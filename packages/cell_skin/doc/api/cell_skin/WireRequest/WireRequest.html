Creates a new WireRequest envelope to carry a signal into the system.

In the framework's biological metaphor, this constructor assembles the Nervous Signal envelope. It prepares the data needed to cross the Skin Membrane and begin a Command Journey.

When to use

  • Transport Adapters: Use this when writing code for MCP tools, REST endpoints, or custom network listeners to wrap incoming data.
  • Testing: Use this to simulate external requests during integration tests of the governance layer.

How it works

The constructor simply bundles the somatic address (cellId), the instruction (function), and the causal metadata into a stable, immutable record. This record is then vetted by the membrane before being converted into a framework command.

Parameters

  • cellId: The name of the cell this signal is trying to reach.
  • function: The name of the update or action to perform.
  • positional: Optional data passed by order (e.g., first argument, second argument).
  • named: Optional data passed using specific labels.
  • correlationId: The unique ID used by the system to track this signal in the Forensic Ledger.
  • clientCorrelationId: An optional label provided by the caller to help them identify the response.
  • lastSeenSeq: An optional marker to ensure the caller has the latest data before they try to change the state.
