Converts a LedgerEntry into an authoritative WireStateChange signal.

In the framework's biological metaphor, this is a Forensic Export. It takes a confirmed record from the Forensic Ledger and packages it as an official message to be sent outside the cell membrane.

Unlike "Unledgered" signals, this message carries its official Forensic Receipt, proving that the change was successfully committed to the system's DNA.

When to use

  • Ledgered Communication: Use this when your system uses a Ledger and you need to notify external systems of a confirmed somatic change.
  • Audit Syncing: Use this to provide other systems with an identical copy of your internal audit trail.

How it works

  1. Receipt Extraction: It pulls the official WireReceipt directly from the ledger entry's stored JSON.
  2. Payload Retrieval: It extracts the Pulse data that caused the change.
  3. Authoritative Pairing: It combines the receipt and data into a WireStateChange where pendingReceipt is set to false.

Parameters

  • entry: The official LedgerEntry record representing a completed Somatic State Transition.

Non‑obvious behavior

  • Authoritative Link: Because the receipt and the data come from the same ledger entry, they are guaranteed to be perfectly paired. The receiver can trust this is a finalized "Source of Truth."
  • Encoding Consistency: This function uses the same canonical JSON format as the audit trail itself, ensuring the data looks the same in the ledger as it does on the wire.
  • Causal Completeness: Unlike temporary signals, this export represents a journey that is already finished and recorded.

Example

// Listening to the tail of the Forensic Ledger
myLedger.stream.listen((entry) {
  final officialSignal = wireStateChangeForEntry(entry);

  // Send the confirmed change to a remote server
  dispatcher.send(officialSignal);
});

  • LedgerEntry: The stored record of a nervous signal.
  • WireStateChange: The container used for signals exiting the system.
  • buildEgressCells: For sending signals from systems without a ledger.

Implementation

WireStateChange wireStateChangeForEntry(LedgerEntry entry) {
  final storedReceipt = entry.toJson()['receipt'];
  return WireStateChange(
    cellId: entry.receiptCellId,
    payload: entry.pulseJson?['payload'],
    receipt: storedReceipt is Map
        ? WireReceipt.fromJson(storedReceipt.cast<String, Object?>())
        : WireReceipt.fromJson(wireReceiptJson(entry.receipt)),
    pendingReceipt: false,
  );
}
