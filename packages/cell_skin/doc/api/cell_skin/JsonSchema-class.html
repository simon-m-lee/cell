JsonSchema

JsonSchema class final

The technical blueprint describing the shape and constraints of a somatic signal.

In the framework's biological metaphor, JsonSchema is the Somatic Blueprint. It defines the "DNA" structure required for a Nervous Signal (request) to successfully pass through a cell's Integrity Gate.

These blueprints are carried within the Somatic Index (the manifest) to help external agents (like AI tools) understand how to format a Command Journey that the system will accept.

When to use

  • Discovery: Provided in a WireManifestResponse so clients know the valid inputs for exposed cells and tools.
  • Validation: Used at the Skin Membrane to pre-screen Skin Payloads before they are converted into internal pulses.

How it works

  1. Observation: The system monitors the Forensic Ledger and uses schemaForValue to record the shapes of data that have successfully triggered transitions.
  2. Widening: As different types of data are accepted, the blueprint "widens" to accommodate the new valid shapes.
  3. Manual Hardening: Developers can provide explicit blueprints to enforce strict Integrity Gates (e.g., specific enum values or numeric ranges).

Non-obvious behavior

  • Permissive Fallback: If a cell's receptor is an opaque predicate (a Dart closure), the blueprint falls back to permissive ({}). In this case, the Integrity Gate remains authoritative, but the membrane cannot describe the requirements to the outside world.
  • Forensic Integrity: While the blueprint guides the agent, the actual state transition is only granted if the live cell accepts the pulse during the Command Journey.

See also

  • WireManifestResponse: The signal that carries these blueprints.
  • schemaForValue: The utility that derives blueprints from observed state.

AI Agent Guide

Layer: Skin — this is your guide for tool calls. Constraint: Always match your arguments to the properties defined here. Validation: Rejection by the system usually means your signal violated the somatic structure defined in this blueprint.
