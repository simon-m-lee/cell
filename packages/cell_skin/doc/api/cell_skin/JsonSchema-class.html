JsonSchema

JsonSchema class final

A small JSON Schema subset sufficient for MCP tools/list and REST clients. Unknown keywords are preserved in extra.

When to use

  • Declaring a binding's argumentSchema hint, or describing the observed value shape in the manifest.

How it works

schemaForValue derives a widening schema from a live value: type-only inference (no single-value enum or minimum == maximum), required as the intersection across objects, absent bounds as unconstrained, and array items merged across every element.

Non-obvious

JsonSchema.fromJson is lenient (array type, schema-object additionalProperties) and strips known keys from extra so a raw input map can never re-spread over modelled fields.

See also

mergeSchemas, SkinBinding.argumentSchema.
