WirePulseGate

WirePulseGate class final

An integrity gate that ensures only valid wire signals enter the somatic graph.

In the framework's biological metaphor, WirePulseGate acts as the Ingress Membrane Filter. It sits at the absolute edge of the Skin Membrane to verify that an incoming impulse is a recognized Nervous Signal (a WireMessage) before it is allowed to begin a Command Journey.

When to use

  • Ingress Validation: Automatically used by the framework's inbound transport cell to prevent malformed or non-somatic data from polluting the reactive graph.
  • Structural Integrity: Ensures that every pulse entering via a physical adapter (REST, MCP, SSE) carries a payload that can be sanitized and recorded.

How it works

  1. Signal Ingress: A pulse arrives at the membrane's ingress pore.
  2. Payload Inspection: The gate inspects the object.payload.
  3. Verification:
    • If the payload is a WireMessage, the signal is vetted.
    • If the payload is another Pulse (wrapped ingress), it recursively checks for an internal WireMessage.
  4. Rejection: If no WireMessage is found, the gate triggers a Membrane Rejection, discarding the impulse.

Non‑obvious behavior

  • Pre-Forensic Gate: Because this check happens at the entry point of the Cell.ingress, a rejection here occurs before the signal is assigned a sequence number. This results in a Forensic Hole if not explicitly logged by the transport adapter.
  • Channel Permissiveness: This gate specifically filters the pulse channel. It allows other internal signals (like link or action updates) to pass through, as those are governed by the underlying ingress cell's native logic.

See also

  • WireMessage: The base contract for all signals crossing the membrane.
  • buildInboundCell: The factory that installs this gate at the pore.
