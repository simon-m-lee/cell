SkinWhitelist

SkinWhitelist class final HowTo · Whitelist

cellId → {functionName} exposure policy.

When to use

  • Shrinking the wire surface below "every registered binding": applies, egress, /skin/observe/:cellId, and /skin/ledger all respect it.

How it works

A function that is not bound does not exist on the wire; a bound but not whitelisted function is refused at the skin. Entries with no matching binding raise startup policy warnings.

Non-obvious

The whitelist is policy over the binding table — it never creates exposure by itself.

See also

SkinBindingTable, SkinMembrane.isExposed.
