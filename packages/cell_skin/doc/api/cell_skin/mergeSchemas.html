Merges two somatic blueprints into a single, wider DNA structure.

In the framework's biological metaphor, this is Somatic Merging. When the system observes multiple successful Nervous Signals (pulses) over time, it combines their requirements to form a unified Somatic Blueprint that represents the total known capacity of the cell.

When to use

  • Schema Evolution: Used by the Somatic Index (manifest) to update its technical description of a cell as new, valid argument shapes are observed in the Forensic Ledger.
  • Blueprint Synthesis: Helpful when combining developer-provided hints with observed data shapes to create a hardened Integrity Gate.

How it works

  1. Widening Logic: The merge always prefers the "loosest" constraint. For example, if one blueprint allows an integer and another allows a number, the result is a number.
  2. Recursive Integration: For complex Skin Payloads (objects), it recursively merges the blueprints for every property.
  3. Requirement Intersection: A field is only marked as required in the resulting blueprint if it was mandatory in both source blueprints. This prevents "Forensic Holes" where a valid signal is blocked by an overly strict requirement.
  4. Constraint Union: For enum values, the result is the union of both vocabularies. For numeric bounds, the result is the widest possible range (the minimum of the minimums and the maximum of the maximums).

Non‑obvious behavior

  • Absorption: If either blueprint is JsonSchema.permissive (untyped), the resulting blueprint effectively becomes permissive for that segment, as an unconstrained DNA strand can absorb any shape.
  • Conflict Resolution: If the two blueprints describe fundamentally incompatible types (e.g., a string and a boolean), the merge widens to a null-typed schema, signaling that the membrane cannot reliably predict the shape.
  • Sorting: Required keys and enum values are sorted during the merge to ensure the resulting Skin Form is deterministic and stable for caching.

See also

  • JsonSchema: The blueprint structure being merged.
  • schemaForValue: The function that generates the initial blueprints for merging.

Implementation

JsonSchema mergeSchemas(JsonSchema a, JsonSchema b) {
  // An unconstrained type absorbs everything.
  if (a.type == null || b.type == null) {
    return JsonSchema(description: a.description ?? b.description);
  }
  final type = switch ((a.type!, b.type!)) {
    ('integer', 'number') || ('number', 'integer') => 'number',
    (final x, final y) when x == y => x,
    _ => null,
  };
  if (type == null) {
    return JsonSchema(description: a.description ?? b.description);
  }
  final properties = <String, JsonSchema>{};
  if (a.properties != null) properties.addAll(a.properties!);
  if (b.properties != null) {
    b.properties!.forEach((key, schema) {
      properties[key] = properties.containsKey(key)
          ? mergeSchemas(properties[key]!, schema)
          : schema;
    });
  }
  // The union requires the *intersection* of required keys: a key is
  // only required when both observations require it.
  final required = <String>{
    if (a.required != null && b.required != null)
      ...a.required!.where(b.required!.contains),
  };
  return JsonSchema(
    type: type,
    description: a.description ?? b.description,
    properties: properties.isEmpty ? null : properties,
    required: required.isEmpty ? null : (required.toList()..sort()),
    items: a.items == null || b.items == null
        ? null
        : mergeSchemas(a.items!, b.items!),
    // Widening: the union's minimum is the smaller bound and its
    // maximum the larger — but an absent bound is unconstrained.
    minimum: a.minimum == null || b.minimum == null
        ? null
        : (a.minimum! < b.minimum! ? a.minimum : b.minimum),
    maximum: a.maximum == null || b.maximum == null
        ? null
        : (a.maximum! > b.maximum! ? a.maximum : b.maximum),
    enumValues: a.enumValues == null || b.enumValues == null
        ? null
        : {...a.enumValues!, ...b.enumValues!}.toList(),
    additionalProperties:
        a.additionalProperties == null || b.additionalProperties == null
            ? null
            : (a.additionalProperties! || b.additionalProperties!),
  );
}
