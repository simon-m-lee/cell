ContextBridge

ContextBridge class abstract interface

The translation layer that converts external identities into internal framework provenance.

In the framework's biological metaphor, ContextBridge acts as the Membrane Translator. It ensures that every Nervous Signal (request) arriving at the Skin Membrane is stamped with a verified identity before it begins its Command Journey.

When to use

  • Identity Mapping: Use this to define how credentials extracted from the wire (like JWTs or API keys) map to the framework's internal security model.
  • Provenance Enforcement: Required to ensure that every Somatic State Transition triggered by a remote actor is correctly attributed in the Forensic Ledger.

How it works

  1. Signal Ingress: A WireRequest hits the membrane carrying a SkinPrincipal.
  2. Translation: The bridge's resolve method is called to convert that principal into a framework Context.
  3. Stamping: The resulting context is attached to the pulse, becoming the authoritative "who" for the entire journey.

Non‑obvious behavior

  • Integrity Gate Prerequisite: Most Integrity Gates within cells rely on the output of this bridge to decide whether to accept or reject a transition.
  • Forensic Traceability: If this bridge is misconfigured, the Forensic Ledger will record the wrong provenance, creating a "Forensic Hole" in your audit trail.
  • Least Privilege: By default, the membrane treats incoming signals as untrusted. The bridge is the only way to elevate privilege for a specific journey.

See also

  • SkinPrincipal: The external identity being translated.
  • Context: The internal provenance record.
  • SkinAuth: The mechanism that provides the principal to this bridge.
