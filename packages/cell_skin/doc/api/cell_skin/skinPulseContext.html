The request PulseContext a transport builds for an authenticated caller.

The actor is skin:<principal id> (alice becomes skin:alice; anonymous becomes skin:anonymous — the id is used as-is, never stripped or stacked). A JSON snapshot of the principal — id, roles, and the claims jsonEncode accepts — rides in others under skin.principal, so the router can rebuild the principal for SkinCall and an authorizer. The bearer token is never copied.

Implementation

PulseContext skinPulseContext({
  required SkinPrincipal principal,
  required Context baseContext,
  required String reason,
}) =>
    PulseContext(
      baseContext: baseContext,
      actor: 'skin:${principal.id}',
      reason: reason,
      others: {'skin.principal': _encodableSnapshot(principal)},
    );
