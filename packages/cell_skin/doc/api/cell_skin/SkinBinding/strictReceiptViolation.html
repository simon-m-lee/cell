The strict-receipts verdict for a successful apply, or null when the write shape is the one this binding promises.

A state binding must have written exactly one row whose receipt id is the apply receipt (an update() inside the function produces a synthetic _emit row and fails). A raw binding may write zero rows, but every row it writes must carry the apply receipt. A command binding is exempt: its inner applies own the rows.

Implementation

String? strictReceiptViolation(
  List<LedgerEntry> written,
  ApplyOutcome<Object?> outcome,
) {
  switch (_write) {
    case _SkinWrite.command:
      return null;
    case _SkinWrite.state:
      if (written.length == 1 &&
          written.single.receipt.id == outcome.receipt.id) {
        return null;
      }
      if (written.isEmpty) {
        return 'ledgered binding "$cellId.$functionName" did not append '
            'its apply receipt';
      }
      return 'ledgered binding "$cellId.$functionName" appended a receipt '
          'that is not the apply receipt';
    case _SkinWrite.raw:
      if (written.isEmpty ||
          written.every((entry) => entry.receipt.id == outcome.receipt.id)) {
        return null;
      }
      return 'ledgered binding "$cellId.$functionName" appended a receipt '
          'that is not the apply receipt';
  }
}
