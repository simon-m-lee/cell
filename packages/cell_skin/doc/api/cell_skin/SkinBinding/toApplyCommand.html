Builds the framework ApplyCommand for a decoded WireRequest.

Positional wire arguments arrive as a JSON object whose keys must be a contiguous 0..n-1 integer range — order is taken from the keys, never from JSON object insertion order (JSON objects are unordered by spec). Named wire arguments are decoded into the framework's Map<Symbol, Object?> convention.

For a SkinBinding.state binding the command function is a wrapper that Function.applys the stored user function and returns the result as a Pulse stamped with the ambient SkinCall's context (an existing Pulse passes through — re-stamped only when it carries no actor; a Future is unwrapped first). A command binding's positional calls get a return-value wrapper that stamps a returned pulse the same way; anything else (the true from a txApply batch) is unchanged. Raw bindings keep the user function itself on the command — authors who want the actor on the row return SkinPulses.payload(...).

Dart has no variadic closures, so the wrappers accept positional wire arguments through optional positional parameters (up to 12) and forward the collected prefix. A state or command binding called with named wire arguments is refused with bad_arguments — there is no generic named wrapper, so letting it through would silently drop the return-value wrapping (and, on a ledgered membrane, fail the strict-receipt check after the row was written). An empty named: {} is treated as absent.

Implementation

ApplyCommand toApplyCommand(WireRequest request) {
  final positional = _orderedPositional(request.positional);
  final named = _namedSymbols(request.named);
  final positionalOnly = named == null;
  if (!positionalOnly &&
      (_write == _SkinWrite.state || _write == _SkinWrite.command)) {
    throw BadArgumentsException(
        'named arguments are not supported for this binding; '
        'pass positional arguments');
  }
  final wrapsState = _write == _SkinWrite.state && positionalOnly;
  final wrapsCommand = _write == _SkinWrite.command && positionalOnly;
  return (
    function: wrapsState
        ? _stateWrapper(function, null)
        : wrapsCommand
            ? _commandWrapper(function, null)
            : function,
    arguments: (
      positionalArguments: positional,
      namedArguments: named,
    ),
    compensation: compensation == null
        ? null
        : (
            function: wrapsState
                ? _stateWrapper(compensation!, null)
                : compensation!,
            arguments: (
              positionalArguments: positional,
              namedArguments: named,
            ),
            cell: compensationCell ?? target,
          ),
  );
}
