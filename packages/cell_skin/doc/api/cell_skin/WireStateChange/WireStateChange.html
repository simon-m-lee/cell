Creates a new WireStateChange observation envelope.

In the framework's biological metaphor, this constructor assembles a Somatic Observation. It represents a Nervous Impulse generated when a cell changes its physical state, ready to be broadcast across the Skin Membrane.

When to use

  • Observation Streaming: Use this when a cell's state changes and you need to notify external subscribers (via SSE, MCP, etc.).
  • Testing: Use this to simulate state transitions in integration tests or to verify observer behavior.

How it works

The constructor bundles the cell's address (cellId), its new observable traits (payload), and its forensic evidence (receipt) into a stable record. By default, new observations are marked as pendingReceipt until the Forensic Ledger confirms the write.

Parameters

  • cellId: The Somatic Address of the cell that changed.
  • payload: The Phenotype (value) of the cell after the transition.
  • receipt: The Forensic Receipt providing proof of the change.
  • pendingReceipt: Whether the transition is still "in-flight" and waiting to land in the permanent ledger.

Non‑obvious behavior

  • Volatile by Default: If not specified, pendingReceipt defaults to true. This assumes the impulse is live and unconfirmed until the ledger tail specifically emits an authoritative entry.
  • Stateless Construction: This constructor does not require a correlationId because observations are environmental broadcasts, not direct replies to a specific Command Journey.

See also

  • WireStateChange.cellId: The unique address of the target cell.
  • WireStateChange.pendingReceipt: The flag governing the authoritative status of this signal.
