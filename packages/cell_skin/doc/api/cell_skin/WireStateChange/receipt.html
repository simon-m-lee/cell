receipt property

WireReceipt? receipt
final

The forensic evidence for the state change, if available.

In the framework's biological metaphor, this is the Forensic Receipt. It provides the official proof from the Forensic Ledger that a Somatic State Transition has been physically recorded in the system's "DNA."

When to use

  • Verification: Use this to confirm the sequence number, timestamp, and authoritative signature of the cell's physical state.
  • Audit Trails: Essential for AI agents or external systems that need to maintain a perfect, chronological record of the system's evolution.

How it works

  1. Capture: When a change is committed to the permanent ledger, a receipt is generated.
  2. Broadcasting: This receipt is attached to the WireStateChange Nervous Impulse to serve as proof for all observers.

Non‑obvious behavior

  • Pending States: If pendingReceipt is true, this receipt usually represents the previous known transition. It is included to provide the last known authoritative context while the new impulse is still being ledgered.
  • Never Fabricated: The system never creates "fake" receipts. If the ledger has never recorded a change for this cell (e.g., in a volatile system), this field will be null.
  • Sequence Authority: The sequence number inside this receipt is the only legal way to determine the global order of events across the entire somatic graph.

See also

  • WireStateChange.pendingReceipt: The flag indicating if the current impulse is still waiting for its own receipt.
  • WireReceipt: The detailed structure of the forensic evidence.
