payload

payload property

Object? payload
final

The new state value of the cell, provided as a JSON-serializable object. /// In the framework's biological metaphor, this is the Phenotype. It represents the observable traits of the cell immediately following a Somatic State Transition.

When to use

  • UI Updates: Use this to reflect the latest state of a cell in a dashboard or view.
  • External Logic: Used by AI agents or external systems to react to data changes without querying the Forensic Ledger.

How it works

  1. Capture: When a cell value changes, the framework attempts to serialize the new value.
  2. Broadcasting: This value is wrapped as the payload of a Nervous Impulse (WireStateChange) and pushed through the Skin Membrane.

Non‑obvious behavior

  • Omission on Failure: If a value cannot be encoded into JSON, this field is omitted (set to null). In such cases, the observer should refer to the receipt or the ledger entry for the authoritative data.
  • Volatile State: When pendingReceipt is true, this payload represents an unconfirmed "live" state that has not yet been physically committed to the permanent ledger.
  • Forensic Separation: While this field is convenient for live reactivity, the receipt remains the only legal proof of the underlying state change.

See also

  • WireStateChange.cellId: The somatic address where this phenotype exists.
  • WireStateChange.receipt: The forensic evidence confirming this value.
