Converts the observation into a JSON-safe map for transport.

In the framework's biological metaphor, this method creates the Skin Form of the state change. It prepares the Somatic Observation to cross the Skin Membrane so it can be broadcast to the environment.

When to use

  • Egress: Use this when a server, MCP host, or SSE bridge needs to serialize a live state transition for external subscribers.
  • Persistence: Used to store a snapshot of an observation in transport-level logs or message queues.

How it works

  1. Signal Labeling: It includes the kind ('stateChange') so the receiver knows this is an environmental broadcast, not a response.
  2. Somatic Addressing: It embeds the cellId so observers know exactly where in the body the transition occurred.
  3. Phenotype Encoding: It includes the payload (the value) if it is serializable.
  4. Forensic Evidence: It attaches the receipt to provide the authoritative proof from the Forensic Ledger.

Non‑obvious behavior

  • No Causal Link: Unlike WireResponse.toJson, this map does not contain a correlationId. It is a broadcast of a physical fact, not a direct reply to an impulse.
  • Pending Status: The pendingReceipt flag is included to tell the receiver if the change is already part of the permanent "DNA" or if it is a volatile, in-flight signal.
  • Omission Safety: Fields that are null (like a non-serializable payload or a missing receipt) are omitted from the map to keep the Skin Form lean.

See also

  • WireStateChange.fromJson: The reverse process for decoding signals.
  • WireReceipt.toJson: How the forensic evidence is serialized.

Implementation

@override
Map<String, Object?> toJson() => withWire({
      'kind': kind,
      'cellId': cellId,
      if (payload != null) 'payload': payload,
      if (receipt != null) 'receipt': receipt!.toJson(),
      'pendingReceipt': pendingReceipt,
    });
