Decodes a raw JSON map into a WireStateChange observation.

In the framework's biological metaphor, this factory acts as the Signal Decoder at the Skin Membrane. It translates the Skin Form of a somatic event back into a structured Nervous Impulse that the local system can process.

When to use

  • Egress Processing: Use this when a client (AI agent, web app, or remote listener) receives a state broadcast from a cell over a network bridge (SSE, MCP, etc.).
  • Synchronization: The primary entry point for external observers to ingest updates and keep their local "Phenotype" in sync with the living graph.

How it works

  1. Address Resolution: It extracts the cellId to identify the Somatic Address where the change occurred.
  2. Phenotype Mapping: It pulls the payload representing the new observable state of the cell.
  3. Forensic Verification: It attempts to decode the receipt to attach authoritative proof from the Forensic Ledger.
  4. Authoritative Check: It determines the stability of the signal via the pendingReceipt flag.

Non‑obvious behavior

  • Volatile Default: If pendingReceipt is missing from the JSON, it defaults to true. This follows the principle that a signal is "unconfirmed" until the Forensic Ledger explicitly clears it.
  • Null Phenotypes: If the payload is missing, it implies the state was not serializable. The decoder still creates the object, but the observer should rely on the receipt for sequence data.
  • Recursive Decoding: It utilizes WireReceipt.fromJson to maintain the integrity of the audit trail during the decoding process.

See also

  • WireStateChange.toJson: The reverse process for broadcasting signals.
  • WireMessage.fromJson: The top-level membrane decoder.
  • WireReceipt.fromJson: The decoder for the attached forensic proof.

Implementation

factory WireStateChange.fromJson(Map<String, Object?> json) =>
    WireStateChange(
      cellId: json['cellId'] as String,
      payload: json['payload'],
      receipt: json['receipt'] == null
          ? null
          : WireReceipt.fromJson(
              (json['receipt'] as Map).cast<String, Object?>()),
      pendingReceipt: json['pendingReceipt'] as bool? ?? true,
    );
