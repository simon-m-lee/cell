McpAdapter

McpAdapter class abstract interface

The lifecycle contract for bridging the somatic graph to an AI agent via the Model Context Protocol.

In the framework's biological metaphor, McpAdapter is the AI Synaptic Bridge. It acts as a specialized Membrane Pore designed specifically for high-bandwidth communication with external AI "nervous systems."

While SkinMembrane handles the general boundary logic, this adapter provides the physical transport seam. It allows an AI agent to perform a Discovery Impulse to read the Somatic Index (manifest) and subsequently trigger Command Journeys via MCP tool calls.

Why this exists

This interface decouples the framework's governance from specific MCP SDK implementations. By providing a neutral seam, the framework can support different SDKs (like dart_mcp or mcp_dart) without altering the internal somatic logic.

How it works

  1. Sensitization: On start, the adapter opens a communication channel.
  2. Discovery: It exposes the SkinManifest as a set of MCP Tools and Resources.
  3. Pulse Ingress: External tool calls are converted into Nervous Signals and dispatched through the membrane.
  4. Forensic Return: The results of Somatic State Transitions are translated back into MCP-compliant tool responses.

Non‑obvious behavior

  • Neutral Translation: The adapter must use mcpToolSpecs to ensure that tool names and schemas are deterministic and round-trippable.
  • Forensic Integrity: The adapter is responsible for ensuring that transport-level MCP errors are correctly reported as Membrane Rejections (WireError) to prevent gaps in the external audit trail.
