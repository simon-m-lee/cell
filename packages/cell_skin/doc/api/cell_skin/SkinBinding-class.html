SkinBinding

SkinBinding class final HowTo · Bindings HowTo · Cursors

AI Agent Guide

Layer: Skin — this is the exposure declaration, not the command itself. When to use: a requirement says "expose X on cell Y", "tools/list should show Z", "this command must be serialisable", or "positional calls must map to schema property names" (pass positionalNames). When NOT to use: declaring graph behaviour — gates belong to the cell's TestCell, not the binding. Live signature: const SkinBinding({required String cellId, required String functionName, required Cell target, required Function function, String? description, JsonSchema? argumentSchema, bool strictCursor = false, Function? compensation, List<String>? positionalNames}) — plus SkinBinding.state(...) and SkinBinding.command(...) with the same extra parameters — pinned at cell_skin: 1.0.0 Stability: stable Do NOT confuse with: SkinWhitelist (policy over bindings) or SkinBindingTable (the sealed registry). Guide: FEATURES-Skin.md §4 (binding table and whitelist). Example: example/lib/mock/mock_home.dart (every Echo Home tool is one binding). Cross-layer: binding.target.apply runs the cell's own TestCell gate — the second gate. Minimal compilable example

final target = Cell.state<int>(initial: 20);
final binding = SkinBinding(
  cellId: 'thermostat',
  functionName: 'setTarget',
  target: target.cell,
  function: (int value) => target.update(value),
);
