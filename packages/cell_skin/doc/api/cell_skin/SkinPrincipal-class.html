SkinPrincipal

SkinPrincipal class final

The resolved identity DNA of an external actor at the membrane.

In the framework's biological metaphor, SkinPrincipal is the Resolved Identity DNA. It represents the stable chemical signature of an actor after their Environmental Markers (SkinCredentials) have been verified by the Identity Gatekeeper (SkinAuth).

This identity is the source of all Provenance. Before a Nervous Signal can begin a Command Journey into the somatic graph, the ContextBridge translates this principal into an internal framework Context.

When to use

  • Auth Result: The primary return type for SkinAuth.authenticate.
  • Identity Mapping: Used by the ContextBridge to determine what level of authority to grant to the resulting pulse.

How it works

  1. Verification: SkinAuth validates the incoming credentials.
  2. Identification: This class is instantiated with the actor's unique id and roles.
  3. Translation: The membrane passes this principal to the bridge, which stamps the pulse with somatic authority.

Non‑obvious behavior

  • Forensic Persistence: The id provided here is what ultimately appears in the Forensic Ledger. Choosing a stable, unique ID is critical for long-term audit integrity.
  • Skin-Only Boundary: Somatic cells (the core graph) never interact with SkinPrincipal directly. They only see the Context produced by the Membrane Translator.
  • Anonymity: If no identity is provided, the system defaults to the Neutral Signature (SkinPrincipal.anonymous).

See also

  • SkinAuth: The gatekeeper that produces this identity.
  • ContextBridge: The translator that turns this principal into somatic authority.
  • WireLedgerEntry: Where this identity eventually leaves a forensic mark.
