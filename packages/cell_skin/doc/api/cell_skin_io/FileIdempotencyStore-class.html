FileIdempotencyStore

FileIdempotencyStore class final

The durable sibling of MemoryIdempotencyStore.

Implements the same IdempotencyStore interface; the file-only details (the log, the lock file, the lease) live here. A second FileIdempotencyStore opened on the same directory sees a completed record and claim returns IdempotencyReplay; across processes the next claim after leaseUntil returns IdempotencyOwned.

TTL and the cap match the memory store: expired completed lines and completed lines past maxEntries are dropped when the log is rewritten under the lock — never by a timer — and an in-flight line is never the eviction victim. A crash after the domain commit and before complete can still double-apply; complete is what makes the retry safe.
