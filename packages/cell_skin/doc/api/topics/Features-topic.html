1. What cell_skin Is

A transport membrane over a Cell graph: a sealed wire vocabulary, a four-cell pipeline, a binding table, a closed-by-default REST adapter, an MCP seam, and two Dart clients. The graph keeps its own gates, ledger, and replay; the skin only translates and enforces exposure.

2. Status and Boundaries
In scope Commands over REST/MCP/Dart; state observation; audit streaming; exposure policy; remote identity.
Out of scope The decision layer (cell_flow), the books (cell_tissue), an MCP transport (the McpAdapter is a seam for SDKs like dart_mcp), and inventing receipts the graph never produced.
Version 0.1.0 — pre-1.0; the wire vocabulary may evolve before 1.0.

3. Wire Vocabulary

One sealed hierarchy, one intent per variant:

  • WireRequest — a command. correlationId is server-assigned; clientCorrelationId is the caller's echo-only id. Positional arguments accept a JSON array or an index-keyed object; named arguments are validated identifiers.
  • WireResponse — the target's real ApplyOutcome, or pendingReceipt for an accepted pulse whose entry has not landed. Decoded responses carry outcomeJson (WireOutcome) so the result survives JSON.
  • WireStateChange — a state observation with an optional receipt. No correlation id: egress is not a reply.
  • WireError — pre-apply rejections with stable codes: unknown_tool, bad_arguments, cursor_required, conflict, transport_error, plus transport-level codes.
  • WireNotification — fire-and-forget; request() on one throws ArgumentError.
  • WireManifestRequest/WireManifestResponse — tool catalogue.
  • WireLedgerEntry — one audit entry via LedgerEntry.toJson.

Sanitising codecs (WireOutcome, wireReceiptJson, JsonSchema) guarantee the wire is always JSON-encodable: unencodable results, reasons, and arguments become labelled placeholders with resultOmitted/reasonOmitted/argumentsOmitted flags. fromJson throws FormatException on malformed input, never a raw TypeError.

4. Binding Table and Whitelist

  • SkinBinding binds (cellId, functionName) to a graph cell and its closure — with an optional description, declared argument schema, strict cursor, and compensation (which receives the same wire arguments as the command).
  • SkinBindingTable rejects duplicate registrations and seals at SkinMembrane.open — the manifest, egress set, and wire can never diverge.
  • SkinWhitelist is the declarative exposure policy. It covers applies, egress, /skin/observe/:cellId, and /skin/ledger. Entries with no matching binding produce startup policy warnings.
  • A binding's target must be identical to the graph's registered cell — anything else throws at open().

5. The Four-Cell Membrane

SkinMembrane.open assembles Cell.ingress → Cell.asyncMap (concurrency: 1) → target.apply → egress → mux → outbound over a graph, an optional ledger, and a transport writer. The API surface:

  • membrane.request(message, {type, context, timeout}) — emits one wire message and awaits its correlated WireResponse/WireError (or a WireManifestResponse).
  • membrane.responses — the broadcast of everything that survives the mux (responses, state changes, ledger entries).
  • membrane.manifest — the live tool catalogue.
  • membrane.isExposed(cellId) — binding + whitelist policy combined.
  • membrane.close() — idempotent; stops everything and fails pending requests with SkinError('closed').

Inbound pulses are governed (Pulse.governed) with per-request PulseContext; the default inbound context is least privilege (Context.describe('skin:untrusted')).

6. Receipt Provenance and Egress

  • The router packages WireRequest into ApplyCommand and hands it to target.apply — never its own apply — so every receipt stays attributable to the domain cell.
  • Ledgered membranes drive egress from Ledger.tail: the entry's own receipt pairs with the entry's own pulse payload (from the entry's canonical stored JSON).
  • Unledgered membranes observe targets with pendingReceipt: true always — a receipt is never fabricated, never borrowed from an earlier change.

7. Stateless Cursors

Opt-in strictCursor bindings require lastSeenSeq == ledger.head exactly:

Condition Result
cursor missing cursor_required (428 on REST)
cursor behind head conflict (409) — stale caller state
cursor ahead of head conflict (409) — cannot have seen current state
cursor == head proceeds

The cursor is the global ledger head by design (stateless server); the check-then-apply window is documented and intra-skin races are removed by the router's concurrency: 1.

8. Idempotency and Correlation

  • Server-assigned correlationId; the caller's clientCorrelationId is echoed, never matched by other waiters.
  • The router's bounded store is keyed by clientCorrelationId ?? correlationId. A duplicate key replays the stored outcome re-wrapped with the current request's ids — so a retry after a timeout returns the original result without double-applying.
  • RemoteCellClient ids include a monotonically increasing counter; SkinClient ids likewise.

9. Manifest and Schemas

SkinManifest.describe builds the tool catalogue from the binding table and optional whitelist:

  • Per-function descriptions (function.description → cell description), with cell ids and function names.
  • Argument schemas: explicit binding hint → observed current cell value (schemaForValue) → permissive. Observation widens correctly: type-only inference (no single-value enum/minimum == maximum), required is the intersection across objects, absent bounds mean unconstrained, int ∪ double → number, and array items merge every element's schema.
  • JsonSchema JSON round-trips are lenient on the way in (array type, schema-object additionalProperties) and never let stored extras re-spread over modelled keys.

10. REST Adapter

RestAdapter lives in cell_skin_rest.dart (the main barrel stays dart:io-free). bind() is closed by default — auth is required; anonymous access is the explicit AllowAllSkinAuth.

Route Behaviour
GET /health Liveness before auth.
POST /skin/apply Command → sanitised outcome; error map: unknown_tool 404, conflict 409, bad_arguments 422, cursor_required 428, timeout 504 outcome_unknown.
GET /skin/manifest Tool catalogue.
GET /skin/observe/:cellId SSE state changes; 404 for unexposed cells.
GET /skin/ledger?since=N SSE audit: backlog replay from the store, then the live tail, id: events, exposure filtering.
POST /skin/verify Structured verification; tamper failure → {ok: false, message}.

Transport hardening: Host loopback check, Origin rejection unless listed, method enforcement per route, JSON-only capped bodies, 401 with WWW-Authenticate, case-insensitive Bearer, per-request provenance from the ContextBridge. SSE runs over a detached raw socket with flush, keep-alive pings, silent-disconnect detection (activeSubscriptions returns to zero), and slow-client drop.

11. MCP Seam

McpAdapter.mcpToolSpecs(manifest) → neutral McpToolSpec / McpResourceSpec values: tool names <cellId>.<functionName> with dot-free, collision-checked parts, per-function descriptions, and schemas ready for any MCP SDK. cell_skin deliberately does not speak the MCP transport itself.

12. Clients

  • SkinClient — in-process: apply(...) (returns the outcome or null for pendingReceipt), observe(...) filtered to WireStateChange, manifest(), ledgerEntries().
  • RemoteCellClient — a cell-shaped facade over a remote membrane (counter-based correlation ids, private constructor + factory).
  • SkinError — one error type for the whole package.

13. Security SPI

  • SkinAuth — authenticate(SkinCredentials) → SkinPrincipal?; credentials carry the token plus transport metadata (peer, host, user agent).
  • AllowAllSkinAuth — the explicit anonymous opt-in.
  • ContextBridge — remote identity → framework Context; DescribeContextBridge (default), SystemContextBridge (the loud opt-in to system authority).
  • Per-request PulseContext(baseContext: bridge.resolve(principal), actor: 'skin:<id>', reason: ...) — the domain's TestCell gates see the remote actor.

14. Consistency and Lifecycle

  • Bindings seal at open(); egress/manifest/wire cannot diverge.
  • Binding targets must be the graph's registered cells.
  • close() is idempotent and total: no further pulses, no leaked observers, pending requests fail fast with SkinError('closed').
  • WireMessage.fromJson throws FormatException on malformed input.
