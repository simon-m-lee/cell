API Chooser — cell_skin

Layer: Skin — the membrane between a Cell graph and remote consumers (MCP hosts, REST clients, Dart clients). Does not own: graph nodes (cell), the decision (cell_flow), the books (cell_tissue).

Read this file when: a BRD sentence says "expose the graph over REST", "stream ledger entries", "bind a tool for MCP", "authenticate remote callers", or "observe cell state over the wire".

The full decision procedure lives in the layer docs; this matrix is generated from the ### AI Agent Guide blocks and cannot drift.
