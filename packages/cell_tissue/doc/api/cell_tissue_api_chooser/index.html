API Chooser — cell_tissue operators

Layer: Tissue — the books. Owns: the five collection types, TestTissue, deputies, .unmodifiable. Does not own: the decision (cell_flow), the glue (Cell.observe).

Read this file when: a BRD sentence says "record every Y", "reserve N units", "protected / guarded keys", "open incidents by X", "alert the supervisor", or "council reads, cannot delete".

The full decision procedure lives in HowTo-Mitose-Flow.md; this matrix is generated from the ### AI Agent Guide blocks and cannot drift.
