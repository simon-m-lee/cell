Asynchronously writes some elements of newContents into a range of this list. Copies the objects of newContents, skipping skipCount objects first, into the range from start (inclusive) to end (exclusive) of this list.

Wraps TissueList.setRange. The Future completes successfully if the operation is permitted. Otherwise, it completes with an error.

Parameters:

  • start: The inclusive start index of the range to write to.
  • end: The exclusive end index of the range to write to.
  • newContents: An Iterable<E> providing the source elements.
  • skipCount: (Optional) The number of elements to skip from the beginning of newContents. Defaults to 0.

Returns: A Future<void> that completes when the operation is done.
