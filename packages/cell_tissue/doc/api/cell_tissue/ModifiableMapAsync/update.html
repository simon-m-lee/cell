Asynchronously updates the value associated with key.

This method wraps the synchronous _tissue.update(key, update, ifAbsent: ifAbsent) call in a Future. If key is present, its value is replaced by the result of calling update with the old value. If key is not present and ifAbsent is provided, ifAbsent is called and its result is inserted into the map. If key is not present and ifAbsent is not provided, a StateError (or similar, depending on the underlying map implementation) is typically thrown by the synchronous operation, which would cause the Future to complete with an error.

Parameters:

  • key: The key whose associated value is to be updated.
  • update: A function that computes the new value from the old value.
  • ifAbsent: Optional. A function that computes a value if key is not present. If provided and key is absent, the result of ifAbsent is added to the map.

Returns: A Future<V> that completes with the new value associated with key.
