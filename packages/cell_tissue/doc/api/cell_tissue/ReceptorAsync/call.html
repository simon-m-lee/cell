Processes a pulse asynchronously.

When to use

Use this method to inject a pulse into the receptor without blocking.

How it works

  • The pulse is added to an internal queue.
  • A background worker drains the queue sequentially.
  • If serializedCompletion is true, the returned Future waits for the entire propagation wave to complete; otherwise, it resolves as soon as the pulse is queued.

Non‑obvious

  • The serializedCompletion parameter affects causal consistency. Use true when order and completion matter; false for fire‑and‑forget.
  • The worker is thread‑safe and uses the cell's lock.
  • If the pulse is a shell, it performs the reciprocal handshake before queueing.

Parameters:

  • pulse: The incoming pulse.
  • serializedCompletion: If true, waits for full propagation; if false, returns immediately after queueing.

Returns:

A Future that completes when the pulse is queued (or fully processed, depending on serializedCompletion).

Implementation

Future<void> call(PulseBase pulse, {bool serializedCompletion = true}) async {

  if (pulse is Shell) {
    return pulse.scrutinize(_receptor, null, {#serializedCompletion: serializedCompletion});
  }

  final cell = _receptor.cell;

  if (await pulse._checker.async.add(cell) == false) {
    return;
  }

  if (serializedCompletion == false) {
    // pulse = pulse.evolve(context: PulseContext(others: {'system#serializedCompletion': false}));
    pulse = _Pulse(parent: pulse, user: {#serializedCompletion: false});
  }

  await _queue.add(pulse);

  if (!_unawaitedLock.canLock) {
    return;
  }

  unawaited(_unawaitedLock.synchronized(() async {
    PulseBase? out;

    while (await _queue.isNotEmpty) {
      final p = await _queue.removeFirst();

      bool wait = true;
      final user = p._user;
      if (user != null && user.containsKey(#serializedCompletion)) {
        wait = false;
      }

      final lock = cell._nucleus.lock;
      if (lock != null) {
        out = await lock.synchronized(() async {
          final result = _receptor._onPulseReceived(p);
          return (result is Future<PulseBase?>) ? await result : result;
        });
      } else {
        final result = _receptor._onPulseReceived(p);
        out = (result is Future<PulseBase?>) ? await result : result;
      }

      if (out != null) {
        final synapses = cell._nucleus.synapses;
        if (synapses != Synapses.disabled) {
          if (wait) {
            await synapses.async.call(out);
          } else {
            unawaited(synapses.async.call(out));
          }
        }
      } else {
        p._complete();
      }

    }
  }));
}
