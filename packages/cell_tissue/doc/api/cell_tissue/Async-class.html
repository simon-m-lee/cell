Async

Async<C> class abstract

Async is a foundational marker interface and architectural contract used to identify the Asynchronous Proxy or Controller of a specific core component C.

In the cell.core framework, most primary entities (like Cell, Box, or Synapses) operate in a synchronous reactive domain to ensure immediate propagation and low latency. However, to interact with these entities from asynchronous contexts—such as the Dart Event Loop, background Workers, or high-concurrency triggers—a specialized "Async Handle" is required.

Architectural Role: The Concurrency Bridge

Async serves as the base for all *Async variants (e.g., ValueCellAsync). It indicates that the implementing class provides a Thread-Safe, Future-based API for the underlying synchronous component C.

  1. Serialized Access: Implementations of Async typically wrap calls to the principal component C using a synchronization Lock. This ensures that asynchronous "Reads" or "Writes" do not occur while a synchronous "Reactive Wave" is in progress.
  2. Non-Blocking Interface: While the principal C might throw errors or return false if a lock is held, the Async variant will await the lock, providing a smoother developer experience for long-running or high-contention tasks.
  3. Logical Linking: The generic type parameter C explicitly defines the Principal Identity. For every Async<C>, there is a strictly coupled synchronous instance of type C.

Design Pattern: Proxy & Controller

This interface is part of the "Principal vs. Controller" pattern. The Principal (C) owns the data and the reactive logic, while the Async implementation manages the temporal access to that data.

Usage Example:

// A synchronous ValueCell
final count = ValueCell<int>(value: 0);

// Its asynchronous counterpart (which implements Async<ValueCell<int>>)
final Async<ValueCell<int>> controller = count.async;

// Interacting via the Async contract
void updateScore() async {
  // The async handle ensures we wait for any ongoing transformations
  final current = await (controller as ValueCellAsync).value;
  print('Consistent value: $current');
}

Type Parameters:

  • C: The type of the Principal Component being managed. This is usually a subtype of Cell, Box, or another core framework entity.
