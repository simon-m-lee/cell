NucleusSimplest

NucleusSimplest typedef

NucleusSimplest = Nucleolus

A type alias representing the most primitive, zero-overhead implementation of the Nucleus contract.

NucleusSimplest points directly to Nucleolus, which is a specialized constant class used by the framework to represent a nucleus with no custom configuration, no extensions, and no principal inheritance.

Architectural Role:

  • Root of Inheritance: It serves as the terminal node in any Nucleus inheritance chain (the principal of all root-level nuclei).
  • Memory Efficiency: Because it maps to a const Nucleolus, it ensures that cells requiring only default framework behavior do not allocate unique memory for their property storage.
  • Semantic Clarity: While Nucleolus is the implementation detail, NucleusSimplest provides a clear semantic indication that the associated cell is using the "simplest" possible configuration (e.g., Context.system, Receptor.passThrough, and TestCell.allowAll).

Characteristics:

  • Immutable: As a constant implementation, its properties cannot be modified.
  • Stateless: It does not store any unique Cell bindings or Synapses observers.
  • Non-Extensible: It contains no extensions record and cannot carry ad-hoc metadata.

Typically accessed via the Nucleus.empty factory constructor.
