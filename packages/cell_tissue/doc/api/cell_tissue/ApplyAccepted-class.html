ApplyAccepted

ApplyAccepted<R> class final

The command was authorized, safety-checked, and successfully executed.

ApplyAccepted is the successful "receipt" returned by the framework when an action has been completed. It contains the data returned by your function and a detailed forensic record of the event.

In the framework's biological metaphor, this represents a Successfully Transmitted Signal that has updated the state of the reactive graph.

Why it is used

  • Successful Completion: It confirms that the command passed through the "Integrity Gate" and was executed by the cell's governance layer.
  • Result Delivery: It carries the actual value returned by the function, allowing you to use that data immediately in your UI or logic.
  • Forensic Confirmation: It provides the receipt, which allows you to track the exact ID and timestamp of this success in the ledger.

How it works

When a command is successful, the framework wraps the return value R into this object. Because ApplyOutcome is sealed, you can use a switch statement or pattern matching to safely extract the result only when the state is "Accepted."

Technical Details

  • Type-Safe Result: The result R matches the return type of the function you invoked, ensuring no data is lost or incorrectly cast.
  • Immediate State: Unlike ApplyStaged, an accepted outcome means the reactive graph has already been notified of the change.
