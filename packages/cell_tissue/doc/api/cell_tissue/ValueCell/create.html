A high‑level static factory that builds a ValueCell and its update handles in one step – used internally by Cell.value.

When to use

You don't call this directly – Cell.value does it for you.

How it works

It creates the cell from the nucleus, then returns a StateHandle with the cell and its update functions (trigger, triggerAsync, ingest).

Implementation

static StateHandle<V> create<V>(
    ValueNucleus<V> nucleus, {V? value}) {
  final cell = ValueCell<V>.fromNucleus(nucleus, value: value);
  final valueCellAsync = ValueCellAsync<V>(cell);
  final receptor = nucleus.receptor;

  Future<void> ingest(Pulse<V> pulse, {bool serializedCompletion = true}) {
    return receptor.async.call(pulse as PulseBase, serializedCompletion: serializedCompletion);
  }

  return (cell: cell, trigger: cell._trigger, triggerAsync: valueCellAsync._trigger, ingest: ingest);
}
