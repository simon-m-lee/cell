Executes the Validation Predicate and orchestrates the Chain of Responsibility for this rule.

This method serves as the operational entry point for Policy Enforcement and Integrity Gate resolution. It evaluates a stimulus (object)—typically a payload or a state transition—against the governing invariants.

Developer Ergonomics & Human Legibility

Developers typically don't call this directly. The framework invokes it automatically during validation. However, it can be called manually for testing:

final rule = TestRule<int>((object, {host, arguments, user}) {
  return object > 0;
});

final result = await rule.call(5); // true
final result2 = await rule.call(-1); // false

1. Hybrid Convergence: Sync/Async Orchestration

To support high-performance reactive waves alongside complex security checks (like database lookups or remote authority verification), the method returns FutureOr:

  • Synchronous Path: For standard invariants (e.g., range checks), it returns bool immediately, allowing the reactive wave to complete within the current call stack at Native Speed.
  • Asynchronous Path: For I/O-bound logic, it returns a Future, safely suspending the node's Conactive Lock until validation is complete.

2. Operational Pipeline

  1. Predicate Evaluation: Executes the primary validation logic. If the result is a Future, the method transitions into an asynchronous mode for the remainder of the validation.
  2. Short-Circuit Logic: If this rule is part of a composite chain, execution halts immediately if any segment returns false.
  3. Fail-Safe Resilience: To ensure Operational Resilience, unhandled exceptions within a validator are caught and treated as true (Pass). This prevents a faulty validator from paralyzing the System.
  4. Hierarchical Delegation: If all local conditions pass, the evaluation is delegated to the parent ancestor in the inheritance chain.

3. Example: Testing Validation

final rule = TestRule<int>((object, {host, arguments, user}) {
  return object >= 0 && object <= 100;
});

// Sync test
expect(await rule.call(50), isTrue);
expect(await rule.call(150), isFalse);

// Async test
final asyncRule = TestRule<int>((object, {host, arguments, user}) async {
  await Future.delayed(Duration.zero);
  return object >= 0;
});
expect(await asyncRule.call(5), isTrue);

Parameters:

  • object: The data, action, or payload being validated.
  • host: The host environment (typically a Cell) providing context for cross-field validation.
  • arguments: Optional metadata or execution parameters from the Pulse.

Returns:

true if all validation criteria are met; false if the operation is rejected by policy.

Implementation

FutureOr<bool> call(dynamic object, {C? host, dynamic arguments}) {
  FutureOr<bool> result = true;

  final rule = _rule;

  // Handle Primary Predicate
  if (rule != null) {
    try {
      result = rule(object, host: host, arguments: arguments, user: _user);
    } on Exception {
      rethrow;
    }
  } else { // Handle Composite Chain
    final rules = _rules;
    if (rules.isNotEmpty) {
      result = _evaluateChain(rules, 0, object, host, arguments);
    }
  }

  if (result is Future<bool>) {
    final parent = _parent;
    if (parent != null) {
      return result.then((passed) {
        if (!passed) return false;
        return parent.call(object, host: host, arguments: arguments);
      });
    }
    return result.catchError((e) => e);
  } else if (!result) {
    return false;
  }

  // Handle Hierarchical Delegation
  return _parent?.call(object, host: host, arguments: arguments) ?? true;

}
