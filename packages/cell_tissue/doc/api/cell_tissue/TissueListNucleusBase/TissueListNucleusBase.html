Primary Blueprint Constructor – Defines the immutable behaviour and storage strategy for a reactive list.

In the framework's biological metaphor, this constructor synthesizes the Initial DNA of a list. It establishes the structural constraints (growable vs. fixed-length) and the foundational integrity gates that will govern all cells derived from this nucleus.

When to use

  • Internal Implementation: This constructor is public specifically to allow concrete subclasses (like _TissueListNucleus) to invoke it via super().
  • Custom List Nuclei: Use this if you are extending the framework to create a specialized list type with unique storage needs.

Note: Standard application code should use TissueListNucleus.create or TissueListNucleus.evolve instead of calling this directly.

How it works

  1. Structural Selection: The growable flag determines the physical Container strategy:
    • true → Container.growableTrue: An ordinary, resizable list.
    • false → Container.growableFalse: A fixed‑length list.
  2. Bitmask Encoding: All governance parameters are passed to the TissueNucleusBase super-constructor, where they are packed into a memory-optimized, bitmask-enabled record.
  3. Immutability: Once constructed, the structural strategy is locked. Any future TissueListNucleus.evolve operations will maintain this core DNA.

Parameters:

  • bind: Ingress Link. An optional upstream Cell for the list to observe and mirror.
  • context: Operational Authority. The security tier and priority domain (default: Context.system).
  • receptor: Command Engine. The logic used to process mutations.
  • testRule: Integrity Gate. Validation rules that guard elements.
  • synapses: Signal Distribution. Manages egress connectivity and event broadcasting.
  • growable: If true, the list can change size. Defaults to true.
  • ephemeralPolicy: Lifecycle Governance. Defines the TTL for the collection state.
  • forceLock: If true, shares the principal's synchronization lock; otherwise, allocates a new one.
  • user: Extension Metadata. Optional record for domain-specific tags.
  • principal: Prototype Source. The parent nucleus from which this instance inherits its structural DNA.
