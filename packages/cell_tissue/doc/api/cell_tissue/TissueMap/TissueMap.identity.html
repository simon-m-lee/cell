Architectural factory for instantiating a TissueMap that utilises Referential Identity (identical) for key lookups and uniqueness.

This constructor is a specialised entry point for creating a reactive map where the "Identity" of a key is distinct from its "Value." It ensures that even if two keys have the exact same field values (equal via ==), they are treated as distinct entries if they are different instances in memory.

When to use

Use this when you need to track keys by identity rather than value. This is essential when keys are mutable objects (like Cells) whose internal state might change, which would break a value‑based map.

How it works

  • It creates a nucleus with identityMap: true.
  • The underlying storage uses LinkedHashMap.identity.
  • All key lookups and uniqueness checks use identical.

Example

final map = TissueMap.identity<MyKey, int>();
final key = MyKey('id');
map[key] = 42;
print(map[key]); // 42
