Creates a stack of pulse transformation rules.

When to use

This constructor is typically used via the PulseRule.chain() factory or the + operator. Developers rarely need to instantiate it directly.

Parameters:

  • rules: An ordered collection of PulseRules to be executed in sequence.
  • user: Optional context data passed to the rules during execution.
  • strategy: An optional override function. If provided, it executes instead of the default sequential iteration over rules. Use this for custom handling of the rule set.

Example: Custom Strategy

final customChain = PulseRule.chain(
  [rule1, rule2, rule3],
  strategy: ({required cell, required pulse, user}) {
    // Skip rule2 if the pulse is null
    if (pulse.payload == null) {
      return rule3.call(cell: cell, pulse: pulse);
    }
    // Execute normally
    return rule1.call(cell: cell, pulse: pulse)
        .then((r) => r != null ? rule2.call(cell: cell, pulse: r) : null)
        .then((r) => r != null ? rule3.call(cell: cell, pulse: r) : null);
  },
);
