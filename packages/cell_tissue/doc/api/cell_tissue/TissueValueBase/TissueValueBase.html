Constructs a TissueValueBase with the given properties and an optional initial value.

If value is provided, it is stored in the underlying container. If the value is a Cell, it is automatically linked to this tissue's synapses to ensure reactivity propagates from the element.

Parameters:

  • properties: A TissueValueNucleus<V> object that holds the configuration for this TissueValue. This is a required parameter.
  • value: An optional initial value V? to store in the TissueValue. If null or omitted, the TissueValue is initialized without a value.

Implementation

TissueValueBase(TissueValueNucleus<V> properties, {V? value})
    : super(properties as TissueValueNucleusBase<V,C>) {
  if (value != null) {
    properties.container.store.value = value;
    if (value is Cell) {
      _nucleus.synapses.link(value, downstreamCell: this);
    }
  }
}
