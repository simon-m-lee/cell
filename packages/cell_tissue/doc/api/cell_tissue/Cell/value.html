Creates a specialized Stateful Ingress Record, providing a managed interface for both persistent state representation and imperative mutation of a ValueCell.

The value static factory is a high-fidelity architectural tool designed for Stateful Ingress. Unlike Cell.ingress, which creates transient signal sources, Cell.value initializes a node that possesses its own physical memory container (Box) and maintains its state across reactive cycles.

When to use

This is the most common factory for application state. Use it whenever you need a piece of data that can be read and updated reactively.

How it works

  • value: The initial state (written directly to storage).
  • transform: A function that maps incoming pulses to new state. Return null to reject the update.
  • The returned StateHandle gives you a cell (for observation) and trigger/triggerAsync (for imperative updates).

Non‑obvious

The transform is only called when you use trigger or triggerAsync. Directly reading or writing cell.value bypasses the transform – use that only for reading, not for mutation.

Example: Counter

final counter = Cell.value<int>(
  value: 0,
  transform: (host, input, {user}) {
    final delta = input.payload as int;
    return Pulse(host.value + delta);
  },
);
counter.trigger(5); // value becomes 5
print(counter.cell.value); // 5

Parameters:

  • value: The initial state. This value is written directly to storage during initialization, bypassing the first transformation cycle.
  • transform: Optional. The Transformation Pipeline logic. It determines how the incoming input maps to the final committed state. If a user object is provided (either at initialization or during an update), it is injected into the third parameter of this closure to enable Context-Aware Transformations. Returning null rejects the commitment.
  • user: User-Provided Data. Optional contextual metadata or arbitrary identifiers passed through to the transform and receptor logic to enrich the transformation cycle.
  • bind: An optional upstream Cell to observe (Ingress). This creates a Dual-Input Node that reacts to both imperative triggers and automated upstream updates.
  • context: The operational Context (defaults to Context.system), defining the Authority Tier of the state changes.
  • receptor: The underlying transformation logic. Note: If transform is null and a custom receptor is used, ensure it handles state commitment to the internal Box.
  • testRule: A validation TestCell (Integrity Gate) that must approve the state change before it is committed.
  • synapses: The Signal Distribution Network (Egress) controlling propagation. Defaults to Synapses.enabled.
  • forceLock: If true, ensures the creation of an Atomic Transaction Domain via a mandatory Lock.

Returns:

A StateHandle (Record) providing:

  • cell: The persistent, stateful ValueCell instance (The Observable).
  • trigger: A synchronous gateway for manual state updates.
  • triggerAsync: An asynchronous, lock-protected version of the trigger.
  • ingest: A high-level ingress handle for standardized Signal Orchestration, supporting serializedCompletion for Stabilization Boundaries.
