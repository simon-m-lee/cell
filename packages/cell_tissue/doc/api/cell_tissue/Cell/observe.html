Synthesizes an Output Terminal designed to observe the reactive graph and trigger imperative side effects.

In the framework's Software Engineering (SE) Pivot, the observe factory creates a point of Signal Termination—the boundary where reactive Pulses exit the automated graph and are converted into real-world actions (e.g., UI updates, disk persistence, or hardware commands).

When to use

Use this when you need to react to a cell's changes with side effects: updating UI, writing to a database, sending a network request, or logging.

How it works

  • bind: the cell to observe.
  • onPulse: the callback that runs on each accepted pulse.
  • The returned EgressHandle gives you start() and stop() to enable or disable the observer.

Non‑obvious

This node is terminal – it has no downstream observers. It never propagates pulses further, so it cannot create loops.

Example: UI Update Observer

final uiUpdate = Cell.observe<int>(
  bind: counter.cell,
  onPulse: (pulse, {user}) {
    setState(() => count = pulse.payload);
  },
);
uiUpdate.start();

Parameters:

  • bind: The Ingress Source. The Cell instance to observe.
  • onPulse: The Side-Effect Logic. An imperative callback executed when a valid stimulus is received.
  • context: The Authority Level. Defines the security scope (defaults to Context.system).
  • testRule: The Integrity Gate. A TestCell used to screen signals before triggering the effect (defaults to TestCell.allowAll).
  • user: Contextual Metadata. An optional payload passed to the receptor for Causal Provenance.
  • initiallyStarted: Whether the observer should begin in an active state.
  • forceLock: If true, ensures the creation of an Atomic Transaction Domain via a mandatory Lock.

Returns:

An EgressHandle (Record) containing:

  • cell: The live observer node.
  • start: A closure to enable side-effect processing.
  • stop: A closure to disable side-effect processing.

Implementation

static EgressHandle<P> observe<P extends Pulse>({
  required Cell bind,
  required void Function(P pulse, {dynamic user}) onPulse,
  Context context = Context.system,
  TestCell testRule = TestCell.allowAll,
  dynamic user,
  bool initiallyStarted = true,
  bool forceLock = false
}) {

  final cancel = Box<bool>(!initiallyStarted);
  bool start() => cancel.value = false;
  bool stop() => cancel.value = true;
  final receptor = _Receptor(reaction: (pulse, cell, {dynamic user}) {
    if (cancel.value == false) {
      onPulse(pulse as P, user: user);
    }
    return null;
  }, user: user);
  final cell = Cell.governed(bind: bind, context: context, receptor: receptor, forceLock: forceLock,
      testRule: testRule, synapses: Synapses.disabled);
  return (cell: cell, start: start, stop: stop);
}
