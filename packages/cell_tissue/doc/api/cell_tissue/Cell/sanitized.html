Synthesizes a Sanitized Cell—a security-hardened node that automatically redacts Pulse payloads based on Sensitivity and Compliance.

The sanitized factory acts as a Sovereign Privacy Guard within the reactive graph. It ensures that sensitive data—such as PII or credentials— is programmatically stripped or masked before it propagates to less secure layers of the tissue.

When to use

Use this when you need to automatically redact sensitive information (PII, secrets) before it reaches observers that shouldn't see it.

How it works

  • bind: the upstream cell containing sensitive data.
  • redactor: a function that takes the sensitive pulse and returns a redacted version.
  • minSensitivity: the threshold at which redaction is applied. Pulses with sensitivity equal or higher will be redacted.

Non‑obvious

The redaction happens at the egress point – only outgoing pulses are sanitised. The original cell remains intact.

Example: PII Redaction

final raw = Cell.ingress<UserData>().cell;
final sanitized = Cell.sanitized<UserData>(
  bind: raw,
  redactor: (pulse) => Pulse(pulse.payload.copyWith(email: '***')),
);

Parameters:

  • bind: The Ingress Source. The upstream Cell containing the raw, potentially sensitive data.
  • redactor: The Sanitization Logic. A function that takes the sensitive pulse and returns a redacted/masked version.
  • minSensitivity: The Trigger Threshold. The Sensitivity level at which redaction is enforced (defaults to Sensitivity.confidential).

Returns:

A Cell that serves as a secure, privacy-aware filter for its source.

Implementation

static Cell sanitized<P extends Pulse>({
  required Cell bind,
  required P Function(P pulse) redactor,
  Sensitivity minSensitivity = Sensitivity.confidential,
}) {
  final receptor = _Receptor(reaction: (pulse, cell, {user}) {
    final p = pulse as P;
    final sensitivity = p.context.sensitivity;
    if (sensitivity != null && sensitivity.index >= minSensitivity.index) {
      return redactor(p);
    }
    return p;
  });
  return Cell(bind: bind, receptor: receptor);
}
