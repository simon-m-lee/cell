Creates a specialized Ingress Port, serving as a managed gateway for injecting external, imperative stimuli into the reactive graph.

The ingress static factory is the primary architectural mechanism for Imperative-to-Reactive Transition. It allows non-reactive components— such as UI event handlers, hardware sensors, or network callbacks—to communicate with the System by wrapping raw input data into a synchronized Pulse.

When to use

Use this when you have an external event source – e.g. a button click, a WebSocket message, or a sensor reading – that must be fed into the reactive graph.

How it works

The factory returns an IngressHandle record containing:

  • cell: the underlying reactive node (you can observe it).
  • trigger: a synchronous function to inject data (returns true if accepted).
  • triggerAsync: an asynchronous version that respects the cell's lock.
  • ingest: a low‑level entry point that takes a full Pulse (for advanced provenance).

Non‑obvious

  • If forceLock is true, the cell gets a dedicated lock, ensuring sequential processing of concurrent triggers. This is essential for high‑frequency external bursts.
  • The transform callback is optional; if omitted, raw input is passed through unchanged. Use it to sanitise or map external data into the expected pulse shape.

Parameters:

  • transform: Optional Transformation Logic. Defines how raw input is converted into a reactive Pulse.
  • user: Optional immutable metadata for Causal Provenance.
  • bind: An optional upstream Cell to observe, creating a Dual-Input Node.
  • context: The operational Context (defaults to Context.system).
  • receptor: The underlying Receptor logic.
  • testRule: A validation TestCell (Integrity Gate) that must approve the signal.
  • synapses: The Signal Distribution Hub (Egress).
  • forceLock: If true, ensures the creation of an Atomic Transaction Domain via a mandatory Lock.

Returns:

An IngressHandle (Record) providing:

  • cell: The live Cell instance representing this ingress port.
  • trigger: A synchronous gateway for manual input.
  • triggerAsync: An asynchronous, lock-protected version of the trigger.
  • ingest: A high-level ingress for direct Signal Orchestration, supporting serializedCompletion for Stabilization Boundaries.

static IngressHandle<I> ingress<I>({

  Pulse<I?>? Function(Cell host, Pulse<I> input, {dynamic user})? transform,
  dynamic user,

  Cell? bind,
  Context context = Context.system,
  Receptor receptor = Receptor.passThrough,
  TestCell testRule = TestCell.allowAll,
  Synapses synapses = Synapses.enabled,

  bool forceLock = false
}) {
  receptor = transform != null
      ? _Receptor(reaction: (pulse, cell, {dynamic user}) => transform(cell, pulse as Pulse<I>, user: user))
      : receptor;
  final cell = Cell.governed(bind: bind, context: context, testRule: testRule, synapses: synapses, receptor: receptor);
  bool trigger(I input) => cell._nucleus.receptor.call(Pulse<I>(input)) != null;

  Future<bool> triggerAsync(I input)  async {
    final lock = cell._nucleus.lock;
    if (lock != null) {
      return lock.synchronized(() => trigger(input)).then((value) => value);
    }
    return Future<bool>(() => trigger(input)).then((value) => value);
  }

  Future<void> ingest(Pulse<I> pulse, {bool serializedCompletion = true}) async {
    return await receptor.async.call(pulse as PulseBase<I>, serializedCompletion: serializedCompletion);
  }

  return (cell: cell, trigger: trigger, triggerAsync: triggerAsync, ingest: ingest);
}
