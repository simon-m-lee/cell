Synthesizes a Tissue Cell, a specialized structural node that performs Information Convergence by coordinating signals from a collection of source cells.

The tissue factory is the primary mechanism for Multi-Source Fusion. It allows the reactive graph to treat a set of disparate Cell instances as a single functional tissue, ensuring that the system can reason about a "Whole" composed of many "Parts."

When to use

Use this when you have multiple sources (e.g. sensors, streams) that you want to combine into a single logical output – sensor fusion, state aggregation, or combining multiple UI controls.

How it works

  • sources: a list of upstream cells.
  • aggregator: a function that receives the list of sources and the triggering pulse, and returns a new pulse (or null to drop it).

Non‑obvious

The tissue cell itself does not store state; it only reacts to changes from any of its sources. The aggregator is called for every pulse from any source.

Example: Sensor Fusion

final temperature = Cell.ingress<double>().cell;
final humidity = Cell.ingress<double>().cell;
final environment = Cell.tissue<EnvironmentalReading>(
  [temperature, humidity],
  aggregator: (sources, trigger) {
    return Pulse(EnvironmentalReading.from(sources));
  },
);

Parameters:

  • sources: The Iterable of upstream Cell instances to be synthesized into this tissue.
  • aggregator: The logic used to transform the collection of sources and the triggering Pulse (passed as the second argument to the closure) into the synthesized collective payload.
  • context: The Scene-Driven Ontology (Authority Tier) of this node.
  • testRule: The Integrity Gate (TestCell) that enforces system policy.
  • synapses: The Signal Distribution Hub for downstream propagation.
  • forceLock: If true, ensures the creation of an Atomic Transaction Domain via a mandatory Lock.

Returns:

A Cell instance (specifically a SynthesisCell) acting as a managed synthesis point for the provided sources.

Implementation

static Cell tissue<P extends Pulse>(Iterable<Cell> sources, {
  required P? Function(Iterable<Cell> cells, Pulse trigger) aggregator,

  Context context = Context.system,
  TestCell testRule = TestCell.allowAll,
  Synapses<P,Cell> synapses = Synapses.enabled,
  bool forceLock = false,
}) {
  final receptor = _Receptor(reaction: (pulse, cell, {user}) => aggregator(sources, pulse));

}
