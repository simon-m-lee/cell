Creates an OpenCell, a specialized Module Interface that exposes public control planes for manual signal injection and structural modification.

Unlike standard Cell instances, which are typically "Closed" or reactive-only nodes, an OpenCell is designed for Imperative Orchestration and Dynamic Topology. It serves as the primary gateway for bridging external systems or user interactions with the reactive Collection.

When to use

Use this when you need to manually control a cell – to inject pulses from outside the reactive graph, or to dynamically link/unlink observers at runtime.

How it works

  • receptor(pulse): manually send a pulse into the cell.
  • link(cell): manually attach a downstream observer.
  • unlink(cell): remove an observer.

Non‑obvious

An OpenCell is still governed by its testRule and context – manual pulses are validated just like reactive ones. This is not a backdoor.

Example: API Gateway Cell

final gateway = Cell.open(
  receptor: Receptor((cell, pulse, {user}) {
    // Handle incoming HTTP request
    return pulse;
  }),
);
gateway.receptor(Pulse(request)); // manual injection
final unlinker = gateway.link(serviceCell);

Parameters:

  • bind: An optional upstream Cell to observe, making the node a hybrid reactive-imperative relay.
  • receptor: The logic unit (Receptor) that processes incoming signals. Defaults to Receptor.passThrough.
  • testRule: The authoritative Integrity Gate (defaults to TestCell.allowAll). This governs all manual injections and structural modifications.
  • synapses: The synapse registry manager. Defaults to Synapses.enabled.
  • forceLock: If true, ensures the creation of an Atomic Transaction Domain via a mandatory Lock.

Returns:

An OpenCell serving as a governable, imperative gateway into the system.

Implementation

static OpenCell open({
  Cell? bind,
  Receptor receptor = Receptor.passThrough,
  TestCell testRule = TestCell.allowAll,
  Synapses synapses = Synapses.enabled,
  bool forceLock = false,
}) {
  return OpenCell(
      bind: bind,
      receptor: receptor,
      testRule: testRule,
      synapses: synapses,
      forceLock: forceLock,
  );
}
