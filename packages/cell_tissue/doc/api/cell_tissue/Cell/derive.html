Synthesizes a Derived Cell—a functional node that performs a pure, deterministic transformation on an upstream source.

The derive factory is the framework's primary implementation of the Map Pattern. It creates a reactive link between a source cell (bind) and a new output state, ensuring that every mutation in the parent is immediately reflected as a functionally derived pulse in the child.

When to use

Use this when you need a read‑only projection or transformation of another cell's data – e.g. formatting a user name, computing a derived value, or converting between types.

How it works

  • bind: the source cell.
  • transform: a pure function that takes the source pulse and returns a new pulse of a different type.
  • The derived cell automatically updates whenever the source changes.

Non‑obvious

The derived cell does not store state; it's a stateless transform. If you need to store the result, use Cell.value with bind instead.

Example: Data Transformation

final raw = Cell.ingress<Map<String, dynamic>>().cell;
final user = Cell.derive<Map<String, dynamic>, User>(
  bind: raw,
  transform: (input) => Pulse(User.fromJson(input.payload)),
);

Parameters:

  • bind: The Ingress Source. The principal Cell to be observed.
  • transform: The Derivation Logic. A pure function that maps the input pulse I to the output pulse O.
  • context: Operational Authority. Defines the Authority Tier (defaults to Context.system).
  • testRule: Integrity Gate. A validator (TestCell) that ensures the derived result satisfies the scene's ontological constraints.
  • synapses: Egress Network. Configures the Signal Distribution Hub for downstream observers.
  • forceLock: If true, ensures the creation of an Atomic Transaction Domain via a mandatory Lock.

Returns:

A Cell that represents a functionally derived projection of its source.
