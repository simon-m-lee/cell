Synthesizes a Conditional Gate—a specialized node that acts as a reactive circuit breaker, controlling signal propagation through the graph.

The valve factory is a primary mechanism for Dynamic Graph Pruning. It intercepts incoming stimuli from a source and, based on its internal state or policy, decides whether to "Open" (propagate the signal) or "Close" (suppress the signal).

When to use

Use this to filter or control the flow of pulses – e.g. debouncing a search input, rate‑limiting sensor data, or blocking signals during maintenance.

How it works

  • filter: a function that receives the pulse and returns it (to pass) or null (to block). If you return null, the signal stops there.
  • propagationPolicy: optionally control timing – e.g. debounce, throttle, batch.

Non‑obvious

The valve itself is a cell – you can observe its output (the pulses that pass through) just like any other cell. It does not store state; it only filters.

Example: Debounced Search Input

final searchGate = Cell.valve<String>(
  propagationPolicy: PropagationPolicy(
    strategy: PropagationStrategy.debounced,
    debounceTime: Duration(milliseconds: 300),
  ),
  filter: (pulse, {user}) => pulse.payload.isNotEmpty ? pulse : null,
);

Parameters:

  • propagationPolicy: Optional policy for managing Signal Distribution dynamics (e.g., Immediate vs. Batched).
  • filter: The Gate Logic. A function that determines if the signal should pass through. Returning null terminates the wave.
  • context: Operational Authority. Defines the security and priority tier (defaults to Context.system).
  • user: Optional immutable metadata for Causal Provenance.
  • downstreams: An optional set of specific Cell nodes to target for egress.
  • forceLock: If true, ensures the creation of an Atomic Transaction Domain via a mandatory Lock.

Returns:

A Cell instance acting as a managed gate for signal propagation.

Implementation

static Cell valve<P extends Pulse>({
  PropagationPolicy? propagationPolicy,

  P? Function(P pulse, {dynamic user})? filter,
  Context context = Context.system,
  dynamic user,
  Iterable<Cell>? downstreams,
  bool forceLock = false,
}) {
  final rule = filter != null ? FilterRule<P>(filter, user: user) : null;
  final synapses = Synapses<P,Cell>(filter: rule, downstreams: downstreams, policy: propagationPolicy);
  return Cell.governed(context: context, synapses: synapses, forceLock: forceLock);
}
