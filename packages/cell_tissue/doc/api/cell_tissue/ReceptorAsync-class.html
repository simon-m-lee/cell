ReceptorAsync

ReceptorAsync<C extends Cell> class

An asynchronous execution handle for a Receptor that facilitates non‑blocking pulse processing.

ReceptorAsync is obtained via receptor.async. It provides a Future- based API for processing pulses without blocking the current execution thread. This is essential for high‑throughput scenarios where you want to fire‑and‑forget or await the completion of a pulse's propagation.

Where to start

You get an instance from any receptor:

final receptor = Receptor((cell, pulse, {user}) => pulse);
final asyncReceptor = receptor.async;

When to use

Use the async view when:

  • You are in an asynchronous context (e.g., event handler, background task).
  • You need to wait for the entire propagation wave to finish before continuing (serializedCompletion: true).
  • You want to avoid blocking the UI or main thread.

How it works

  • The async receptor buffers incoming pulses in a thread‑safe queue.
  • A background worker drains the queue, processing pulses sequentially to preserve causal order.
  • Each pulse is processed within the cell's Lock to ensure atomicity.
  • The serializedCompletion flag controls whether the worker waits for all downstream propagation to complete before moving to the next pulse.

Non‑obvious

  • The queue is bounded only by memory; high‑frequency pulses without backpressure can lead to unbounded growth. Use with caution.
  • When serializedCompletion is false, the worker does not wait for downstream propagation – this can lead to causal races if not handled carefully.
  • The async receptor shares the same TestCell and Lock as the synchronous receptor – validation and concurrency are preserved.

Example: Awaiting Completion

final receptor = Receptor((cell, pulse, {user}) => pulse);
final async = receptor.async;

// Wait for the pulse to fully propagate through the graph
await async.call(Pulse(42), serializedCompletion: true);
print('Pulse fully processed');

Example: Fire‑and‑Forget

// No waiting – just queue and continue
unawaited(async.call(Pulse(42)));
