Processes an incoming Pulse via the cell's internal transformation logic.

This method acts as the public entry point for Pulse Ingestion.

Execution Logic:

  1. Authorization: Invokes the Integrity Gate (validate) to ensure the stimulus is permitted within the current Host Context.
  2. Transformation: If authorized, delegates to the internal Receptor logic stored in the Nucleus.
  3. Result Attribution: Returns the transformed output if successful, preserving the Causal Trace for downstream modules.
  • pulse: The input stimulus to be ingested.

Returns a FutureOr containing the transformed output pulse, or null if the action was rejected by governance or produced no state change.

Implementation

FutureOr<Pulse?> receptor(Pulse pulse) {
  final validation = validate(pulse, host: this);

  // Helper to execute the core receptor logic
  FutureOr<Pulse?> process() {
    try {
      return _nucleus.receptor.call(pulse);
    } catch (_) {
      return null;
    }
  }

  // 1. Branch: Asynchronous Path (Remote Governance/IO)
  if (validation is Future<bool>) {
    return validation.then((passed) => passed ? process() : null);
  }

  // 2. Branch: Synchronous Path (Native Speed)
  return validation ? process() : null;
}
