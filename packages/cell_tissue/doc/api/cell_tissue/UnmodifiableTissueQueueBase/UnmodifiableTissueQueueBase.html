Initializes a new UnmodifiableTissueQueueBase instance, anchoring a read‑only reactive queue (Double‑Ended Buffer) to its behavioral and structural blueprint.

This constructor is the internal structural initializer for the unmodifiable queue hierarchy. It bridges the gap between the TissueQueueNucleusBase configuration and the live reactive infrastructure, ensuring that the queue enters the graph with an established "Read-Only" barrier.

Purpose & Architectural Role:

The fundamental purpose of this constructor is to Hydrate a Fixed Reactive Node. Within the reactive ecosystem, an unmodifiable queue is not merely a static collection; it is a node in a Directed Acyclic Graph (DAG) that must maintain its integrity while allowing high‑performance, double‑ended observation.

This constructor facilitates:

  1. Logic Activation: It binds the provided property record to the queue instance, activating the synchronization lock and execution context required for "Conactive" (Concurrent + Reactive) operations.
  2. Immutability Enforcement: It prepares the instance to strictly prohibit structural changes, ensuring that any attempt to evolve the queue via standard methods (like addFirst or removeLast) is intercepted and denied.
  3. Recursive Safety (unmodifiableElement): It establishes the policy for deep immutability. If enabled, the queue ensures that member elements that are themselves reactive cells are accessed only as read‑only deputies.

Performance & Optimization (elements):

A critical feature of this constructor is its support for Pre‑computed Storage.

  • If elements are provided, the constructor triggers the creation of a specialized, dedicated storage container for the instance.
  • Efficiency Gain: In the Deputy Pattern (created via .view), providing pre‑resolved unmodifiable proxies of member cells allows this constructor to bypass "Lazy Projection" logic. This significantly optimizes iteration speed ($O(1)$ per access) for high‑frequency read operations in the UI layer.

Parameters:

  • nucleus: Required. The TissueQueueNucleusBase defining the queue's structural strategy, its synchronization domain, and its reactive blueprint.
  • unmodifiableElement: A boolean flag. When true, reactive elements retrieved from the queue are automatically projected as unmodifiable deputies.
  • elements: Optional. A pre‑mapped set of elements used to seed a dedicated high‑performance storage container for this specific instance.
