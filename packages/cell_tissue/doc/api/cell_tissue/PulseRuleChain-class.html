PulseRuleChain

PulseRuleChain<C extends Cell, I extends Pulse, O extends Pulse> class

A composite PulseRule that applies a sequence of rules to a pulse.

PulseRuleChain is created automatically when you use the + operator on rules. It executes rules in order, passing the output of one as the input of the next. If any rule returns null, the chain stops and returns null.

Where to start

You never need to instantiate this directly. Just chain rules with +:

final pipeline = rule1 + rule2 + rule3;

When to use

Use the + operator when you need a series of transformations or filters. The chain is the preferred way to build complex logic from simple rules.

How it works

  • Rules are executed in the order they appear in the chain.
  • Each rule's output becomes the next rule's input.
  • If a rule returns null, the chain stops and no further rules are run.
  • The chain handles both synchronous and asynchronous rules seamlessly.
  • Errors in individual rules are caught and logged; the pipeline continues with the last valid pulse to avoid breaking the entire chain.

Non‑obvious

  • The chain is resilient – exceptions are not propagated; they are caught and the chain continues with the last known good pulse.
  • If a rule returns a Future, the chain automatically switches to asynchronous mode and waits for it before continuing.
  • The chain can be extended with a custom strategy to override the default sequential execution (e.g., for branching or parallel execution).
  • The chain is stateless – it doesn't store any intermediate state between calls; state is carried in the pulse itself.

Example: Custom Strategy

final customChain = PulseRule.chain(
  [rule1, rule2, rule3],
  strategy: ({required cell, required pulse, user}) {
    // Skip rule2 if the pulse is null
    if (pulse.payload == null) {
      return rule3.call(cell: cell, pulse: pulse);
    }
    // Normal sequential execution
    return rule1.call(cell: cell, pulse: pulse)
        .then((r) => r != null ? rule2.call(cell: cell, pulse: r) : null)
        .then((r) => r != null ? rule3.call(cell: cell, pulse: r) : null);
  },
);
