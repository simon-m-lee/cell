Creates a base rule with a single transformation and rule logic.

This constructor initializes the rule by packing the rule function and optional user context into an internal memory-optimized record.

1. Architectural Role: The Logic Anchor

This constructor establishes the Causal Contract for the rule. It defines exactly how a stimulus should be processed relative to its host environment.

2. Hybrid Convergence: Multi-Tiered Execution

The rule function supports Hybrid Convergence by returning FutureOr. This allows the framework to execute zero-cost synchronous logic while retaining the ability to suspend the pulse for asynchronous Deputy Mandate audits.

  • rule: The core functional logic that maps an input Pulse to an output Pulse.
  • user: Optional context-specific metadata or Mandate data passed to the rule during execution.
