Executes the transformation logic of this rule with error handling.

This method invokes the underlying rule function. If the function executes successfully, its result is returned. If an exception is thrown during execution, it is caught silently, and the original input pulse is returned as a fallback to ensure the processing pipeline does not crash.

  • cell: The host Cell where the transformation is occurring.
  • pulse: The input pulse to be processed.

Implementation

@override
FutureOr<O?> call({required C cell, required I pulse}) {

  Pulse? out;

  try {
    final rule = _rule;
    out = rule != null
        ? rule(cell, pulse, user: _user)
        : pulse;
  } catch(e, stackTrace) {
    out = pulse;
    (pulse as PulseBase)._fail(e, stackTrace: stackTrace);
  }

  return out is O? ? out : null;
}
