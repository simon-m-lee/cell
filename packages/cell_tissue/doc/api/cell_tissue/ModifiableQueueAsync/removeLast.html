Future<E> removeLast()

Asynchronously removes and returns the last element of the associated TissueQueue.

This method wraps the synchronous _tissue.removeLast() call in a Future. The underlying removeLast() operation would typically throw a StateError if the queue is empty.

Returns: A Future<E> that completes with the element removed from the end of the queue. The Future will complete with an error (e.g., StateError from the underlying operation) if the queue is empty.

Implementation

  return Future<E>(() => _tissue.removeLast());
