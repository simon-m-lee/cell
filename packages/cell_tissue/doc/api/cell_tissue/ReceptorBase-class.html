ReceptorBase

ReceptorBase<C extends Cell> class abstract

The foundational base implementation of Receptor that provides the core synchronization and pulse propagation engine.

ReceptorBase is the concrete implementation used by all receptors. It manages the pipeline execution, error handling, and propagation to downstream synapses. You typically don't interact with this directly – you use the Receptor factory or the Receptor.passThrough constant.

Where to start

You never need to construct ReceptorBase directly. Use the Receptor factory or the predefined constants.

How it works

  • It stores the pipeline stages (preProcess, rule, postProcess) in a memory‑efficient record.
  • The call method validates the pulse, runs the pipeline, and broadcasts the result to the cell's synapses.
  • It handles both synchronous and asynchronous execution.
  • It integrates with the cell's TestCell for validation.

Non‑obvious

  • The receptor is activated when bound to a cell – this sets the cell getter and marks isActivated as true.
  • The clone method creates a shallow copy, useful for reusing logic across multiple cells.
  • The call method uses the pulse's _checker to prevent cycles.

See also: Receptor for the public API.
