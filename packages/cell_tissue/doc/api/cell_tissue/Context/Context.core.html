Synthesizes a Core Infrastructure Blueprint for foundational nodes, ingress switches, and architectural plumbing within the Switching Fabric.

This factory identifies high-authority System-Space nodes. It serves as the ontological anchor for the framework's internal orchestration layers and global signal management.

When to use

Use this for infrastructure nodes like gateways, hubs, or system services that operate at the highest priority.

How it works

The factory automatically sets domains: 'system', taxonomy: 'core', and priority: 0 (maximum precedence). You only need to provide a label (stored in partOf).

Example

final gatewayContext = Context.core('System_Gateway_01');

Parameters:

  • label: The identifier for this infrastructure component (e.g., 'Gateway'). Stored within Ontology.partOf.
  • others: Catch-all for specialized system metadata, hardware IDs, or cluster tags.

Implementation

factory Context.core(String label, {Map<String, dynamic>? others}) =>
    Context.fromEntries(
      [
        Ontology.partOf.entry(label),
        Ontology.taxonomy.entry('core'),
        Ontology.domains.entry('system'),
      ],
      others: {
        'priority': 0, // Maximum precedence for infrastructure orchestration
        ...?others,
      },
    );
