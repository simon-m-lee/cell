evolvable property

  1. @override
bool evolvable
final

Indicates whether this Mandate Dimension is a structural invariant or a dynamic operational attribute.

In the framework's Blueprint Synthesis model, the evolvable flag determines the "rigidity" of a governance pillar during a DeputyContext.evolve or Nucleus.evolve operation:

  • False (Static Pillar): The dimension is a structural invariant and must be inherited exactly from the principal. These anchors form the deputy's Causal Identity (e.g., Mandate.role, Mandate.authority).
  • True (Fluid Boundary): The dimension can be uniquely redefined or specialized within a downstream sub-mission. These boundaries reflect the Current Operational Scope (e.g., Mandate.constraints, Mandate.lease, Mandate.justification).

1. Architectural Role: Policy Cascading

This property governs the behavior of the evolve mechanism. When a DeputyContext is specialized for a sub-task, the framework filters the ontology based on this flag to ensure that core power—the "Static Pillars" of authority—cannot be expanded or "evolved away" by a delegate.

2. Developer Ergonomics

This flag helps developers understand which mandate aspects can be customized. Human developers typically interact with the pre-configured Mandate enum values where this flag is hard-coded to maintain Ontological Purity.
