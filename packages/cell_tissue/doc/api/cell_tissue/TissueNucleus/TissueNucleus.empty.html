TissueNucleus.empty

TissueNucleus<E>.empty constructor

const TissueNucleus<E>.empty()

A specialised, terminal factory for creating a Null Nucleus—a stateless, immutable configuration representing a collection that can never contain data and rejects all mutations.

The empty factory is a primary architectural implementation of the Null Object Pattern within the cell_tissue ecosystem. It is designed for scenarios where a Tissue identity is required by an interface or API, but the underlying state is conceptually "Never" or "Permanently Depleted."

When to use

Use this when you need a tissue placeholder that is guaranteed to be empty and immutable – e.g., as a fallback for a collection that is not yet initialised or for a terminal node in a graph.

How it works

  • The factory returns a singleton TissueNucleusNever instance.
  • This nucleus has no storage, no synapses, and a testRule that rejects all mutations.
  • It is the most memory‑efficient nucleus possible.

Non‑obvious

  • The resulting nucleus is not a deputy – it is a root nucleus with no principal.
  • Any tissue created from this nucleus will be empty and immutable.
  • It is a singleton – all calls return the same instance.

Example

final emptyNucleus = TissueNucleus.empty<int>();
final emptyList = Tissue.fromNucleus(emptyNucleus);
print(emptyList.length); // 0
// emptyList.add(1); // throws or silently fails

Returns:

A const TissueNucleus<E> that represents a permanently empty, read‑only, and non‑allocating reactive blueprint.

Implementation

const factory TissueNucleus.empty() = TissueNucleusNever;
