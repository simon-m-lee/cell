Creates a collective from the given pulses (which are actually TissueEvent<E> instances).

When to use

This is used internally by TissueEvent.batch and the + operator. You don’t call it directly.

How it works

All metadata (type, context, priority, callbacks) is taken from the first event in the iterable. The _branches counter is initialised to the number of events.

Parameters:

  • pulses: The events to bundle.
  • policy, type, context, timestamp, source, step: Optional overrides for the collective’s metadata.
  • onComplete, onError, onProgress: Optional callbacks for the entire batch.
  • pulse, parent, scrutinize, user, priority: Low‑level pulse‑related fields (rarely used directly).
