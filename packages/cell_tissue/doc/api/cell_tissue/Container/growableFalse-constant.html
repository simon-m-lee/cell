_Container const growableFalse

A strategy for Fixed‑Length List behaviour, where the structural dimensions of the collection are immutable after initialisation.

When to use

Use this when you need a collection with a constant size, such as a coordinate vector or a fixed‑size buffer.

How it works

  • The create function returns a fixed‑length List<E>.
  • The add function will throw if the list is full (or if the list is not growable).
  • The remove function works on fixed‑length lists (removes by value, shifting elements), but the length stays the same.

Non‑obvious

  • Even though the list is fixed‑length, you can still replace elements using index assignment. The add and remove methods operate on content, not structure.
  • This strategy is memory‑efficient for known‑size collections.

Implementation

static const growableFalse = _Container(create: _growableFalseCreate, add: _listAdd, remove: _listRemove);
