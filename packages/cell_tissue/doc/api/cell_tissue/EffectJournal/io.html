Record (or replay) an arbitrary I/O call. The value the caller's run closure returns is recorded (or the recorded value is served).

Parameters:

  • label: A stable semantic label for the call, e.g. 'http.GET /profile/42'. Replay compares it exactly.
  • input: The call's input; its fingerprint is recorded.
  • run: The closure that performs the real I/O. Not invoked on the replay side — the recorded output is returned directly, which is the mechanism by which replay avoids touching the network.
  • serializeOutput: Optional hook that converts run's result into a JSON-encodable form before it is stored. If not supplied, the raw result of run is stored directly and must be JSON-encodable — non-encodable results throw loudly at the fingerprint boundary.
