Creates a baseline Pulse instance, the primary data carrier used to initiate state updates and trigger system reactions.

When to use

Use this for most signals – it's the default constructor for a reason. It's lightweight, efficient, and covers 90% of use cases.

How it works

You provide a payload (the data), and the framework wraps it into an immutable, traceable signal. A timestamp is automatically recorded.

Example

final pulse = Pulse<int>(42);

Parameters:

  • payload: The Message Content. The primary data or instruction payload to be processed by handlers.

Returns:

A singular Pulse instance ready for propagation through the reactive network.

Implementation

factory Pulse([P? payload]) => _Pulse<P>(payload: payload);
