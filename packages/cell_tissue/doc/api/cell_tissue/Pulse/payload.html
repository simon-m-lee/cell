payload

payload property

P? get payload

The primary data or instruction payload carried by this signal.

When to use

Read this to get the data that was sent – it's the whole point of a pulse.

How it works

The payload is resolved by walking up the _parent chain to the root pulse. This means evolved pulses don't duplicate the payload – they inherit it from their ancestor, saving memory.

Non‑obvious

  • For composite pulses (created with +), this returns the payload of the first pulse in the bundle. To access individual payloads, iterate over the composite.
  • The payload is immutable – you can't change it; you create a new pulse with evolve if you need a different payload.

Example

final pulse = Pulse<String>('Hello');
print(pulse.payload); // 'Hello'
