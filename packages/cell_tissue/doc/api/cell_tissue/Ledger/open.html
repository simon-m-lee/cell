Future<Ledger> open({
  1. required CellGraph graph,
  2. required LedgerStore store,
  3. String? genesisHash,
})

Creates a ledger bound to graph and backed by store. The genesis hash is fingerprint({'graphId': graph.id}); the store's own genesisHash must match, or this throws — a store created for graph G can never silently serve graph H.

Parameters:

  • graph: The graph this ledger records.
  • store: The persistence backend.
  • genesisHash: Overrides the chain genesis — fork ledgers chain from their ForkRecord.genesisHash, not from the graph id.

Returns:

The opened ledger.

Implementation

static Future<Ledger> open({
  required CellGraph graph,
  required LedgerStore store,
  String? genesisHash,
}) async {
  final chain = HashChain(genesisHash ?? genesisHashOf(graph.id));
  if (store.genesisHash != chain.genesisHash) {
    throw StateError(
      'Ledger.open: store genesis hash "${store.genesisHash}" does not '
      'match graph "${graph.id}" (expected "${chain.genesisHash}"). '
      'Construct the store with Ledger.genesisHashOf(graph.id), or '
      'with the explicit genesis hash this ledger is chained from.',
    );
  }
  return Ledger._(graph, store, chain);
}
