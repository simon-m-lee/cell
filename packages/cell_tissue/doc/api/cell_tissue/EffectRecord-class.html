EffectRecord

EffectRecord class sealed

A single recorded non-deterministic observation.

How it works

Every field is a JSON primitive (except at, which is a DateTime serialised to ISO-8601 in toJson). The record is designed to be stored verbatim in the ledger, so its canonical form is pinned by this codec and never extended without a schema version bump.

Non-obvious: input/output digests, not raw values

Recording the value of every clock read or I/O response would blow up the ledger (a Future<Response> with a 10 KB body per call, times thousands of calls). The journal records the fingerprint of the input and the output instead, and stores the raw value in a side buffer only when the value is required to reconstruct (see IoEffect.rawOutput). This keeps the ledger compact and lets verify() detect tampering via hash mismatch, without storing secrets in the clear.

See also:

  • IoEffect — the only variant that carries a raw output.
  • EffectJournal — the boundary that produces and consumes these records.
