SyncCycleChecker

SyncCycleChecker class

A thread-safe, Synchronized Circular Dependency Guard for asynchronous reactive flows.

SyncCycleChecker extends the cycle detection logic to handle propagation waves that span across asynchronous boundaries or multi-threaded execution contexts. It ensures that the "visited" state of the reactive graph remains consistent and protected from race conditions during concurrent pulse transmissions.

1. Architectural Role: Thread-Safe Topology Protection

In a concurrent reactive network, multiple Pulse waves may be active simultaneously. The SyncCycleChecker provides:

  • Atomic Traversal: Uses an internal Lock to ensure that adding a node to the visited set is an atomic operation, preventing two concurrent branches of the same pulse from bypassing the cycle guard.
  • Asynchronous Coordination: Enables Receptors to safely check for circular dependencies even when the transformation pipeline involves Future results or cross-isolate communication.

2. Functional Mechanics

This class wraps a standard CycleChecker and gates all state-modifying operations behind a synchronization primitive. It is typically accessed via the async property of a base CycleChecker when a propagation wave transitions from a synchronous to an asynchronous execution tier.
