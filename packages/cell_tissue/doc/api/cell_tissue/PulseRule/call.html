Executes the transformation logic of this rule.

When to use

Typically you don't call this directly – the framework invokes it when a pulse arrives at a cell. You might call it for testing or manual invocation.

How it works

The rule receives the cell context and the input pulse, applies the transformation, and returns either a new pulse or null.

Non‑obvious

  • If the rule throws an exception, the error is caught and the original pulse is returned as a fallback, ensuring the pipeline doesn't break.
  • The return type is FutureOr – the rule can be synchronous or asynchronous.

Example: manual execution

final result = await rule.call(cell: myCell, pulse: Pulse<int>(5));
