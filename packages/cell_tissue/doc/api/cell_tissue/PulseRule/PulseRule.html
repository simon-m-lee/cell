Creates a PulseRule from a function.

When to use

This is the primary way to create a rule. Most rules are single‑function transformations.

How it works

The provided rule function is called with the host cell, the incoming pulse, and optional user data. It returns the transformed pulse or null to drop it.

Non‑obvious

  • The user parameter is a convenient way to pass configuration without creating a new class. It's not part of the pulse's context.
  • The rule function is wrapped in a try-catch; errors are caught and logged, and the original pulse is returned to keep the pipeline running.

Parameters:

  • rule: The function that transforms an input pulse I to an output pulse O.
  • user: Optional context data passed to the rule function during execution.

Example: Rule with Configuration

final multiplierRule = PulseRule<int, int>((cell, pulse, {user}) {
  final value = pulse.payload;
  final multiplier = user as int? ?? 1;
  return Pulse(value * multiplier);
}, user: 3); // Default multiplier is 3
