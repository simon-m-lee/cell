Synthesizes an Autonomous Inference Blueprint for signals originating from AI-driven reasoning, pattern recognition, or optimization tasks.

This factory serves as the architectural standard for Non-Deterministic Intent. It ensures that signals generated by Autonomous Agents (Managed Nodes) carry the necessary metadata—specifically confidence and AuditLevel.detailed auditing—to be properly governed within the Reactive Update Pipeline.

1. Architectural Role: Autonomous Optimization

In the framework's reactive model, inference signals represent Heuristic Adjustments. By defaulting to a probabilistic reasoning strategy and a background priority (20), this blueprint guarantees:

  • Background Execution: Ensures that autonomous optimizations do not preempt critical User Actions or System Homeostasis waves.
  • Telemetry for Transparency: Sets the auditLevel to AuditLevel.detailed, capturing the internal logic and perception state required for Explainable AI (XAI).
  • Scene-Driven Boundaries: Wraps the agent's proposal in a context that allows Integrity Gates (TestCell) to verify if the inference is compatible with the target node's Ontology.

2. Technical Mechanics: The Reciprocal Handshake

During the Ingress Phase, signals generated via this factory are subjected to a Confidence Challenge. Because the strategy is ReasoningStrategy.probabilistic, the Reciprocal Handshake (Bidirectional Mutual Authorization) protocol evaluates the confidence dimension against the receptor's confidence threshold. Signals that fall below the threshold are neutralized before they can trigger the Egress Phase.

3. Developer Ergonomics: Practical Example

Developers should use this factory when an AI agent proposes a state change based on observed patterns:

// An optimization agent suggests scaling a collection:
final inferenceContext = PulseContext.inference(
  baseContext: clusterOntology,
  actor: 'Heuristic_Optimizer_v2',
  reason: 'Detected high latency in somatic processing',
  confidence: 0.82,
  purpose: 'RESOURCE_SCALING',
);

// The resulting pulse is audited for XAI and governed by confidence gates.

Parameters:

  • baseContext: The ancestral Context (or Ontology) providing the baseline lineage and trace anchor.
  • actor: The specific AI model, agent instance, or heuristic engine.
  • reason: The functional justification or evidence for the inference.
  • confidence: The probability (0.0 to 1.0) of the signal's validity.
  • purpose: The high-level mission category, defaulting to 'AUTONOMOUS_OPTIMIZATION'.
  • priority: The relative urgency, defaulting to the background tier (20).

Implementation

factory PulseContext.inference({
  required Context baseContext,
  required String actor,
  required String reason,
  required double confidence,
  String? purpose,
  int priority = 20,
}) {
  return PulseContext.fromEntries([
    // --- Static Pillars (Non-Evolvable Identity) ---
    Provenance.actor.entry(actor),
    Provenance.traceId.entry(Identity.next()),
    if (baseContext is PulseContext)
      Provenance.parentTraceId.entry(baseContext.traceId!),
    Provenance.sensitivity.entry(Sensitivity.internal),

    // --- Fluid Boundaries (Evolvable Intent) ---
    Provenance.strategy.entry(ReasoningStrategy.probabilistic),
    Provenance.confidence.entry(confidence),
    Provenance.auditLevel.entry(AuditLevel.detailed),
    Provenance.priority.entry(priority),
    Provenance.purpose.entry(purpose ?? 'AUTONOMOUS_OPTIMIZATION'),
    Provenance.reason.entry(reason),
  ]);
}
