The primary factory constructor for Receptor, providing a streamlined way to create a functional pulse processor for a Cell.

When to use

This is the most common way to define a receptor – for a single transformation or filter step. It's simple and covers the majority of use cases.

How it works

You provide a function that receives the cell, the pulse, and optional user data. The function can return a modified pulse or null to filter. The framework wraps this function into a PulseRule internally.

Non‑obvious

  • If the function throws an exception, the error is caught and logged, and the receptor returns null to prevent propagation.
  • The receptor is stateless until activated (bound to a cell).

Example

final doubleReceptor = Receptor((cell, pulse, {user}) {
  final value = pulse.payload as int;
  return Pulse<int>(value * 2);
});

Parameters:

  • rule: A function defining the transformation or filtering logic. Returning null stops the pulse from propagating further.
  • user: Optional arbitrary data (e.g., a multiplier, a logging level, or a security scope) accessible within the rule.

Implementation

factory Receptor(FutureOr<Pulse?> Function(C cell, Pulse input, {dynamic user}) rule, {dynamic user}) {
  return _Receptor<C>(rule: PulseRule<C,Pulse,Pulse>((cell, pulse, {dynamic user}) {
    return rule(cell, pulse, user: user);
  }, user: user));
}
