Orchestrates the formal transition from Perception to Reasoning by executing the receptor's transformation logic within the host's Operational Perimeter.

When to use

You don't call this directly – the framework invokes it when a pulse arrives at the cell. It's the core method that processes the pulse.

How it works

The method:

  1. Checks if the pulse is a shell (defensive proxy); if so, performs the mutual authorization handshake.
  2. Validates the pulse against the cell's TestCell.
  3. Executes the receptor's pipeline (preProcess → rule → postProcess).
  4. Returns the transformed pulse or null.

Non‑obvious

  • The method handles both synchronous and asynchronous execution via FutureOr.
  • If the pulse is invalidated or the cell is invalidated, the call returns null.
  • The pipeline is wrapped in error boundaries; exceptions are caught and reported via the pulse's onError callback.
