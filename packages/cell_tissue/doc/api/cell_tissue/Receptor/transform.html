transform<C extends Cell, I extends Pulse, O extends Pulse> static method

Receptor<C> transform<C extends Cell, I extends Pulse, O extends Pulse>(
  1. PulseRule<C, I, O> rule
)

A static convenience factory that creates a type-safe Receptor specialized for transforming signals from one specific type to another.

When to use

Use this when you have a strongly‑typed transformation that maps one pulse type to another (e.g., Pulse<String> to Pulse<int>). It's more explicit and type‑safe than the generic constructor.

How it works

You provide a PulseRule that is typed with the exact input and output types. The receptor will only accept pulses of type I and will produce pulses of type O.

Non‑obvious

  • This is just a convenience wrapper around the primary constructor.
  • It provides better static analysis and code completion.

Example

final lengthReceptor = Receptor.transform<MyCell, Pulse<String>, Pulse<int>>(
  PulseRule((cell, pulse, {user}) {
    final text = pulse.payload;
    return text != null ? Pulse(text.length) : null;
  })
);

Type Parameters:

  • C: The concrete Cell type that will host this receptor.
  • I: The expected type of the incoming Pulse.
  • O: The type of the Pulse resulting from the transformation.

Implementation

static Receptor<C> transform<C extends Cell, I extends Pulse, O extends Pulse>(PulseRule<C,I,O> rule) {
  return _Receptor<C>(rule: rule);
}
