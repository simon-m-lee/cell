_PassThroughReceptor const passThrough

A canonical, stateless Receptor that performs an Identity Transformation on all incoming signals.

passThrough is the framework's default "Open Gate." It implements the simplest possible reactive behavior: every Pulse received by the Cell is immediately and transparently broadcast to all downstream observers via the cell's Synapses.

When to use

You typically don't need to specify this – it's the default if you don't provide a custom receptor. Use it explicitly if you're building a relay node that just forwards signals without transformation.

How it works

The receptor returns the input pulse unchanged. No validation, no transformation – just pass‑through.

Non‑obvious

  • This is a singleton; millions of cells can share it without memory overhead.
  • It provides no protection against invalid data – use a custom receptor if you need validation.

Implementation
