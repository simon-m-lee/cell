1. **Universal consensus (8/8):** The framework is deliberately not for typical Flutter use; the complexity targets audit-bound domains (payments, energy, safety telemetry); the author intends a "causally intelligible runtime," not a Riverpod competitor.
2. **Majority consensus (6/8):** The realistic end game is a **durable niche** with a possible **pivot toward AI-agent governance** — the one market with an urgent buyer for "why did the machine do that?"
3. **The key divergence:** not *what* the framework is, but *who arrives*. Bullish documents (Qwen, Gemini) extrapolate from the author's own narrative; skeptical documents (Kimi, Claude) weight verifiable adoption signals — which currently read as zero.
4. **Instructive correlation:** skepticism tracks evidence quality. The most skeptical documents cite the most checkable facts (stars, forks, Melos scripts, doc drift); the least skeptical fabricate or hallucinate. **Practical takeaway:** Kimi, Claude, Grok, and OpenAI form the reliable core; Dola is usable with caution; Qwen and Gemini should be treated as unreliable.
5. **Convergent falsification test:** every serious document converges on the same leading indicator — the Flutter binding package and any first external production adoption. That is where the prediction dispute will actually be decided.
