# Document_AI_MasterGenerator.md

**Version:** 1.0  
**Role:** Master entry point for all Mitose document generation.  
**Consulted by:** `HowTo-Mitose.md` before any individual generator is invoked.

## What a reader must understand

This script is the single place an agent consults when it needs to generate any Mitose document. It does not replace the individual generators. It routes the agent to the correct generator and records that the generator was followed. A document produced without going through this master script and then its corresponding generator is invalid.

## Document → Generator map

| Document | Generator script that MUST be followed | When |
|---|---|---|
| `<stem>-WalkThrough.md` | `WalkThrough-AI-Generator.md` | After BRD exists |
| `<stem>-Demo.dart` + `<stem>-test.dart` | `HowTo-Mitose.md` §5 (plus layer HowTos) | After WalkThrough |
| `<stem>-LEDGER.md` | `LEDGER-AI-Generator.md` | After Demo and test have been executed |
| `<stem>-COMPREHENSION.md` | `COMPREHENSION-AI-Generator.md` | At C1 (or recorded as declined in autonomous mode) |
| `<stem>-ARCHITECTURE.md` | `ARCHITECTURE-AI-Generator.md` | After Demo exists and WalkThrough §5.12 is filled |
| `<stem>-FEATURES.md` | `FEATURES-AI-Generator.md` | After Demo exists and WalkThrough §5.12 is filled |
| `<stem>-CHANGE-<nnn>.md` | `CHANGE-AI-Generator.md` | Change mode only |

## Procedure (both step-by-step and autonomous mode)

1. When `HowTo-Mitose.md` reaches a document-generation step, the agent **first** opens this file.
2. The agent locates the document in the table above.
3. The agent opens the corresponding generator script and follows it **exactly** (all required sections, blocks, and order).
4. The agent records in the run log:  
   `Document <name> generated by following <Generator>.md (via Document_AI_MasterGenerator.md)`.
5. If the generator cannot be read, the agent stops under `HowTo-Mitose.md` §15.8 and reports the missing file.

## Autonomous-mode note

Autonomous mode does not relax this procedure. The agent still consults this master script and then the individual generator. Ad-hoc writing of any document listed above is invalid.
