Creates a ForkRecord.

Parameters:

  • forkId: UUID identifying this fork.
  • originalLedgerId: UUID of the parent ledger's graph.
  • divergedAt: Sequence number in the parent ledger at which the fork was taken.
  • originalSnapshotHash: The parent graph's snapshot hash at divergedAt.
  • parentHeadHash: The hash of the parent ledger's entry at divergedAt.
  • at: Wall-clock time the fork was created.
