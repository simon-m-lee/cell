Primary Blueprint Constructor – Defines the immutable behaviour, capacity, and storage strategy for a reactive queue.

In the framework's biological metaphor, this constructor synthesizes the Initial DNA of a queue. It establishes the structural constraints (bounded vs. unbounded capacity) and the foundational integrity gates that will govern all cells derived from this nucleus.

When to use

  • Internal Implementation: This constructor is public specifically to allow concrete subclasses (like _TissueQueueNucleus) to invoke it via super().
  • Custom Queue Nuclei: Use this if you are extending the framework to create a specialized queue type with unique storage or backpressure needs.

Note: Standard application code should use TissueQueueNucleus.create or TissueQueueNucleus.evolve instead of calling this directly.

How it works

  1. Structural Selection: The physical Container is hardcoded to Container.queue – a high-performance double-ended buffer optimized for O(1) operations at both ends.
  2. Capacity Storage: The capacity (maximum element threshold) is stored in the others segment of the record, separate from the bitmask-governed operational properties.
  3. Bitmask Encoding: All governance parameters are passed to the TissueNucleusBase super-constructor, where they are packed into a memory-optimized, bitmask-enabled record.

Parameters:

  • capacity: The maximum number of elements (-1 for unbounded). Determines the backpressure limits of the DNA.
  • bind: Ingress Link. An optional upstream Cell for the queue to observe and mirror.
  • context: Operational Authority. The security tier and priority domain (default: Context.system).
  • receptor: Command Engine. The logic used to process mutations.
  • testRule: Integrity Gate. Validation rules that guard elements.
  • synapses: Signal Distribution. Manages egress connectivity and event broadcasting.
  • ephemeralPolicy: Lifecycle Governance. Defines the TTL for the collection state.
  • forceLock: If true, shares the principal's synchronization lock; otherwise, allocates a new one.
  • user: Extension Metadata. Optional record for domain-specific tags.
  • principal: Prototype Source. The parent nucleus from which this instance inherits its structural DNA.
