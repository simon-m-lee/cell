Creates a specialized Architectural Extension of an existing Nucleus to support hierarchical property inheritance and contextual overrides.

This factory constructor is the primary implementation of the Prototype-based Inheritance pattern (specifically the Deputy-Principal Relationship) within the framework. In its biological meta-language, evolve performs a directed Genetic Mutation, creating a descendant (Deputy) that inherits the foundational "DNA" of this nucleus (Principal) while layering on its own specific operational traits.

When to use

  • Specialization: Creating a cell that shares the same Context and Receptor but requires a stricter TestCell integrity gate.
  • Contextual Shifting: Moving a node to a different Context (e.g., from module to system) without redefining its transformation logic.
  • Lifecycle Tuning: Overriding an EphemeralPolicy to change the TTL of a specific branch in the reactive graph.

How it works

The constructor utilizes a Tiered Resolution Hierarchy to determine the final state of any property:

  1. Local Override: Values explicitly passed to this method.
  2. Prototype Inheritance: Values inherited from the principal.
  3. Causal Binding: Values derived from the upstream bind dependency.
  4. Global Default: Framework-level constants (e.g., Context.system).

Parameters:

  • principal: Required. The source Nucleus from which this instance derives its structural and logic inheritance.
  • ephemeralPolicy: Lifecycle Governance. Defines when the node should be automatically neutralized. Resolves from principal if null.
  • bind: Ingress Link. A Cell dependency. Note: bindings are instance-specific and are not inherited from the principal.
  • context: Execution Environment. Defines the security tier and priority. Resolves from principal if null.
  • receptor: Transformation Pipeline. The logic used to process incoming signals. Resolves from principal if null.
  • testRule: Integrity Gate. Validation rules that guard state modifications. Resolves from principal if null.
  • synapses: Signal Distribution. Manages egress connectivity. Resolves from principal if null.
  • user: Extension Metadata. An optional record for domain-specific properties kept separate from framework logic.
  • override: Optional. A pre-compiled Nucleus whose internal record will be adopted directly.
