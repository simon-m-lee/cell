EntryUpdatedRecord

EntryUpdatedRecord<K, V> typedef

EntryUpdatedRecord<K, V> = ({V? after, V? before, K key})

A record that captures a before‑and‑after snapshot of a key‑value pair change, delivered as the payload of an entryUpdated event.

When to use

  • Map Mutation Tracking: Reacting to key‑value insertions, modifications, or removals inside a TissueMap.
  • Auditing & History: Recording exact key changes for forensic logs or undo/redo pipelines.
  • Conditional Logic: Comparing before and after values to trigger targeted side effects for specific map keys.

You never create this record directly. It's constructed automatically by the framework and delivered to you as the payload of an entryUpdated event when observing a TissueMap. Use it to inspect exactly which key changed and how its value evolved.

How it works

This is a Dart record (not a class), making it lightweight and immutable. The record consists of three named and positional fields:

  • key: The key within the map that underwent mutation.
  • before: The value associated with the key before the change. May be null if the key was newly inserted.
  • after: The value associated with the key after the change. May be null if the key was removed or cleared.

The record is typically destructured in the event handler:

mapCell.listen((event) {
  if (event.type == Tissue.entryUpdated) {
    final (:key, :before, :after) = event.payload!;
    print('Key "$key" changed from $before to $after');
  }
});

Non‑obvious

  • Insertions vs. Deletions: If before is null and after is present, it represents an insertion. If after is null, it represents a removal.
  • Equality: Because this is a record, equality is value‑based. Two records with identical key, before, and after values are equal.

Type Parameters:

  • K – The type of the map keys (e.g., String, int).
  • V – The type of the map values being tracked.

See also:

  • Tissue.entryUpdated – the event classification that carries this record.
  • TissueMap – the reactive map collection that emits these events.
