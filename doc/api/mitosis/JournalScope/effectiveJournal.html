EffectJournal effectiveJournal(
  1. EffectJournal captured
)

The journal an effectful operator should actually use: the ambient journal when an outer scope has pushed one (the ReplayEngine pushes a per-entry ReplayJournal around the dispatch), otherwise the journal the operator captured at construction.

How it works

The ambient can only be observed before the operator pushes its own scope; the operator then pushes effectiveJournal so the mapper sees the same journal through both channels.

Parameters:

  • captured: The journal the operator captured at construction.

Returns:

The ambient journal when one is in scope, otherwise captured.

Implementation

static EffectJournal effectiveJournal(EffectJournal captured) {
  final ambient = current;
  return identical(ambient, NullJournal.instance) ? captured : ambient;
}
