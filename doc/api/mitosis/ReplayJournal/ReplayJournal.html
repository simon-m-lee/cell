Creates a replay journal from a recorded log. The list must be in ordinal order (which RecordingJournal.toJson guarantees).

Parameters:

  • records: The recorded effects, in ordinal order.
  • deferredFires: Changes the timer semantics for ENGINE replay: fire callbacks are collected instead of run inside the consuming entry, and the engine runs them after the entry loop. (Review fix: the eager fire landed a debounce trailing edge one entry before the recording's, breaking the recorded baseline of the next entry. Direct journal users — the tests — pass nothing and keep the eager behaviour.)
