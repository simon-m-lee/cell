Creates a specialized Architectural Extension of an existing TissueNucleus to support hierarchical property inheritance and contextual overrides for collections.

This factory is the primary architectural implementation of Prototypal Inheritance and Behavioural Shadowing within the collection ecosystem. In the framework's biological meta-language, it creates a Deputy configuration that inherits the structural "DNA" and baseline rules of a principal while selectively applying directed Genetic Mutations.

When to use

  • Access Control: Creating a restricted "Read-Only" view of a shared storage pool by overriding the testRule.
  • Contextual Isolation: Moving a collection into a different Context (e.g., from background to ui) to change its processing priority.
  • Transformation Overrides: Swapping a receptor to apply different mutation logic to the same underlying data.

How it works

The constructor utilizes a Tiered Resolution Hierarchy to determine the final state of any collection property:

  1. Local Override: Values explicitly passed to this factory.
  2. Prototype Inheritance: Values inherited from the principal.
  3. Causal Binding: Values derived from the upstream bind dependency.
  4. Global Default: Framework-level constants (e.g., Context.system).

Parameters:

  • principal: Required. The source nucleus from which this instance derives its structural DNA and inheritance chain.
  • ephemeralPolicy: Lifecycle Governance. Defines the TTL for the collection state.
  • bind: Ingress Link. An optional upstream Cell to observe.
  • context: Operational Authority. Defines the execution tier (default: inherits from principal).
  • receptor: Command Engine. The logic used to process mutations (default: inherits from principal).
  • testRule: Integrity Gate. Validation rules that guard the collection (default: inherits from principal).
  • synapses: Signal Distribution. Manages egress connectivity (default: inherits from principal).
  • override: Composite Shadowing. An optional, complete nucleus whose internal record is adopted directly as the local tier.

Returns:

A new TissueNucleus<E> instance acting as a specialized behavioral layer over the principal.

factory TissueNucleus.evolve(TissueNucleus<E> principal, {
  EphemeralPolicy? ephemeralPolicy,
  Cell? bind,
  Context? context,
  TissueReceptor<E, Tissue<E>>? receptor,
  TestTissue<E, Tissue<E>>? testRule,
  Synapses? synapses,
  TissueNucleus<E>? override
}) {
  return _TissueNucleus.fromRecord((
    local: override != null
        ? (override as NucleusBase).record.local
        : TissueNucleusBase.mask<E, Iterable<E>, Tissue<E>>(
            bind: bind,
            context: context,
            receptor: receptor,
            testRule: testRule,
            synapses: synapses,
            forceLock: true,
            ephemeralPolicy: ephemeralPolicy,
          ),
    principal: principal,
  ));
}
