AiConfig fromJsonFile(
  1. String path
)

Reads a JSON file and builds an AiConfig from its contents.

Parameters

  • path: The File Path. Relative to the current working directory or absolute. The file must be UTF-8 encoded JSON whose top-level value is an object.

Throws

  • FileSystemException if the file cannot be read.
  • FormatException if the JSON is malformed or missing required keys.

Implementation

static AiConfig fromJsonFile(String path) {
  final raw = readJsonFileSync(path);
  final decoded = jsonDecode(raw);
  if (decoded is! Map<String, dynamic>) {
    throw const FormatException(
      'AiConfig: file must contain a top-level JSON object',
    );
  }
  return AiConfig.fromJson(decoded);
}
