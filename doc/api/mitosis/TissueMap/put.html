Upserts the key/value pair into this map Tissue.

If the key is already present, the existing value is replaced and a Tissue.entryUpdated pulse is emitted with an EntryUpdatedRecord payload carrying the before and after values. If the key is absent, the pair is inserted and a Tissue.elementAdded pulse is emitted.

This is the named counterpart of the []= operator (which delegates to this method) and the explicit "set" command for the apply gateway and modifiable whitelist. Unlike add, it never treats an existing key as a no‑op.

Example

final map = TissueMap<String, int>();
map.put('a', 1); // emits elementAdded
map.put('a', 2); // emits entryUpdated (key: 'a', before: 1, after: 2)
