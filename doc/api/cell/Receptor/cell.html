cell property

C get cell

The host Cell instance that this receptor is currently serving.

When to use

This is the primary way for transformation logic to access Host Context. Use it inside custom instructions to read the current state of the cell or to access its metadata.

How it works

It returns a reference to the Cell that successfully called activate on this receptor.

Non‑obvious

  • Late-Bound Property: Accessing this getter before isActivated is true will throw a StateError.
  • Type Integrity: The returned cell is guaranteed to match the generic type C specified during the receptor's construction, ensuring compile-time safety for host-specific logic.

Returns:

The host cell instance.
