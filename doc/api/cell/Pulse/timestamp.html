timestamp

timestamp property

DateTime get timestamp

The exact moment this pulse was synthesised.

When to use

  • Temporal Ordering: Read this to know when the pulse was created — useful for debugging, auditing, or ordering signals in time.
  • Debugging to understand signal timing.
  • Auditing to know when an event occurred.
  • Ordering signals chronologically.
  • Performance analysis.

How it works

The timestamp is set when the root pulse is created and inherited by all derived pulses. It never changes.

Non‑obvious: this is the root's timestamp

This is the creation time of the original pulse, not the current derived one. If you evolve a pulse, the timestamp stays the same.
