isComposite property

bool get isComposite

Indicates whether this pulse is a multi‑message bundle.

When to use

  • Bundle Detection: Check this if you need to know whether a pulse contains multiple sub‑pulses — for example, when iterating over it.
  • Checking if a pulse is a bundle before iterating.
  • Conditional logic based on composite status.
  • Debugging to understand pulse structure.

How it works

A composite pulse is created with the + operator or Pulse.batch. It acts as an iterable collection of pulses.

Example

final composite = Pulse<int>(1) + Pulse<String>('hello');
if (composite.isComposite) {
  for (final p in composite) {
    print(p.payload); // 1, hello
  }
}
