Synthesizes a Functional Projection—a specialized node that performs a pure, deterministic transformation on an upstream source.

The derive factory is the primary tool for Data Refinement. It creates a strictly reactive 1-to-1 mapping where every incoming pulse is projected into a new form based on the project logic.

When to use

Use this when you need to change the shape or type of a single data stream—for example, converting a "User" object into a "Username" string.

  • Type Conversion: Mapping a raw model to a UI-friendly view model.
  • Data Sanitization: Trimming strings or normalizing numbers.
  • State Extraction: Pulling a specific property out of a complex state.

How it works

  1. The cell establishes a persistent link to the source source.
  2. Every pulse emitted by the source triggers the project function.
  3. The resulting pulse is automatically wrapped as an EvolvedPulse and propagated to downstream observers.

Non‑obvious

  • Causal Lineage: Projections automatically preserve Causal Provenance. The resulting pulse is an EvolvedPulse linked to the original stimulus.
  • Implicit Suppression: If the project returns null, the derivation acts as an implicit valve and terminates the signal.
  • Statelessness: Derivations do not store state; they compute results on-demand. Use Cell.state if you need state persistence.
  • Flow Control: Use the synapses parameter to attach a PropagationPolicy. This allows you to debounce state emissions, throttle high-frequency updates, or batch multiple state changes into a single downstream pulse.

Example: Name Extraction

final username = Cell.derive<UserPulse, StringPulse>(
  source: userProfile.cell,
  project: (pulse) => Pulse(pulse.payload.displayName),
);

Parameters:

  • source: The Ingress Source. The single upstream Cell to observe.
  • project: The Projection Logic. A pure function that defines how the input pulse maps to the output pulse.

Returns:

A Cell instance representing a Functional Transformation. It dynamically computes its state by applying the project logic to the upstream source source.

See Also:

  • Cell.synthesis: For merging multiple sources into one consensus.
  • Cell.state: For conditional suppression without transformation.
  • Example: See example/derive_demo.dart for a walkthrough of chained projections and causal tracing. {@category Core 16 Operators}
