Creates a deputy: a proxy Cell that shares the same underlying state and identity as this cell, but operates under a different context and/or testRule.

A deputy is not a copy. It points at the same physical storage and Lock as its principal — cell == cell.deputy() is always true, and changes to one are visible through the other. What differs is what the deputy is allowed to do: testRule governs it, and it is layered additively on top of the principal's own rule, so a deputy can only narrow permissions, never grant ones the principal doesn't already have.

When to use

Use this to create restricted views of a cell – e.g. read‑only, scoped authority, temporary access, or sandboxed simulations.

How it works

  • testRule: additional restrictions (layered on top of principal's).
  • context: the deputy's own mandate (authority, clearance, lease).
  • ephemeralPolicy: independent lifecycle for this handle.
  • synapses: independent observer registry for this handle.

Non‑obvious

  • The deputy's testRule is added to the principal's – you cannot bypass the principal's own rules.
  • Deputies are equal to their principal: deputy == principal is true.

Example: read-only view

final readOnly = await cell.deputy(testRule: TestCell.readOnly);
readOnly.value;        // works
readOnly.apply(...);   // blocked — modifiable whitelist is empty for readOnly

Parameters:

  • context: The deputy's DeputyContext — its authority, role, and clearance. Defaults to DeputyContext.system (inherits the principal's identity, tagged as a delegate).
  • testRule: Additional TestCell policy, layered on top of (not replacing) the principal's own rule. Defaults to TestCell.allowAll (no additional restriction beyond the principal's).
  • ephemeralPolicy: Optional TTL/event-count lifecycle for this specific handle, independent of the principal's own lifecycle.
  • synapses: The deputy's own downstream observer registry. Defaults to Synapses.enabled — a fresh, independent registry, not shared with the principal's.

Returns:

A FutureOr resolving to a Cell sharing this instance's state under the specified restrictions.
