UnmodifiableValueCell

UnmodifiableValueCell<V> class

A specialized read‑only proxy of a ValueCell that enforces immutability.

This is what you get from ValueCell.unmodifiable. It blocks any mutation attempts while still being a live, reactive participant in the graph.

When to use

You get this automatically via unmodifiable. You don't construct it directly.

How it works

It shares the same Box and lock as the principal, but its testRule is set to TestCell.readOnly, so any mutation is rejected.

Non‑obvious

  • It recursively projects nested Cell values as unmodifiable.
  • It is logically equal to its principal (== is true).

See also: ValueCell.unmodifiable.
