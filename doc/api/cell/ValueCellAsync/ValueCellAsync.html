Initializes a new ValueCellAsync controller, anchoring an asynchronous execution layer to a specific ValueCell principal.

When to use

You typically obtain this via cell.async, not by calling the constructor directly.

How it works

  • The constructor stores a reference to the principal cell.
  • It doesn't allocate any additional state – all state is held in the cell's nucleus.
  • The resulting instance is ready for asynchronous operations.

Non‑obvious

  • The controller is cheap – it's just a wrapper.
  • It shares the cell's lock, so it's fully thread‑safe.

Parameters:

  • cell: The principal ValueCell to control.
