isTerminal property

bool get isTerminal
inherited

A boolean indicator identifying whether this Cell acts as a Processing Sink within the reactive graph.

In a reactive architecture, a Terminal Node is a component that possesses the internal logic to process and store state but lacks the propagation mechanisms required to broadcast its updates to downstream dependents.

When to use

This is mostly informational. Terminal nodes (e.g. Cell.observe) have no downstream observers, so they're lightweight and won't cause cascade effects.

Returns:

true if this cell is a terminal node with no outgoing notification capabilities; false if it is a transit node that broadcasts its state changes to observers.
